# 09. 원산지증명서와 FTA

이 장이 끝나면 — 바이어가 **"C/O 보내달라"** 고 했을 때 무엇을 어떻게 준비해야 하는지 알게 됨.

원산지증명서는 **바이어가 관세 혜택을 받기 위해 나에게 요구하는 서류**. 발급 주체는 나. 못 만들면 거래가 깨지거나 그만큼 값을 깎임.

---

## 1. FTA 특혜관세 3요건

셋 다 충족돼야 함. 하나라도 빠지면 혜택 없음.

| # | 요건 | 확인 |
|---|---|---|
| 01 | 상대국과 **FTA 발효** | FTA 포털 |
| 02 | 물품이 **양허 대상** | **HS 6단위** 기준 |
| 03 | **원산지증명서** | 내가 발급 |

### 깨야 할 오해 3가지

| 오해 | 사실 |
|---|---|
| "FTA면 무조건 0%" | **아님.** 협정별/품목별로 양허 대상이 아닌 품목이 있음. 양허율은 상대국마다 다름 `[검증]` |
| "양허 대상이면 바로 0%" | **아님.** 최대 20년에 걸쳐 단계적으로 철폐되는 품목이 있음 |
| "C/O 는 항상 필요" | **아님.** WTO 협정관세로 이미 0%면 불필요 |

**발급 전에 실익부터 계산할 것.** 기본세율과 협정세율을 비교해 협정세율이 유리한 경우에만 발급하면 됨. 이미 무관세 품목이면 시간과 비용만 들어감.

### C/O 를 요구하는 진짜 이유

없으면 그 물품이 실제로 한국에서 만들어진 것인지, **제3국 물품이 한국을 거쳐 우회 수출되는 것인지** 구분할 수 없기 때문.

## 2. 발급형식 — 기관발급 vs 자율발급

| 구분 | 기관발급 | 자율발급 |
|---|---|---|
| 발급자 | 세관 또는 상공회의소 | **나** |
| 사전 심사 | 있음 (보완통보 → 재신청) | 없음 |
| 소요 | 서류 완비 시 반나절 수준 | 즉시 |
| 비용 | **세관(유니패스) 무료** / 상공회의소는 비회원 수수료 | 없음 |
| 장점 | 공신력. **사후조사 대응 용이** | 신속/저렴 |
| 단점 | 절차 번거로움 | 판정서류를 **스스로 작성/보관**해야 함 |

**자율발급의 함정** — 아무도 서류를 강제하지 않아 판정 없이 발행하기 쉬움. 그러나 사후 원산지조사에서 입증하지 못하면 특혜 배제 + 추징. **자율발급일수록 내부 서류관리가 더 중요.**

### 협정별 발급형식

| 형식 | 협정 |
|---|---|
| **기관발급** | 한-중 / 한-베트남 / 한-싱가포르 / 한-아세안 / 한-인도 `[검증]` |
| **자율발급** | 한-EU / 한-영 / 한-EFTA / 한-터키 / 한-미 / 한-캐나다 / 한-칠레 / 한-페루 / 한-콜롬비아 / 한-중미 / 한-호주 / 한-뉴질랜드 |
| **원칙 기관발급, 인증수출자 시 자율발급** | RCEP |

### 협정이 여러 개일 때

| 상대국 | 선택 가능 |
|---|---|
| 베트남 | 한-베트남 / 한-아세안 / RCEP |
| 싱가포르 | 한-싱가포르 / 한-아세안 / RCEP |

베트남처럼 결정기준과 세율이 같으면 어느 쪽이든 무방하나, **바이어가 원하는 양식이 있는지 먼저 확인**할 것. 협정마다 결정기준이 다르면 유리한 쪽을 고르는 것도 실무 판단.

## 3. 인증수출자 — 지금 필요한가

한-EU FTA 는 별도 양식 없이 **상업송장 등에 원산지 문구를 적는 것만으로** 원산지를 인정함 (원산지신고서 방식).

> "The exporter of the products covered by this document (customs authorisation No ...(1)) declares that, except where otherwise clearly indicated, these products are of ...(2) preferential origin"

(1) 인증수출자 번호, (2) 원산지 국가.

절차가 간편해진 만큼 부정 수혜를 막기 위해 인증수출자 제도를 함께 운영함.

| 협정 | 조건 |
|---|---|
| 한-EU / 한-영 | **건당 6,000유로 초과** 시 인증수출자만 가능 `[검증]` |
| RCEP | 인증수출자 취득 시 자율발급 가능 |

**결론 — 6,000유로 이하로 시작하는 단계에서는 인증수출자가 없어도 됨.** 거래 규모가 커지면 그때 취득.

## 4. 원산지 판정 — C/O 의 전제

**판정이 먼저, 발급은 그 다음.** 판정 없이 C/O 는 나오지 않음.

### 4.1 BOM 작성

관세사가 가장 먼저 요구하는 것은 **BOM(원재료 명세서)**.

| 항목 | 작성 요령 |
|---|---|
| 원재료 목록 | **누락 없이** 전부 기재 |
| HS 코드 | 아는 것만 먼저 |
| 원산지 / 가격 | 우선 공란으로 두어도 됨 (필요한 만큼만 채움) |

### 4.2 원산지결정기준

협정별/HS 6단위별로 다름. **관세청 FTA 포털 → FTA협정별 원산지결정기준 → 협정 선택 + HS 코드 입력**으로 조회.

| 기준 | 내용 |
|---|---|
| **세번변경기준 (CTC)** | 원재료 HS 세번과 완제품 세번이 달라지면 그 공정국을 원산지로 인정. CC(2단위) / **CTH(4단위)** / CTSH(6단위) |
| **부가가치기준 (RVC)** | 역내 부가가치 비율이 기준 이상. 예 — FOB 기준 40% `[검증]` |

`CTH 또는 RVC 40%` 처럼 선택형인 경우가 많음. **유리한 쪽을 고르면 됨.**

### 4.3 판정 3단계 완충구조 — 이 장의 핵심

세번변경을 먼저 시도하고, 막히면 완충장치를 차례로 씀.

| 단계 | 상황 | 대응 | 부담 |
|---|---|---|---|
| **1** 세번변경 | 완제품과 **HS 코드가 같은 원재료**가 있어 세번변경 불성립 | 그 원재료가 **국내산**이어야 함 → 공급자에게 **원산지확인서** 요청 | **가벼움.** 문제 원재료만 |
| **2** 미소기준 | 확인서를 못 받음 | 문제 원재료 비중이 **10% 이내**면 허용 `[검증]` | BOM 에 **가격 전부** 기재 |
| **3** 부가가치 | 미소기준도 초과 | RVC 로 전환. FOB 기준 **40% 이상 국내산** | **모든 원재료** 확인서 필요 |

**실무 목표는 1단계에서 끝내는 것.** 문제가 된 원재료에 대해서만 원산지확인서를 확보하면 됨.

### 4.4 두 가지 대원칙

| 원칙 | 내용 | 증빙 |
|---|---|---|
| **역내가공 원칙** | 원칙적으로 국내에서 가공되어야 함 | 제조공정도 |
| **충분가공 원칙** | 단순 포장/라벨링 등은 원산지를 부여하지 않음 | 제조공정도 |

## 5. 발급 구비서류

| # | 서류 | 역할 |
|---|---|---|
| 01 | **BOM** | 판정의 출발점 |
| 02 | **원산지(포괄)확인서** | 원재료가 국내산임을 공급자가 증명. 생산자와 수출자가 다를 때도 필요 |
| 03 | **원산지소명서** | 판정 근거 정리 |
| 04 | **제조공정도** | 역내가공/충분가공 확인 |
| 05 | 거래명세서 / 세금계산서 | 원재료가 실제 거래되었음을 증명 |
| 06 | 상업송장 / 포장명세서 / B/L | 물품이 실제 거래되고 운송됨을 증명 |
| 07 | 수출신고필증 | **전산 연계로 신고번호만 입력하면 자동 반영 → 첨부 생략 가능** |

## 6. 사고가 나는 지점

### C/O 는 원칙적으로 1회만 출력

| 시점 | 정정 방법 |
|---|---|
| 출력 **전** | 정정신고 후 재승인 (간단) |
| 출력 **후** | **출력된 원본을 세관에 반환**해야 함 (번거로움) |

**출력 전 검수가 결정적.**

| # | 검수 항목 |
|---|---|
| 01 | 수출자/수익자 상호 — **대소문자까지** 송장과 동일한가 |
| 02 | 주소가 동일한가 |
| 03 | 품명/HS/수량/금액이 송장과 일치하는가 |
| 04 | **출항일자**가 B/L 과 일치하는가 |

### Check B/L 로 승인받은 경우

출항 전 Check B/L 기준으로 승인받는 것이 일반적. **출항이 지연되거나 B/L 정보가 바뀌면 정정승인**을 다시 받아야 함.

권장 — 포워더에게서 **O.B/L 스캔본을 받아 최종 대조한 뒤 출력**.

### 송장 오류의 연쇄 — 가장 비싼 실수

```
상업송장 오류
  → 수출신고 정정
  → B/L 정정
  → 적하목록 재신고 (포워더 과태료 가능)
  → 관세사 오류점수 상승 (이후 검사 선별 확률 증가)
  → 이미 발송한 C/O 원본 해외 회수
```

**C/O 는 상업송장을 기초로 작성됨.** 송장이 정확하면 뒤가 전부 정확해짐.
