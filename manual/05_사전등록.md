# 05. 사전등록 — 통관고유부호와 해외거래처부호

이 장이 끝나면 — **통관고유부호**와 **해외거래처부호**가 손에 남음. 이 두 개가 없으면 수출신고서 작성 자체가 불가능.

최초 1회만 하면 되는 작업. 이후 모든 수출 건에 계속 사용됨.

---

## 1. 사업자 통관고유부호

### 무엇인가

관세청이 **업체별로 수출입을 관리하는 식별번호**. 사업자등록번호와 별개로 부여됨.

수출이든 수입이든 무역을 하려면 반드시 필요. 수출신고필증의 수출대행자/수출화주 칸에는 상호와 함께 이 부호가 들어감.

### 자주 나오는 오해 2가지

| 오해 | 사실 |
|---|---|
| "업종이 무역업이어야 발급된다" | **아님.** 현재 사업자등록이 되어 있고 앞으로 무역을 하려 한다면 업종 무관하게 신청 가능 |
| "해외직구할 때 쓰는 그 번호 아닌가" | **완전히 별개.** 개인 직구용 개인통관고유부호와는 다른 제도. 훨씬 간단한 개인용과 혼동 금지 |

### 발급

| 항목 | 내용 |
|---|---|
| 신청처 | 유니패스 (관세청 국가관세종합정보망) |
| 비용 | 무료 |
| 준비물 | 사업자등록증 |

## 2. 해외거래처부호

### 무엇인가

**거래 상대방(바이어)을 유니패스에 등록한 식별번호**. 수출신고필증의 `구매자` 칸에 상호와 함께 기재됨.

### 왜 먼저 해야 하는가

**해외거래처부호가 등록되어 있지 않으면 수출신고서를 작성할 수 없음.** 송장을 다 만들고 관세사에게 넘긴 다음에야 "거래처부호가 없다"는 말을 듣게 되면 그만큼 지연됨.

### 이미 등록되어 있을 수 있음

해외거래처부호는 **제3자가 등록해 둔 것도 사용 가능**. 그 바이어가 한국과의 거래가 처음이 아니라면 이미 유니패스에 등록되어 있을 확률이 높음. 신규 등록 전에 조회부터 할 것.

## 3. 순서

```
사업자등록증 준비
  → 유니패스 사용자등록
  → 통관고유부호 신청
  → 바이어 확정 후 해외거래처부호 조회
       ├ 있음 → 그대로 사용
       └ 없음 → 신규 등록
  → 수출신고 가능 상태
```

## 4. 체크리스트

| # | 항목 | 확인 |
|---|---|---|
| 01 | 유니패스 사용자등록 완료 | |
| 02 | 통관고유부호 발급 완료 | 개인통관고유부호와 다른 것임을 확인 |
| 03 | 바이어의 해외거래처부호 조회 | 기존 등록 여부 먼저 확인 |
| 04 | 없으면 신규 등록 | 상호/주소가 상업송장과 일치하는지 확인 |
| 05 | 두 부호를 관세사에게 전달 | |

## 5. 자주 하는 질문

**Q. 관세사에게 맡기면 이것도 대신 해주나요**
대부분 대행 가능. 다만 통관고유부호는 사업자 본인 정보라 처음 한 번은 직접 신청해 두는 편이 이후 관리에 편함.

**Q. 바이어가 여러 곳이면 각각 등록해야 하나요**
그렇다. 거래처마다 별도 부호가 필요.

**Q. 바이어 상호가 송장과 조금 다르게 등록돼 있으면요**
상업송장과 수출신고필증의 정보는 일치해야 함. 차이가 있으면 등록 정보를 정정하거나 송장을 맞출 것. 특히 **원산지증명서를 발급할 경우 대소문자와 주소까지 일치**해야 하므로 이 단계에서 정리해 두는 것이 유리함.
