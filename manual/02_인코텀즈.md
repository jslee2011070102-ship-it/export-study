# 02. 인코텀즈 2020 — 가격조건 정하기

이 장이 끝나면 — 바이어와 **어떤 조건으로 팔지** 결정할 수 있게 됨. 이 결정이 이후 운임/보험/서류/신고금액을 전부 좌우함.

---

## 1. 인코텀즈는 가격조건이 아니라 인도조건

`FOB BUSAN` 같은 표기를 가격표처럼 쓰지만, 실제로 정하는 것은 **언제 내 책임이 끝나는가**.

읽을 때 볼 것은 두 가지뿐.

| 질문 | 의미 |
|---|---|
| **어디서 인도되는가** | 그 시점에 **위험이 나 → 바이어로 넘어감**. 이후 사고는 바이어 책임 |
| **운송계약과 운임은 누가 내는가** | 위험 이전과 **별개** |

가장 중요한 오해 — **운임을 내가 낸다고 위험도 내가 지는 게 아님.** 이 둘이 어긋나는 것이 C 규칙.

인코텀즈가 **안 정하는 것**도 알아둘 것. 이걸 모르면 "인코텀즈에 다 있겠지" 하고 계약서를 부실하게 씀.

| 정함 | 안 정함 |
|---|---|
| 인도장소, 위험이전 | **소유권이 언제 넘어가는지** |
| 운송/보험 계약 의무 | **대금을 언제 어떻게 받는지** (T/T, L/C) |
| 수출입 통관 의무 | 계약 위반 시 어떻게 할지 |
| 서류 제공, 비용 분담 | 품질 하자 책임, 준거법, 분쟁 관할 |

## 2. 4개 그룹만 외우면 됨

앞 글자로 나뉨.

| 그룹 | 인도장소 | 운송계약/운임 | 운송 중 사고 책임 |
|---|---|---|---|
| **E** — EXW | 내 공장/창고 | 바이어 | 바이어 |
| **F** — FCA, FAS, FOB | 국내 선적지 | **바이어** (착불) | 바이어 |
| **C** — CPT, CIP, CFR, CIF | 국내 선적지 | **나** (선불) | **바이어** |
| **D** — DAP, DPU, DDP | 상대국 목적지 | 나 | **나** |

E/F/C = **선적지 인도** → 배에 실으면 내 책임 끝.
D = **양륙지 인도** → 도착할 때까지 내 책임.

### 두 번째 축 — 배 전용인가 아닌가

그룹과 **별개의 분류**. 여기서 틀리는 사람이 많음.

| 구분 | 규칙 | 
|---|---|
| **아무 운송수단이나 OK** (7개) | EXW, FCA, CPT, CIP, DAP, DPU, DDP |
| **배 전용** (4개) | **FAS, FOB, CFR, CIF** |

배 전용 4개는 인도 지점이 "선측" 또는 "본선 위". 그래서 **항공 건에 FOB/CIF 를 쓰면 안 됨.**

그리고 **컨테이너 화물도 사실 배 전용 규칙에 안 맞음.** 자세한 건 아래 FOB 항목.

## 3. 규칙별 요약 (11개 전부)

### E 그룹

#### EXW — 내 공장에서 끝

| | |
|---|---|
| 인도 | 내 공장/창고에서, **싣지 않은 채로** 바이어가 가져갈 수 있게 둔 때 |
| 운임 | 바이어 |
| 보험 | 없음 |
| 수출통관 | **바이어** |
| 운송수단 | 아무거나 |

매도인 최소의무. 주의할 점 2가지.

- **적재의무 없음.** 내 창고에 지게차가 있어도 규칙상 싣는 것은 바이어 몫. 싣다가 사고 나면 책임 다툼이 됨
- **수출통관도 바이어 의무.** 그러나 외국 바이어가 한국 세관에 수출신고를 하는 건 현실적으로 불가능. 결국 내가 대행하게 되어 **계약은 EXW인데 실제는 FCA처럼 돌아가는 불일치**가 생김

한국 수출자에게는 이게 실제 손해 — 수출신고가 내 명의로 안 되면 **관세환급/영세율/수출실적**이 다 꼬임. 첫 수출이라면 EXW 보다 **FCA** 가 깔끔함.

### F 그룹 — 바이어가 운임 부담 (착불)

#### FCA — 국내에서 운송인한테 넘기면 끝

| | |
|---|---|
| 인도 | **장소에 따라 2가지** (아래) |
| 운임 | 바이어 |
| 보험 | 없음 |
| 수출통관 | **나** |
| 운송수단 | 아무거나 |

| 지정장소 | 언제 끝나나 | 싣는 사람 |
|---|---|---|
| **내 공장/창고** | 바이어가 보낸 차에 **다 싣고 나면** | 나 |
| **그 밖의 장소** (CY, 포워더 창고, 공항터미널) | 내 차에 **실린 채로** 갖다 대면 (내리는 건 안 함) | 상대 |

EXW 와 딱 두 가지 차이 — **내가 수출통관을 하고, 내 공장에서 넘길 땐 싣는 것까지 한다.**

- **컨테이너 수출의 정답이 FCA.** 컨테이너는 CY 에서 넘어가지 배에 실릴 때 넘어가는 게 아님
- **신용장 건이면 미리 확인할 것.** FCA 는 배에 싣기 전에 인도가 끝나서 `on board` 찍힌 선하증권을 내가 못 받을 수 있음. 2020 에 이걸 보완하는 옵션이 생겼지만, 실무에선 신용장 문구를 조정하는 게 확실함

#### FAS — 배 옆에 갖다 두면 끝

| | |
|---|---|
| 인도 | 지정한 배의 **옆(부두 또는 부선)**에 물건을 둔 때. **아직 배에 안 실음** |
| 운임 | 바이어 |
| 보험 | 없음 |
| 수출통관 | **나** |
| 운송수단 | **배 전용** |

11개 중 제일 안 쓰이는 조건. 초보 수출자가 만날 일은 거의 없음.

쓰이는 자리 — 곡물/원목/광석 같은 **벌크 화물**, 크레인으로 들어올리는 **중량물/설비**. 싣는 작업 자체가 크고 위험해서 그 분기점을 배 옆으로 잡는 품목들.

- **컨테이너에 쓰면 안 됨** → FCA
- **"배 옆"이 어디까지인지 계약서에 쓸 것.** 부두 위인지, 부선에 실은 상태인지 항구마다 관행이 다름
- **배가 늦게 오면 그 대기 위험이 아직 내 것.** 부두 보관비/체선료 부담을 미리 정해둘 것

FAS 와 FOB 차이는 **싣는 작업 딱 한 단계.**

#### FOB — 배에 실으면 끝

| | |
|---|---|
| 인도 | 지정 선적항에서 **배에 다 싣고 나면** |
| 운임 | 바이어 (착불) |
| 보험 | 없음 |
| 수출통관 | **나** |
| 운송수단 | **배 전용** |

한국 수출에서 제일 많이 쓰는 조건. 수출신고 금액도 FOB 기준.

- **"배 난간 넘을 때"는 옛날 기준.** 2010 에 없어짐. 지금은 **적재 완료** 시점
- **컨테이너 건에 쓰면 구멍이 생김.** 실제로는 CY 에서 내 손을 떠나는데, 규칙상 위험은 배에 실릴 때까지 내가 짐. 그 사이 사고가 나면 **물건을 통제하지도 못하는 상태에서 내가 책임**. 정확한 건 FCA. 다만 관행상 FOB 를 쓰는 경우가 많으니, 최소한 이 구멍이 있다는 건 알고 쓸 것
- **미국 바이어와 거래할 때 주의.** 미국 국내 관행의 FOB 는 인코텀즈 FOB 와 뜻이 다름. 반드시 `Incoterms® 2020` 병기

FOB 의 장점 — 운임/보험 신경 안 써도 되고 자금 부담이 작음.
단점 — **바이어가 포워더를 지정**하므로 그 운송인이 믿을 만한지 내가 알 수 없음. 실제 사기 경로임 ([04. 오퍼와 무역사기](04_계약과_무역사기.md)).

### C 그룹 — 내가 운임 부담, 위험은 그대로 바이어

| 규칙 | 공식 | 보험 | 운송수단 |
|---|---|---|---|
| **CPT** | FCA + 내가 운임 | 없음 | 아무거나 |
| **CIP** | CPT + 내가 바이어를 위해 보험 가입 | 필수 / **최대담보** | 아무거나 |
| **CFR** | FOB + 내가 운임 | 없음 | **배 전용** |
| **CIF** | CFR + 내가 바이어를 위해 보험 가입 | 필수 / **최소담보** | **배 전용** |

C 그룹의 정체 — **위험 끊기는 곳과 돈 끊기는 곳이 다름.**

| | 어디서 |
|---|---|
| **위험** 분기 | 한국 (운송인한테 넘길 때 / 배에 실을 때) |
| **비용** 분기 | 상대국 (도착지) |

그래서 **`CIF HO CHI MINH` 에서 호치민은 "비용을 내가 여기까지 낸다"는 뜻이지 "여기까지 내가 책임진다"는 뜻이 아님.** 초보가 가장 많이 틀리는 지점.

#### CPT — 운송비를 내가 냄 (모든 운송수단)

내가 계약한 **첫 번째 운송인**에게 넘기는 순간 위험이 바이어로 감. 복합운송이면 국내 트럭 기사에게 넘긴 시점일 수도 있음. 물건이 아직 한국에 있는데 위험은 이미 바이어 것.

- **계약서에 장소를 2개 쓸 것** — 인도장소(위험 분기)와 목적지(비용 분기)
- 보험 의무가 없으니, 바이어가 자기 보험을 들려면 나한테 운송 정보를 계속 물어봐야 함 → 그 불편을 없앤 게 CIP

#### CIP — CPT + 보험 (최대담보)

내가 **바이어를 피보험자로** 보험을 듦. 보험료는 내가 내지만 **사고 나면 보험금은 바이어가 받음** (위험이 이미 넘어갔으니 정상).

- 담보 수준 **최대**(협회적하약관 A급 수준), 금액은 **송장금액의 110%**, 계약통화로
- **2020 에 최소 → 최대로 올라간 게 이 규칙.** CIF 는 안 올라감
- 보험증권/증명서를 바이어에게 넘겨야 함. 신용장 건이면 서류 요건 확인

#### CFR — FOB + 내가 운임 (배 전용)

배에 실으면 위험은 끝, 운임은 목적항까지 내가.

- **양륙비(THC) 를 누가 내는지 확인할 것.** 내 운임에도 포함되고 바이어도 따로 청구받는 이중 부담 사고가 잦음
- **수출신고 때 운임을 빼서 FOB 로 환산해야 함** → 관세사에게 운임 실액을 알려줘야 신고가 됨
- 컨테이너 건이면 CFR 말고 **CPT**

#### CIF — CFR + 보험 (최소담보, 배 전용)

가장 유명한 조건. 다만 **보험이 최소담보**라는 걸 바이어에게 알릴 것. 도난/파손 같은 흔한 사고가 담보 밖일 수 있음. 바이어가 A급을 원하면 추가보험료를 누가 낼지 계약서에 명시.

- **CIP=최대 / CIF=최소.** 이름이 비슷해서 같다고 착각하기 쉬움
- 수출신고 때 **운임 + 보험료 둘 다** 빼서 FOB 환산
- 컨테이너 건이면 CIF 말고 **CIP**

### D 그룹 — 도착까지 내 책임

| 규칙 | 인도 | 양하(하차) | 수입통관/관세 | 운송수단 |
|---|---|---|---|---|
| **DAP** | 목적지, 도착 차량 위 | 안 함 | 바이어 | 아무거나 |
| **DPU** | 목적지, **내려놓은 상태** | **함** | 바이어 | 아무거나 |
| **DDP** | 목적지, 도착 차량 위 | 안 함 | **나** (관세/부가세까지) | 아무거나 |

D 그룹 공통 — **운송 중 사고가 전부 내 책임.** 규칙상 보험 의무는 없지만 **실무상 반드시 들 것.**

#### DAP — 목적지에 차 대주면 끝

D 그룹의 기본형. 나머지 둘은 여기서 하나 더하거나 뺀 것.

- **수입통관은 바이어 몫.** 바이어가 통관을 늦추면 체화료/보관비가 쌓임. 규칙상 그 위험은 바이어가 지지만 계약서에 써두는 게 안전
- 내리는 건 바이어가 함

#### DPU — 내려주기까지 함

**11개 중 유일하게 매도인 양하의무가 있는 규칙.**

- **내릴 수 있는 장소인지 먼저 확인.** 지게차/크레인/램프가 없는 곳을 목적지로 잡으면 내가 장비를 수배해야 함
- **내리다가 사고 나면 내 책임.** 위험이 양하 완료 후에 넘어가기 때문. DAP 와의 실질적 차이가 여기
- 2020 에 **DAT(터미널인도)** 를 대체하면서 생김. 터미널 말고 **아무 장소나** 지정할 수 있게 확대됨

#### DDP — 상대국 세금까지 다 냄

매도인 최대의무. EXW 의 정반대.

- **DPU 가 아니라 DAP 에 통관의무가 더해진 것.** 그래서 DDP 에도 양하의무는 없음. `DAP → DPU → DDP` 순으로 커진다고 오해하기 쉬움
- **수입국 부가세를 환급 못 받을 수 있음.** 내가 그 나라 사업자가 아니면 낸 부가세가 그냥 원가가 됨
- **나라에 따라 비거주자는 수입신고인이 될 수 없음.** 계약 전 확인 필수
- **관세율이 바뀌면 내가 흡수.** 장납기 건은 위험이 큼
- **대안 — DAP 로 계약하고 관세만 따로 정산.** 초보라면 DDP 는 피할 것

## 4. 2020년에 바뀐 것

| 항목 | 2010 | 2020 |
|---|---|---|
| DAT | DAT (터미널인도) | **DPU 로 변경.** 터미널에 한정하지 않음 |
| CIP 보험 | 최소담보 | **최대담보로 상향** |
| CIF 보험 | 최소담보 | 최소담보 유지 |
| FCA 선하증권 | 없음 | 합의 시 **본선적재 표기 B/L** 을 받을 수 있는 옵션 |
| 자기 차로 운송 | 제3자 운송인 전제 | FCA/DAP/DPU/DDP 에서 **자가 운송수단** 명시 허용 |

2010년 조건이 적힌 오래된 양식을 그대로 쓰지 말 것. 계약서와 송장에 **`Incoterms® 2020`** 을 명시.

## 5. 초보 수출자를 위한 선택 가이드

| 상황 | 권장 |
|---|---|
| 처음이라 단순하게 가고 싶음 | **FCA** 또는 **FOB** |
| **컨테이너로 보냄** | **FCA / CPT / CIP** (FOB/CFR/CIF 아님) |
| **항공으로 보냄** | **FCA / CPT / CIP.** 배 전용 4개는 쓰면 안 됨 |
| 바이어가 EXW 를 요구함 | 수출통관을 누가 할지 반드시 문서로 정할 것 |
| **거래 상대가 미덥지 않음** | **CFR / CPT.** 아래 참조 |
| 물류비를 내가 통제하고 싶음 | C 그룹 |
| 상대가 문 앞 배송을 원함 | DAP. DDP 는 상대국 세금까지 부담하므로 신중 |
| 벌크/중량물이고 바이어가 배를 잡음 | FAS 또는 FOB |

### 사기 위험이 있을 때 C 그룹이 안전한 이유

FOB/FCA 는 **바이어가 포워더를 지정**함. 그러면 내가 그 운송인의 신용도를 확인할 방법이 없음. 물건을 넘겼는데 포워더가 바이어에게 그대로 넘기고 잠적하는 사고가 실제로 발생함.

CFR/CPT 는 내가 국내의 공신력 있는 포워더를 쓰므로 물품 탈취 가능성이 훨씬 낮음. 상세는 [04. 오퍼와 무역사기](04_계약과_무역사기.md).

## 6. 인코텀즈가 뒤에 미치는 영향

내가 고른 조건이 서류와 신고에 그대로 따라감.

| 조건 | 상업송장 표기 | 수출신고 금액 처리 | 보험 |
|---|---|---|---|
| FCA / FOB | `FOB BUSAN` | 그대로 | 바이어가 알아서 |
| CPT / CFR | `CFR HO CHI MINH` | **운임을 공제해 FOB 산출** | 바이어가 알아서 |
| CIP / CIF | `CIF HO CHI MINH` | **운임 + 보험료 공제해 FOB 산출** | **내가 가입** |
| DAP / DPU / DDP | `DAP HO CHI MINH` | **목적지까지의 운송/보험비 공제** | 실무상 내가 가입 |

즉 FOB 가 아닌 조건으로 계약했다면 **운임/보험료 금액을 관세사에게 알려줘야** 수출신고가 됨.

## 7. 체크리스트

| # | 항목 |
|---|---|
| 01 | 조건 뒤에 **지정장소**를 붙였는가 (`FOB` 가 아니라 `FOB BUSAN`) |
| 02 | `Incoterms® 2020` 을 명시했는가 |
| 03 | 해상 전용 규칙(FAS/FOB/CFR/CIF)을 **항공/컨테이너** 건에 쓰고 있지 않은가 |
| 04 | C 그룹인데 **인도장소와 목적지를 둘 다** 적었는가 |
| 05 | EXW 인데 수출통관을 내가 하기로 되어 있지 않은가 |
| 06 | CIP/CIF 인데 보험 가입을 잊지 않았는가. 담보 수준(CIP 최대 / CIF 최소)을 바이어와 맞췄는가 |
| 07 | D 그룹인데 운송보험을 들었는가 (의무는 아니지만 사고 시 내 손해) |
| 08 | DPU 인데 목적지에 하역 장비가 있는가 |
| 09 | DDP 인데 상대국에서 내가 수입신고인이 될 수 있는가, 부가세 환급이 되는가 |
| 10 | 계약서/오퍼/송장의 조건 표기가 서로 같은가 |
