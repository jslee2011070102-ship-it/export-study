# 12. 대금 회수와 외국환거래법

이 장이 끝나면 — 돈을 받고, **법 위반 없이** 처리할 수 있게 됨.

외국환거래법은 **경고 없이 곧바로 과태료나 형사처벌**로 이어짐. 모르고 어겼다는 항변이 통하지 않는 영역.

---

## 1. 결제방식별 회수 절차

### T/T (송금)

```
선급금 수령 (계약 시)
  → 생산 및 선적
  → B/L 사본을 바이어에게 송부
  → 잔금 입금 확인
  → Surrender 처리 또는 B/L 원본 송부
  → 바이어 화물 수령
```

**순서가 방어선.** 잔금을 받기 전에 Surrender 를 치면 물건과 돈을 모두 잃을 수 있음. [10장](10_포워더와_선적.md) 참조.

### 신용장

```
선적 완료
  → 신용장이 요구하는 서류 일체 준비
  → 통지은행(지정은행)에 서류 제시
  → 개설은행 서류 심사
  → 일치 판정 시 대금 지급
```

서류 준비가 전부. **조건에 맞는 서류를 제시하지 못하면 정상 선적이어도 대금을 못 받음.**

주요 하자(discrepancy) 유형 — 서류 간 품명 불일치, 금액 불일치, 제시기한 초과, 선적기한 초과, 서명 누락.

## 2. 환어음

| 항목 | 내용 |
|---|---|
| 성격 | 발행인이 지급인에게, 수취인 앞으로 지급을 위탁하는 증권 |
| 사용처 | **추심(D/P, D/A)** 과 **신용장** |
| T/T 에서는 | 불필요 |

국내 어음과 헷갈리는 지점 — 무역에서는 **수출자가 발행인**이 됨. "돈 주세요"를 증권 형식으로 만든 것.

### Sight 와 Usance

| 구분 | 지급 시점 |
|---|---|
| **Sight** (일람출급) | 서류 제시 즉시. 수출신고 코드 `LS` |
| **Usance** (기한부) | 일정 기간 후. 수출신고 코드 `LU` |

Usance 는 **이자를 누가 부담하느냐**로 나뉨.

| 유형 | 이자 부담 |
|---|---|
| Banker's Usance | 은행이 인수/할인. **수입자**가 부담 |
| Shipper's Usance | 수출자가 신용을 공여. **수출자**가 사실상 부담 |

계약 시 반드시 어느 쪽인지 명시할 것. 같은 `Usance` 라도 부담 주체가 정반대.

## 3. 외국환거래법 — 수출자가 걸리는 지점

무역 3법 중 하나. **자본의 이동**을 규율함.

아래는 **외국환거래법(시행 2026-01-02) 조문 대조를 마친 내용**. 다만 시행령/외국환거래규정의 세부 기준(금액/기간 한도)은 별도 확인 필요.

### 원칙

수출대금을 **계약 당사자가 / 계약대로 / 정상적인 은행 경로로** 받으면 문제없음. 문제는 여기서 벗어날 때 발생.

### 신고대상이 되는 대표 상황

법 제16조(지급 또는 수령의 방법의 신고)가 정한 **4가지**. 조문 그대로임.

| # | 유형 | 쉬운 말 |
|---|---|---|
| 01 | **상계** 등의 방법으로 채권/채무를 소멸시키거나 상쇄시키는 결제 | 수출채권과 수입채무를 서로 상계 |
| 02 | 정해진 **기간을 넘겨 결제**하는 경우 | 결제가 지나치게 늦어지는 경우 |
| 03 | 거래 **당사자가 아닌 자**와 지급 또는 수령 | 제3자 지급/수령 |
| 04 | **외국환업무취급기관을 통하지 아니하고** 지급 또는 수령 | 은행을 거치지 않는 결제 |

**해외예금은 제16조가 아니라 제18조(자본거래의 신고) 영역.** 별개 조문이므로 따로 확인할 것.

수출 실무에서 흔히 부딪히는 예.

- 바이어가 **자기 계열사 명의로 송금**하겠다고 함 → 제3자 지급 검토
- 같은 상대와 수출도 하고 수입도 해서 **차액만 정산**하자고 함 → 상계 신고 검토
- 바이어가 **현금으로 주겠다**고 함 → 정상 경로 이탈. [04장](04_계약과_무역사기.md)
- 해외 법인 계좌로 받겠다고 함 → **제18조 자본거래(해외예금) 신고** 검토. 제16조와 별개

### 대응 원칙

| # | 원칙 |
|---|---|
| 01 | **계약 당사자가, 계약대로, 은행을 통해** 받는 것이 가장 안전 |
| 02 | 여기서 벗어나는 제안이 오면 **먼저 은행 외환담당자 또는 관세사에게 확인** |
| 03 | "이번만" 예외를 만들지 말 것. 경고 없이 처벌됨 |
| 04 | 거래 증빙(계약서/송장/면장/입금내역)을 세트로 보관 |

## 4. 대금을 못 받았을 때

| 단계 | 조치 |
|---|---|
| 01 | 계약서/오퍼/송장/B/L/면장 등 증빙 정리 |
| 02 | 서면 최고 (독촉) |
| 03 | **중재** 신청 (계약서에 중재조항이 있는 경우) |
| 04 | 무역보험 청구 (가입한 경우) 또는 **K-SURE 채권추심 위임** |
| 05 | 수출채권 관련 외국환거래법상 처리 확인 |

**무역보험** — T/T 사후송금에서 신용위험을 이전하는 현실적 수단. 무역보험에 가입하지 않은 건도 **채권추심을 공사에 위임**할 수 있음 (무역보험법 제53조제3항). 상세는 [14장 무역보험](14_무역보험.md).

## 5. 체크리스트

| # | 항목 |
|---|---|
| 01 | 선급금을 계약대로 수령했는가 |
| 02 | 잔금 입금 확인 전에 Surrender 를 치지 않았는가 |
| 03 | (L/C) 신용장 요구서류를 빠짐없이 준비했는가 |
| 04 | (L/C) 제시기한/선적기한을 지켰는가 |
| 05 | 입금자가 **계약 당사자와 동일**한가 |
| 06 | 상계/제3자 지급/해외계좌 등 예외 상황이 없는가 |
| 07 | 예외가 있다면 신고 여부를 확인했는가 |
| 08 | 입금액과 수출신고 결제금액이 일치하는가 |
