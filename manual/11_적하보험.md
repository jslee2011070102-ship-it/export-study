# 11. 적하보험

이 장이 끝나면 — **누가 보험을 들어야 하는지**, 그리고 **보험증권을 어떻게 읽는지** 알게 됨.

---

## 1. 무역에서 말하는 보험

| 분류 | 내용 |
|---|---|
| 생명보험 | 사람의 생명. 종신보험 등 |
| **손해보험** | 재산상 손해. 자동차보험/화재보험 등 |
| └ **운송보험** | 손해보험의 한 형태. **무역보험은 여기 해당** |

운송보험은 손해보험사에서 가입.

무역의 운송은 **해상 / 항공 / 복합** 셋 중 하나. 우리나라는 삼면이 바다이고 북쪽 육로가 막혀 있어 순수 육상운송 수출은 사실상 없음.

**모든 운송보험의 기준은 해상보험.** 항공보험도 복합운송보험도 해상보험 규정을 따라감. 그래서 해상보험만 알면 됨.

### 용어 정리

| 용어 | 뜻 |
|---|---|
| 선박보험 (Hull Insurance) | 배 자체에 대한 보험. **화주와 무관** |
| **적하보험 (Cargo Insurance)** | 배에 실린 **화물**에 대한 보험. **우리가 드는 것** |

`해상보험` / `적하보험` / `해상적하보험` / `화물보험` 은 실무에서 같은 의미로 통용됨.

참고 — 손해보험사 이름이 `○○해상`, `○○화재` 로 끝나는 이유는 보험의 역사가 해상보험 → 화재보험 순으로 발전했기 때문. `현대해상`이 해상만, `삼성화재`가 화재만 취급한다는 뜻이 아님.

## 2. 누가 보험을 드는가

원칙은 단순함.

> **위험을 부담하는 자가 자기 이름으로 가입한다.**

| 용어 | 뜻 |
|---|---|
| **피보험자** (Assured / Insured) | 사고 시 **보험금을 받는 사람** |
| 보험계약자 | **보험료를 내는 사람** |

우리나라 법(대륙법)은 둘을 구분하지만, 영미법에서는 원칙적으로 같음.

**피보험자는 위험을 부담하는 자여야 함.** 옆집에 불이 났는데 내가 보험금을 받을 수 없는 것과 같은 이치.

### 인코텀즈별 정리

| 인코텀즈 | 운송 중 위험 | 피보험자 | 보험계약자 |
|---|---|---|---|
| E / F / C 규칙 (선적지 인도) | **바이어** | 바이어 | 바이어 |
| **CIP / CIF** (예외) | **바이어** | **바이어** | **수출자** |
| D 규칙 (양륙지 인도) | **수출자** | 수출자 | 수출자 |

**CIP/CIF 만 예외.** 피보험자는 여전히 바이어인데 보험료는 내가 냄. "바이어를 위해 내가 가입해 주는" 구조.

| 조건 | 부보 수준 |
|---|---|
| **CIP** | **최대담보** (2020년 개정으로 상향) |
| **CIF** | **최소담보** (유지) |

## 3. 보험서류의 종류

| 서류 | 언제 |
|---|---|
| **보험증권** (Insurance Policy) | 건별로 가입할 때 발행되는 정식 증서 |
| 보험증명서 (Insurance Certificate) | **포괄보험** 하에서 발행되는 약식 증서 |

포괄보험(Open Policy) — 대기업처럼 연간 수백~수천 건을 선적하는 경우 건마다 가입하기 어려우므로, 일정 기간 동안 수출하는 모든 물품에 자동으로 보험이 적용되게 하는 방식.

초보 수출자가 받게 되는 것은 보통 **보험증권**.

## 4. 보험증권 읽기

| 항목 | 내용 |
|---|---|
| **Assured** | 피보험자. 사고 시 보험금을 받는 자 |
| **Reference No.** | 보통 **송장번호**가 들어감. 신용장 거래면 **L/C 번호**도 함께 |
| **Claim payable at** | 사고 시 **보험금이 지급되는 장소/대리점**. 수입국이 될 수 있음 |
| **Survey by** | 손해사정을 할 당사자/장소 |
| **Ship / Vessel** | 선박명. 미확정이면 `T.B.A.` / `To be advised` |
| **Sailing on or about** | 출항 예정일. 미확정이면 `T.B.D.` 등 |
| **From / To** | 부보 구간. 원칙은 **선적항 → 양륙항** |
| **Original / Duplicate** | 원본이 복수로 발행됨 |

### 알아둘 점 3가지

**1) 왜 송장번호가 들어가는가** — 송장에 물품과 거래에 관한 모든 것이 적혀 있으므로, 이 보험이 어느 거래에 대한 것인지 특정하기 위함.

**2) 왜 보험금 지급 장소가 따로 있는가** — 한국에서 가입했지만 사고는 상대국에서 나고, 바이어가 상대국에서 청구할 수 있음. 국내 보험에는 없는 개념.

**3) 원본은 전통(full set)을 요구함** — 원본 2통이 발행되면 첫 번째 원본이 사용될 때 나머지가 자동 실효됨. 한 통만 넘기고 다른 한 통으로 이중 청구하는 것을 막기 위해 신용장/계약서는 **원본 전통 제시**를 요구하는 것이 일반적.

### 부보 구간

원칙은 **선적항 → 양륙항 (port to port)**.

내 창고 → 항구, 양륙항 → 바이어 창고 구간은 육상운송이지만 **별도의 육상운송보험이 필요하지 않고 해상보험에서 커버 가능**. 다만 실무에서 이 구간까지 확장하는 경우는 많지 않아 대개 공란으로 둠.

## 5. 수출신고 전이라도 가입 가능

수출은 **신고를 먼저 하고 운송계약을 나중에** 맺으므로, 보험 가입 시점에 선박명이 확정되지 않은 경우가 흔함.

그래서 보험증권의 선박명 칸에 `T.B.A.`(To Be Advised) 로 기재되는 경우가 많음. 확정되면 통보하는 방식.

## 6. 체크리스트

| # | 항목 |
|---|---|
| 01 | 내 인코텀즈 조건에서 **위험을 누가 부담하는가** 확인 |
| 02 | CIP/CIF 인가. 그렇다면 **내가 가입 의무** |
| 03 | CIP 는 최대담보, CIF 는 최소담보로 부보 |
| 04 | 피보험자를 바이어로 정확히 기재했는가 (CIP/CIF) |
| 05 | 송장번호(신용장 거래면 L/C 번호)가 기재되었는가 |
| 06 | 부보 구간이 실제 운송 구간과 맞는가 |
| 07 | (신용장) 원본 전통을 확보했는가 |
| 08 | 보험금액이 신용장 요구 수준을 충족하는가 |
