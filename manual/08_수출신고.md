# 08. 수출신고 — 대상 판단부터 수출면장까지

이 장이 끝나면 — **수출신고필증(수출면장)** 이 손에 남음. 이것이 있어야 선적할 수 있고, 부가세 영세율과 수출실적의 근거가 됨.

---

## 1. 먼저 판단할 것 — 수출신고를 꼭 해야 하는가

### 원칙적으로 생략 가능한 경우

환급 대상이 아닌 **FOB 200만원 이하** 물품은 송품장 또는 간이통관목록 제출로 수출신고를 갈음할 수 있음 (목록통관). `[검증]` 수출통관 사무처리에 관한 고시

### 반드시 신고해야 하는 경우

| # | 대상 |
|---|---|
| 01 | FOB 200만원 초과 물품 `[검증]` |
| 02 | 관세환급을 받아야 하는 물품 |
| 03 | 수출승인(요건)이 필요한 물품 |

### 소액이어도 신고하는 편이 유리한 이유

수출신고를 하면 따라오는 혜택 3가지.

| 혜택 | 실익 |
|---|---|
| 관세환급 | 소액에서는 실익이 미미 |
| **부가가치세 영세율/조기환급** | 수출신고번호 입력만으로 처리 가능 |
| **수출실적 인정** | **정부 지원사업, 은행 대출/무역금융에 직결** |

결론 — 관세환급만 보면 굳이 할 이유가 없지만, **부가세와 수출실적** 때문에 가능하면 신고하는 편이 유리함.

## 2. 직접 신고 vs 관세사 대행

| 방식 | 판단 |
|---|---|
| **관세사 대행** | 실무 표준. 첫 건이라면 사실상 필수 |
| **유니패스 자가신고** | 가능은 함. 수출은 수입보다 단순하므로 |

자가신고의 현실 — 채널 진행자(개업 관세사)조차 "시간당 최저시급이 안 나온다", "나라면 다른 관세사에게 맡기겠다"고 평가. 유니패스 신고 화면이 관세사 전용 프로그램에 비해 불편하기 때문.

판단 기준 — **아주 가끔 한 건씩 수출하는 경우가 아니면 대행 권장.**

자가신고를 하는 경우 입력은 **공통사항1 → 공통사항2 → 란사항** 3단계로 진행됨.

## 3. 언제, 어디에 신고하는가

### 시점 — 운송계약 전이어도 됨

**수출신고에 필요한 것은 상업송장과 포장명세서뿐.** 운송계약이 되어 있을 필요가 없고, B/L 도 필요 없음.

내용만 충실하면 신고 자체는 하루 안에 처리될 수 있음.

### 장소 — 물품이 있는 곳의 관할세관

> 수출신고는 **해당 물품이 장치된 물품소재지를 관할하는 세관장**에게 한다.

| 오해 | 사실 |
|---|---|
| 사업장 소재지 세관에 하는 것 | **아님** |
| 선적하는 항구/공항 세관에 하는 것 | **아님** |

**실제로 물품이 있는 장소** 기준. 공장과 본사가 다르면 공장 주소가 기준.

편의상 본사 주소로 신고하는 사례가 있으나, 검사 대상이 되면 신고한 주소지로 물품을 옮겨야 하는 부담과 함께 **과태료**가 발생할 수 있음.

## 4. 관세사에게 반드시 알려줄 것

서류만 넘기면 안 되고, 아래 두 가지는 명시적으로 전달해야 함.

| # | 항목 | 이유 |
|---|---|---|
| 01 | **물품소재지** | 관할세관이 결정됨. 틀리면 과태료 |
| 02 | **적재예정보세구역** | 어느 항구/공항에 실을 것인지 |

추가로 상황에 따라.

| 상황 | 함께 전달 |
|---|---|
| CIF/CFR 등으로 계약 | 운임/보험료 금액 (FOB 환산에 필요) |
| 수입자가 C/O 요구 | **최대한 빨리** 통보. 원산지판정에 시간이 걸림 |
| 제조자를 아는 경우 | 제조자 정보 (미상 처리하면 불이익 있음) |

### 제조자를 미상으로 두면 안 되는 이유

완제품을 공급받아 수출하는 경우 제조자를 `미상`으로 신고할 수 있음. 그러나 미상이면 두 가지 불이익이 발생.

- **FTA 원산지증명서 발급이 어려워짐**
- **관세환급이 제한됨**

제조자를 알고 있다면 정확히 기재할 것.

## 5. 검사에 걸리는 경우

수출은 수입보다 검사 확률이 훨씬 낮음. 대부분 `수출검사생략` 대상으로 처리됨.

| 검사 종류 | 내용 |
|---|---|
| **적재지검사** | **원칙.** 적재지 보세구역에서 검사 |
| 신고지검사 | 물품소재지 방문 검사. 반송물품/계약상이물품/재수출물품 등 예외적 경우 |

걸리기 쉬운 경우 — **첫 수출**, 불법/도난 가능성이 있는 중고물품.

주의 — 수출신고 후 **적재지가 변경되면 물품검사 전에 수출신고를 정정**해야 함.

비용 지원 — 적재지검사를 받은 **중소/중견기업의 컨테이너 화물**은 검사 후 1개월 내 유니패스에서 검사비용 환급을 신청할 수 있음.

### 검사에 자꾸 걸린다면

수출입신고 **오류점수**가 누적되면 검사 선별 확률이 올라감. "왜 내 화물만 검사에 걸리냐"의 실제 원인이 대개 이것. 신고 정정을 반복하지 않는 것이 결국 통관 속도로 돌아옴.

## 6. 수출신고필증 수령 — 그리고 한 번 더

### 적재 전 / 적재 후

| 시점 | 명칭 |
|---|---|
| 적재 전 | 수출신고필증 **(적재전)** |
| 적재 후 | 수출신고필증 **(수출이행)** |

유니패스에서 여러 번 출력할 수 있고, 출력 시점에 따라 제목이 바뀜.

### 적재기한 30일

수출신고 **수리일부터 30일 이내에 적재**해야 함. `[검증]` 기한은 수출면장 하단에 기재되어 있음.

기한 내 적재가 어려우면 **적재기간 연장신청**. 선박 수배 실패나 출항 지연 시 반드시 관세사에게 연락할 것.

### 적재했는데 미선적으로 뜨는 경우

가장 흔한 사고. 실제로 실었는데 유니패스에 미적재로 남아 과태료가 나옴.

원인 — 대부분 **신고중량과 실제중량의 과도한 차이**로 선적 처리가 매칭되지 않음.

대응 — **B/L 또는 AWB 를 받았다면 관세사에게 적재 처리된 면장을 다시 요청할 것.** 관세사 전용 프로그램에서 미선적 건을 별도 관리하므로 통상 먼저 연락이 오지만, 수출자도 확인하는 편이 안전함.

## 7. 수출신고필증 확인 포인트

관세사도 사람이라 실수함. **수출자가 송장/포장명세서 내용이 면장에 정확히 반영되었는지 대조**해야 함.

| # | 확인 항목 |
|---|---|
| 01 | 수출대행자/수출화주 상호와 통관고유부호 |
| 02 | 구매자 상호와 해외거래처부호 |
| 03 | 품명/규격/수량 — 송장과 일치 |
| 04 | 결제금액/통화 — 송장과 일치 |
| 05 | 결제방법 코드 (T/T = `TT`, 일람출급 L/C = `LS`, 기한부 L/C = `LU`) |
| 06 | 목적국 |
| 07 | 적재항 / 적재예정보세구역 |
| 08 | 물품소재지 |
| 09 | 제조자 (미상 처리되지 않았는지) |
| 10 | 적재기한 |

상세 항목별 해설과 코드표는 [부록 A — 수출신고필증 읽는 법](../docs/03_수출지식맵.md) 4장 참조.
