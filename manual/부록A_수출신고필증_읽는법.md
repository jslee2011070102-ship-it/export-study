# 부록 A. 수출신고필증 읽는 법

수출면장에는 57개 이상의 번호 항목이 있음. 그중 **수출자가 반드시 확인해야 하는 것**과 **코드값의 의미**를 정리.

서식 원본과 작성요령은 [forms/공식서식/수출통관/](../forms/공식서식/수출통관/) 에 보관 중.

| 자료 | 내용 |
|---|---|
| 별지 제1호서식 | 수출신고서 + **수출신고필증 8종**(적재전/수출이행 × 갑지/을지 × 국문/영문) |
| 별표 제1호 | **수출신고서 작성요령** — 항목별 TYPE/자릿수/필수여부/기재례 (35쪽) |

코드값 검증 상태.

| 항목 | 상태 |
|---|---|
| 거래구분 `15` 전자상거래 / `17` 전자상거래 풀필먼트 | **확인 완료** — 수출 및 반송통관에 관한 고시 제2조제15호 |
| 거래구분 `11` 일반형태 / 종류 `A` 일반수출 / 결제방법 `TT` 단순송금방식 / 신고구분 `H` 일반P/L신고 / 운송형태 `40` `ETC` | **확인 완료** — 실제 발급 필증에 명칭이 함께 인쇄됨 |
| 원산지 결정기준 / 표시여부 코드 | **확인 완료** — 별표 제1호 작성요령 |
| 인도조건 11개 | **확인 완료** — 별표 제1호 작성요령 (INCOTERMS 2020) |
| 그 밖의 코드표 (C/S구분 / 세관코드 / 수출종류 나머지) | `[검증]` 관세청 통계부호표 원문 대조 필요 |

---

## 1. 당사자 항목

| 항목 | 내용 |
|---|---|
| **신고자** | 신고서를 작성한 자. 대행 시 관세사, 자가통관 시 수출대행자 |
| **수출대행자** | 수출신고를 책임지는 당사자. 상호 + **통관고유부호** |
| **수출화주** | 실제 수출물품의 소유권자. 상호 + 통관고유부호 |
| **제조자** | 미상 처리 가능(`제조미상9999000`). 미상이면 **FTA C/O 발급 곤란 + 환급 제한** |
| **구매자** | 상업송장의 수입자. **해외거래처부호** 필요 |

### 수출자구분

| 코드 | 의미 |
|---|---|
| **A** | 수출대행자 = 제조자 (제조자/수출화주/수출대행자 동일) |
| B | 수출대행만 수행 (수출화주 ≠ 수출대행자) |
| **C** | 완제품을 공급받아 수출 (제조자 ≠ 수출화주) |
| D | 수출화주와 제조자가 본/지사 관계 |

이 구분은 통계 목적 외에 **수출실적 부여 / 내국신용장 / 구매확인서를 통한 간접수출 확인**에 사용됨.

## 2. 신고구분

| 코드 | 의미 |
|---|---|
| B | 보세구역반입후 신고 |
| E | 전자상거래 간이수출신고 |
| **H** | **Paperless 수출신고 — 관세사 신고의 99% 이상** |
| I | 제조후 Paperless 수출신고 |
| J | 세관장확인대상물품 신고 |
| K | 제조후 일반수출신고 |
| L | 출항후 수출신고 (선상신고) |
| M | 반송신고 |
| S | 송품장에 의한 간이통관 수출신고 |

## 3. 거래구분

| 코드 | 의미 |
|---|---|
| **11** | **일반형태 수출 — 대부분** |
| 15 | 전자상거래에 의한 수출물품 |
| **17** | **전자상거래 풀필먼트 수출** (아마존 FBA 등). 고시 제2조제15호에서 확인됨 |
| 31 | 위탁판매를 위한 물품의 수출 |
| 100 | 화폐 등 지급수단의 수출 |
| 102 | 수출인도장에서의 보세판매장 국산물품 수출 |

아마존 FBA 등으로 수출한다면 과거처럼 `15`/`31` 이 아니라 **`17`** 로 신고해야 함.

| 코드 | 의미 |

| **A** | **일반수출** |

| D | 자유무역지역으로부터 수출 |
| E | 종합보세구역으로부터 수출 |

| L | 선상신고 |
| P | 우편수출 (EMS 등) |

| 코드 | 의미 |
|---|---|
| **TT** | **단순송금방식 (T/T, M/T)** |
| CD | 사후 또는 동시 송금방식 (COD, CAD) |
| DA | D/A (인수인도) |
| DP | D/P (지급인도) |
| **LS** | 일람출급 L/C |

| GN | 무상 거래 |
| GO | 기타 유상 |
| PT | 임가공 지급방식의 위탁(수탁)가공무역 |
| WK | 계좌이체(상호계산방식) |

## 6. C/S 구분 (우범화물 자동선별)

| 코드 | 의미 |
|---|---|
| **A** | **수출검사생략 — 수출의 대부분** |
| B / T | 일반검사대상 (Central / Local C/S) |
| I / U | 정보에 의한 검사대상 (Central / Local C/S) |
| P | 서류제출대상 (반송신고 시 다수) |
| R | 무작위 추출 검사대상 |
| S | 서류제출 선별대상 |
| V | 화면심사대상 |
| W | 표준중량에 의한 검사대상 |
| **Y** | **최초수출에 의한 검사대상** |

첫 수출이 검사에 걸리기 쉬운 이유가 `Y` 코드.

## 7. 운송형태

| 구분 | 코드 |
|---|---|
| 운송수단 | `10` 선박 / `20` 철도 / `30` 차량 / `40` 항공기 |
| 운송용기 | `FC` FCL 컨테이너 / `LC` LCL / `BU` 벌크 / `ETC` 기타 |

예 — 해상 LCL = `10LC`, 항공 = `40ETC`.

## 8. 환율과 금액 구조

환율이 **항상 2개** 표기됨.

| 위치 | 내용 |
|---|---|
| 위 | 수출신고 시점의 **USD 환율** |
| 아래 | 실제 **결제통화 환율** |

금액은 3단 구조.

```
결제통화 금액  →  FOB USD 환산  →  원화
```

신고 시에는 **결제통화 금액만 입력**하면 나머지는 유니패스가 자동 계산. CIF 조건이면 운임/보험료를 입력해 FOB 로 공제.

예 — 송장금액이 `CIF CNY 1,442,478.22` 라면, 결제금액에 CNY 금액을 넣고 운임/보험료를 입력하면 FOB USD 와 원화가 자동 산출됨.

### 결제금액란의 3단 구조

`49 결제금액` 은 한 칸이 아니라 **3개 값이 하이픈으로 붙은 것**.

```
EXW - KRW - 1,124,200.00
 │     │        └── 실제 결제금액
 │     └─────────── 통화종류 (통계부호표)
 └───────────────── 인도조건 (INCOTERMS 2020 코드)
```

**인도조건은 11개 규칙만 사용 가능** — `EXW / FAS / FCA / FOB / CFR / CIF / CPT / CIP / DAP / DPU / DDP`. 작성요령에 "INCOTERMS 2020 코드 이외에는 환산하여 기재"로 명시돼 있어, 2010년의 `DAT` 나 임의 표기는 신고 자체가 안 됨.

### 신고가격(FOB) 환산 예시

작성요령의 기재례.

| 항목 | 값 |
|---|---|
| 결제금액 | CIF 10,000 |
| 운임 | 1,000원 |
| 보험료 | 500원 |
| **신고가격(FOB)** | **8,500원** |

즉 CIF/CFR/CIP/CPT 로 계약했다면 **운임과 보험료 금액을 관세사에게 원화로 알려줘야** 신고가 진행됨. 안 주면 신고가 멈춤.

### 원산지란의 구조

`41 원산지` 도 여러 값이 붙은 형태 (예: `KR---Y`).

| 하위 항목 | 코드 |
|---|---|
| 국가부호 | ISO 2자리 (`KR`) |
| **결정기준** | `A` 완전생산 / `B` 부가가치(직접생산비) / `C` 부가가치(타국원재료비공제) / `D` 가공공정 / `E` 조합 / `2` `4` `6` 세번변경(HS 2·4·6단위) / `8` HS 6단위에서 세분 |
| **표시여부** | `Y` 현품 및 포장에 표시 / `B` 포장에만 / `G` 현품에만 / `N` 미표시 |

원산지 표시 위반은 대외무역법 제33조 제재 대상이므로 `N` 으로 신고돼 있으면 표시면제 사유가 맞는지 확인할 것.

## 9. 보세구역 / 세관 코드

적재예정보세구역 코드의 **앞 3자리가 세관코드**.

| 코드 | 세관 |
|---|---|
| 010 | 서울 |
| 020 | 인천 |
| 030 | 부산 |
| 050 | 마산 |
| 070 | 목포 |
| 090 | 제주 |

보세구역을 알 수 없는 경우 `세관코드 + 99999` 로 기재됨.

## 10. 대개 비어 있는 항목

선박회사(항공사) / 선박명(항공편명) / 출항예정일자는 **필수기재사항이 아님**. 수출은 신고 후에 운송계약을 맺으므로 대부분 공란.

예외는 **선상신고(`L`)**. 먼저 싣고 나중에 신고하는 경우라 정보가 채워질 수 있음.

## 11. 수출자 확인 10항목

| # | 항목 |
|---|---|
| 01 | 수출대행자/수출화주 상호와 통관고유부호 |
| 02 | 구매자 상호와 해외거래처부호 |
| 03 | 품명/규격/수량 — 송장과 일치 |
| 04 | 결제금액/통화 — 송장과 일치 |
| 05 | 결제방법 코드 |
| 06 | 목적국 |
| 07 | 적재항 / 적재예정보세구역 |
| 08 | 물품소재지 |
| 09 | 제조자 (미상 처리되지 않았는지) |
| 10 | **적재기한** |

관세사도 사람이라 실수함. **송장/포장명세서 내용이 면장에 정확히 반영되었는지 수출자가 크로스체크**할 것.

`automation/parse_declaration.py` 가 이 대조를 자동으로 함 — 필증 PDF 와 상업송장 데이터를 넣으면 인도조건/통화/송품장번호/결제금액/총중량/세번을 맞춰 봄.

## 12. 적재의무기한 — 수리일 + 30일이 아님

`55 적재의무기한` 은 유니패스가 자동 계산해 찍는 값. 계산식이 단순 덧셈이 아님.

| 근거 | 내용 |
|---|---|
| 관세법 제251조제1항 | 수리일부터 **30일 이내** 적재 |
| 관세법 제8조제2항 | 기간 계산은 **「민법」에 따름** |
| **관세법 제8조제3항** | 기한이 **토요일 / 일요일 / 공휴일 / 대체공휴일 / 노동절**이면 **그 다음 날**이 기한 |

실제 필증 예.

| 항목 | 값 |
|---|---|
| 신고수리일자 | 2025/01/09 (목) |
| 단순 +30일 | 2025/02/08 **(토)** |
| 순연 | 토 → 일 → **2025/02/10 (월)** |
| 필증 표기 | **2025/02/10** |

30일째가 토·일이면 그것만으로 2일이 밀리고, 설/추석 연휴에 걸리면 더 밀림. **직접 날짜를 세지 말고 필증에 인쇄된 값을 그대로 볼 것.**

반대로 이 순연을 믿고 여유를 잡으면 안 됨 — 연장은 **기한이 지나기 전에만** 신청 가능하고, 지나면 과태료 + 수리 취소 대상. 상세는 [13. 사후관리](13_사후관리.md).
