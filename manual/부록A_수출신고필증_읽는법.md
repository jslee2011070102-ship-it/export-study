# 부록 A. 수출신고필증 읽는 법

수출면장에는 57개 이상의 번호 항목이 있음. 그중 **수출자가 반드시 확인해야 하는 것**과 **코드값의 의미**를 정리.

서식 원본과 작성요령은 [forms/공식서식/수출통관/](../forms/공식서식/수출통관/) 에 보관 중.

| 자료 | 내용 |
|---|---|
| 별지 제1호서식 | 수출신고서 + **수출신고필증 8종**(적재전/수출이행 × 갑지/을지 × 국문/영문) |
| 별표 제1호 | **수출신고서 작성요령** — 항목별 TYPE/자릿수/필수여부/기재례 (35쪽) |

코드값 검증 상태 — **관세법령정보포털 CLIP 통계부호(운영 코드표)로 대조 완료.**

| 항목 | 상태 |
|---|---|
| 거래구분 / 신고구분 / 수출종류 / 결제방법 / 운송형태 / 포장종류 / 중량/수량단위 / 원산지 결정기준/표시방법/표시면제사유 / 환급신청인/환급종류 / 반송사유 / 신고정정/취하/각하사유 / 처리상태 / 세관구분 / 세관장확인대상법령 / 징수형태 | **확인 완료** — 전체 코드값은 [data/통계부호_수출신고.csv](../data/통계부호_수출신고.csv) |
| 가격조건(인도조건) | **확인 완료. 단 고시 별표1 과 불일치** — 아래 8장 참조 |
| 원산지 결정기준 `B`/`C`/`8` | **`[검증]` — 고시 별표1 과 뜻이 어긋남.** 아래 표에 병기 |
| **C/S 구분** | **`[검증]`** — 별도 코드군으로 공개돼 있지 않음. 아래 표는 채널 자료 기준 |
| **세관 코드** (010 서울 등) | **`[검증]`** — CLIP 의 `세관구분코드` 는 본청/본부세관/일선세관 등 **기관 유형** 구분이라 다른 값 |

## 1. 당사자 항목

| 항목 | 내용 |
|---|---|
| **신고자** | 신고서를 작성한 자. 대행 시 관세사, 자가통관 시 수출대행자 |
| **수출대행자** | 수출신고를 책임지는 당사자. 상호 + **통관고유부호** |
| **수출화주** | 실제 수출물품의 소유권자. 상호 + 통관고유부호 |
| **제조자** | 미상 처리 가능(`제조미상9999000`). 미상이면 **FTA C/O 발급 곤란 + 환급 제한** |
| **구매자** | 상업송장의 수입자. **해외거래처부호** 필요 |

### 수출자구분

| 코드 | 의미 |
|---|---|
| **A** | 수출대행자 = 제조자 (제조자/수출화주/수출대행자 동일) |
| B | 수출대행만 수행 (수출화주 ≠ 수출대행자) |
| **C** | 완제품을 공급받아 수출 (제조자 ≠ 수출화주) |
| D | 수출화주와 제조자가 본/지사 관계 |

이 구분은 통계 목적 외에 **수출실적 부여 / 내국신용장 / 구매확인서를 통한 간접수출 확인**에 사용됨.

## 8. 환율과 금액 구조

환율이 **항상 2개** 표기됨.

| 위치 | 내용 |
|---|---|
| 위 | 수출신고 시점의 **USD 환율** |
| 아래 | 실제 **결제통화 환율** |

금액은 3단 구조.

```
결제통화 금액  →  FOB USD 환산  →  원화
```

신고 시에는 **결제통화 금액만 입력**하면 나머지는 유니패스가 자동 계산. CIF 조건이면 운임/보험료를 입력해 FOB 로 공제.

예 — 송장금액이 `CIF CNY 1,442,478.22` 라면, 결제금액에 CNY 금액을 넣고 운임/보험료를 입력하면 FOB USD 와 원화가 자동 산출됨.

### 결제금액란의 3단 구조

`49 결제금액` 은 한 칸이 아니라 **3개 값이 하이픈으로 붙은 것**.

```
EXW - KRW - 1,124,200.00
 │     │        └── 실제 결제금액
 │     └─────────── 통화종류 (통계부호표)
 └───────────────── 인도조건 (INCOTERMS 2020 코드)
```

**인도조건은 11개 규칙만 사용 가능** — `EXW / FAS / FCA / FOB / CFR / CIF / CPT / CIP / DAP / DPU / DDP`. 작성요령에 "INCOTERMS 2020 코드 이외에는 환산하여 기재"로 명시돼 있음.

#### 관세청 자료 두 개가 어긋남 `[검증]`

| 출처 | 내용 |
|---|---|
| **고시 별표1 작성요령** (시행 2026-06-26) | EXW, FAS, FCA, FOB, CFR, CIF, CPT, CIP, DAP, **DPU**, DDP — 11개 |
| **CLIP 통계부호 `가격조건코드`** (운영 코드표) | 17종. **DPU 없음.** 폐지 조건이 그대로 남아 있음 |

통계부호표의 17종 —

| 부호 | 조건 | 인코텀즈 2020 |
|---|---|---|
| 11 / 12 / 13 | FOB / C&F(CFR) / CIF | O |
| 15 / 16 / 17 | EXW / FAS / FCA | O |
| 18 / 19 | CPT / CIP | O |
| 23 / 26 | DDP / DAP | O |
| **14** | **C&I** | **X — 인코텀즈 규칙 아님** |
| **20 / 21 / 22** | **DES / DEQ / DAF** | **X — 2000년판, 2010에서 폐지** |
| **24** | **DDU** | **X — 2010에서 DAP 로 대체** |
| **25** | **DAT** | **X — 2020에서 DPU 로 대체** |
| 99 | 기타 | - |

해석 —

- 필증 실물에는 숫자가 아니라 **알파벳 코드**가 찍힘 (`EXW-KRW-1,124,200.00`). 이 숫자 코드표는 다른 용도(수입 가격신고 등)의 레거시일 가능성이 큼
- 법적 근거는 **고시 별표1** 이므로 실무에서는 **11개 규칙만 쓸 것**
- 다만 통계부호표가 갱신되지 않아 시스템에서 `DPU` 가 거부될 소지가 있음. **DPU 로 계약한 건이 처음이면 관세사에게 신고 가능 여부를 먼저 확인**할 것

### 신고가격(FOB) 환산 예시

작성요령의 기재례.

| 항목 | 값 |
|---|---|
| 결제금액 | CIF 10,000 |
| 운임 | 1,000원 |
| 보험료 | 500원 |
| **신고가격(FOB)** | **8,500원** |

즉 CIF/CFR/CIP/CPT 로 계약했다면 **운임과 보험료 금액을 관세사에게 원화로 알려줘야** 신고가 진행됨. 안 주면 신고가 멈춤.

### 원산지란의 구조

`41 원산지` 는 **4개 값이 하이픈으로 붙은 것**. 실물 예 `KR---Y` 는 하이픈이 3개이므로 아래 4칸에 정확히 대응.

```
KR - (공란) - (공란) - Y
│      │        │      └── 원산지증명서 유무
│      │        └───────── 표시여부
│      └────────────────── 결정기준
└───────────────────────── 국가부호 (ISO 2자리)
```

**결정기준** — 통계부호표 12종. 별표1 작성요령과 **뜻이 어긋나는 항목이 있음** `[검증]`

| 코드 | 통계부호표 (운영) | 별표1 작성요령 |
|---|---|---|
| A | 완전생산기준 | 완전생산기준 |
| **B** | **부가가치기준(타국원재료비 공제)** | **부가가치기준(직접생산비기준)** |
| **C** | **부가가치기준(직접생산비)** | **부가가치기준(타국원재료비공제기준)** |
| D / E | 가공공정기준 / 조합기준 | 가공공정기준 / 조합기준 |
| 2 / 4 / 6 | HS 2 / 4 / 6단위변경 | 세번변경기준 (HS 2 / 4 / 6단위) |
| **8** | **HS 8단위변경** | **HS 6단위에서 세분** |
| F / G / H | 주요부분품의 단순 결합물품 / 원재료의 단순 혼합물품 / 중고물품 | (없음) |

`B` 와 `C` 가 서로 뒤바뀌어 있고 `8` 의 뜻도 다름. **부가가치기준으로 신고할 때는 관세사에게 코드값을 확인**할 것.

**표시여부** — `Y` 현품 및 포장에 표시 / `B` 포장에만 / `G` 현품에만 / `N` 미표시

원산지 표시 위반은 대외무역법 제33조 제재 대상이므로 `N` 으로 신고돼 있으면 표시면제 사유가 맞는지 확인할 것. 면제사유는 16종 (`01` 외화획득용 원료/시설기재, `06` 견본품 및 하자보수용, `09` 우리나라에서 수출된 후 재수입, `12` 반입 없이 외국으로 반송 등).

**원산지증명서 유무** — 5종

| 코드 | 의미 |
|---|---|
| **Y** | **원산지증명서를 구비한 경우** |
| N | 세관장 확인대상이 아니거나 원산지증명서를 구비하지 못한 경우 |
| A / B | 사전제출 대상 / 사후제출 대상 |
| X | 제출면제 대상 |

**표시방법**은 별도 코드 8종 (`A` 각인 / `B` 실크인쇄 / `C` 직물제라벨 / `D` 지제라벨/스티커 / `E` 주형조각 / `F` 택 부착 / `G` 최소포장상 인쇄/스티커 / `Z` 기타).

## 10. 대개 비어 있는 항목

선박회사(항공사) / 선박명(항공편명) / 출항예정일자는 **필수기재사항이 아님**. 수출은 신고 후에 운송계약을 맺으므로 대부분 공란.

예외는 **선상신고(`L`)**. 먼저 싣고 나중에 신고하는 경우라 정보가 채워질 수 있음.

## 11. 수출자 확인 10항목

| # | 항목 |
|---|---|
| 01 | 수출대행자/수출화주 상호와 통관고유부호 |
| 02 | 구매자 상호와 해외거래처부호 |
| 03 | 품명/규격/수량 — 송장과 일치 |
| 04 | 결제금액/통화 — 송장과 일치 |
| 05 | 결제방법 코드 |
| 06 | 목적국 |
| 07 | 적재항 / 적재예정보세구역 |
| 08 | 물품소재지 |
| 09 | 제조자 (미상 처리되지 않았는지) |
| 10 | **적재기한** |

관세사도 사람이라 실수함. **송장/포장명세서 내용이 면장에 정확히 반영되었는지 수출자가 크로스체크**할 것.

`automation/parse_declaration.py` 가 이 대조를 자동으로 함 — 필증 PDF 와 상업송장 데이터를 넣으면 인도조건/통화/송품장번호/결제금액/총중량/세번을 맞춰 봄.

## 12. 적재의무기한 — 수리일 + 30일이 아님

`55 적재의무기한` 은 유니패스가 자동 계산해 찍는 값. 계산식이 단순 덧셈이 아님.

| 근거 | 내용 |
|---|---|
| 관세법 제251조제1항 | 수리일부터 **30일 이내** 적재 |
| 관세법 제8조제2항 | 기간 계산은 **「민법」에 따름** |
| **관세법 제8조제3항** | 기한이 **토요일 / 일요일 / 공휴일 / 대체공휴일 / 노동절**이면 **그 다음 날**이 기한 |

실제 필증 예.

| 항목 | 값 |
|---|---|
| 신고수리일자 | 2025/01/09 (목) |
| 단순 +30일 | 2025/02/08 **(토)** |
| 순연 | 토 → 일 → **2025/02/10 (월)** |
| 필증 표기 | **2025/02/10** |

30일째가 토/일이면 그것만으로 2일이 밀리고, 설/추석 연휴에 걸리면 더 밀림. **직접 날짜를 세지 말고 필증에 인쇄된 값을 그대로 볼 것.**

반대로 이 순연을 믿고 여유를 잡으면 안 됨 — 연장은 **기한이 지나기 전에만** 신청 가능하고, 지나면 과태료 + 수리 취소 대상. 상세는 [13. 사후관리](13_사후관리.md).
