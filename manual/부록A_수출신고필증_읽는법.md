# 부록 A. 수출신고필증 읽는 법

수출면장에는 57개 이상의 번호 항목이 있음. 그중 **수출자가 반드시 확인해야 하는 것**과 **코드값의 의미**를 정리.

`[검증]` 코드값은 채널 게시 시점 기준. 확정 전 관세청 고시 대조 필요.

---

## 1. 당사자 항목

| 항목 | 내용 |
|---|---|
| **신고자** | 신고서를 작성한 자. 대행 시 관세사, 자가통관 시 수출대행자 |
| **수출대행자** | 수출신고를 책임지는 당사자. 상호 + **통관고유부호** |
| **수출화주** | 실제 수출물품의 소유권자. 상호 + 통관고유부호 |
| **제조자** | 미상 처리 가능(`제조미상9999000`). 미상이면 **FTA C/O 발급 곤란 + 환급 제한** |
| **구매자** | 상업송장의 수입자. **해외거래처부호** 필요 |

### 수출자구분

| 코드 | 의미 |
|---|---|
| **A** | 수출대행자 = 제조자 (제조자/수출화주/수출대행자 동일) |
| B | 수출대행만 수행 (수출화주 ≠ 수출대행자) |
| **C** | 완제품을 공급받아 수출 (제조자 ≠ 수출화주) |
| D | 수출화주와 제조자가 본/지사 관계 |

이 구분은 통계 목적 외에 **수출실적 부여 / 내국신용장 / 구매확인서를 통한 간접수출 확인**에 사용됨.

## 2. 신고구분

| 코드 | 의미 |
|---|---|
| B | 보세구역반입후 신고 |
| E | 전자상거래 간이수출신고 |
| **H** | **Paperless 수출신고 — 관세사 신고의 99% 이상** |
| I | 제조후 Paperless 수출신고 |
| J | 세관장확인대상물품 신고 |
| K | 제조후 일반수출신고 |
| L | 출항후 수출신고 (선상신고) |
| M | 반송신고 |
| S | 송품장에 의한 간이통관 수출신고 |

## 3. 거래구분

| 코드 | 의미 |
|---|---|
| **11** | **일반형태 수출 — 대부분** |
| 15 | 전자상거래에 의한 수출물품 |
| **17** | **전자상거래 풀필먼트 수출** (2021년 신설. 아마존 FBA 등) |
| 31 | 위탁판매를 위한 물품의 수출 |
| 100 | 화폐 등 지급수단의 수출 |
| 102 | 수출인도장에서의 보세판매장 국산물품 수출 |

아마존 FBA 등으로 수출한다면 과거처럼 `15`/`31` 이 아니라 **`17`** 로 신고해야 함.

| 코드 | 의미 |

| D | 자유무역지역으로부터 수출 |

| L | 선상신고 |

| 코드 | 의미 |
|---|---|
| **TT** | **단순송금방식 (T/T, M/T)** |
| CD | 사후 또는 동시 송금방식 (COD, CAD) |
| DA | D/A (인수인도) |
| DP | D/P (지급인도) |

| **LU** | 기한부 L/C |
| LH | 분할영수(지급)방식 |
| GN | 무상 거래 |
| GO | 기타 유상 |
| PT | 임가공 지급방식의 위탁(수탁)가공무역 |

## 6. C/S 구분 (우범화물 자동선별)

| 코드 | 의미 |
|---|---|
| **A** | **수출검사생략 — 수출의 대부분** |
| B / T | 일반검사대상 (Central / Local C/S) |
| I / U | 정보에 의한 검사대상 (Central / Local C/S) |
| P | 서류제출대상 (반송신고 시 다수) |
| R | 무작위 추출 검사대상 |
| S | 서류제출 선별대상 |
| V | 화면심사대상 |
| W | 표준중량에 의한 검사대상 |
| **Y** | **최초수출에 의한 검사대상** |

첫 수출이 검사에 걸리기 쉬운 이유가 `Y` 코드.

## 7. 운송형태

| 구분 | 코드 |
|---|---|
| 운송수단 | `10` 선박 / `20` 철도 / `30` 차량 / `40` 항공기 |
| 운송용기 | `FC` FCL 컨테이너 / `LC` LCL / `BU` 벌크 / `ETC` 기타 |

예 — 해상 LCL = `10LC`, 항공 = `40ETC`.

## 8. 환율과 금액 구조

환율이 **항상 2개** 표기됨.

| 위치 | 내용 |
|---|---|
| 위 | 수출신고 시점의 **USD 환율** |
| 아래 | 실제 **결제통화 환율** |

금액은 3단 구조.

```
결제통화 금액  →  FOB USD 환산  →  원화
```

신고 시에는 **결제통화 금액만 입력**하면 나머지는 유니패스가 자동 계산. CIF 조건이면 운임/보험료를 입력해 FOB 로 공제.

예 — 송장금액이 `CIF CNY 1,442,478.22` 라면, 결제금액에 CNY 금액을 넣고 운임/보험료를 입력하면 FOB USD 와 원화가 자동 산출됨.

## 9. 보세구역 / 세관 코드

적재예정보세구역 코드의 **앞 3자리가 세관코드**.

| 코드 | 세관 |
|---|---|
| 010 | 서울 |
| 020 | 인천 |
| 030 | 부산 |
| 050 | 마산 |
| 070 | 목포 |
| 090 | 제주 |

보세구역을 알 수 없는 경우 `세관코드 + 99999` 로 기재됨.

## 10. 대개 비어 있는 항목

선박회사(항공사) / 선박명(항공편명) / 출항예정일자는 **필수기재사항이 아님**. 수출은 신고 후에 운송계약을 맺으므로 대부분 공란.

예외는 **선상신고(`L`)**. 먼저 싣고 나중에 신고하는 경우라 정보가 채워질 수 있음.

## 11. 수출자 확인 10항목

| # | 항목 |
|---|---|
| 01 | 수출대행자/수출화주 상호와 통관고유부호 |
| 02 | 구매자 상호와 해외거래처부호 |
| 03 | 품명/규격/수량 — 송장과 일치 |
| 04 | 결제금액/통화 — 송장과 일치 |
| 05 | 결제방법 코드 |
| 06 | 목적국 |
| 07 | 적재항 / 적재예정보세구역 |
| 08 | 물품소재지 |
| 09 | 제조자 (미상 처리되지 않았는지) |
| 10 | **적재기한** |

관세사도 사람이라 실수함. **송장/포장명세서 내용이 면장에 정확히 반영되었는지 수출자가 크로스체크**할 것.
