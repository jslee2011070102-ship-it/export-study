# 수출설명서 (초안 v0.2)


**한 페이지로 읽기** — [docs/수출설명서.html](../docs/수출설명서.html). 목차/검색/현재위치 추적이 붙은 읽기용. `python3 scripts/build_manual_html.py` 로 다시 생성.

**14개 장 + 부록 4종 초안 완료.** 다음 단계는 `[검증]` 항목 1차 출처 대조.

수출 경험 0~2건인 사람이 **첫 수출 1건을 스스로 끝낼 수 있게 하는 것**이 목표.

## 집필 원칙

| # | 원칙 |
|---|---|
| 01 | 순서대로 따라 하면 끝나는 구조. 이론은 필요한 지점에서만 |
| 02 | 각 장 첫머리에 "이 장이 끝나면 무엇이 손에 남는가"를 명시 |
| 03 | 수출자가 **직접 해야 하는 일**과 **관세사/포워더에게 넘기는 일**을 항상 구분 |
| 04 | 금액/기한/코드는 1차 출처(법령 원문, 관세청 고시, FTA 포털) 대조 후 확정. 미검증 항목은 본문에 `[검증]` 표시 |
| 05 | 문체는 개조식으로 통일 |
