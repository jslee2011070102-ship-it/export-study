# 07. HS코드 확정과 수출요건 확인

이 장이 끝나면 — 내 물품의 **HS 코드**와 **수출 가능 여부**를 알게 됨. 이 두 가지가 확정돼야 신고도 원산지증명도 가능.

---

## 1. HS CODE 란

수출입 물품에 부여되는 **국제적으로 통일된 6자리 번호**.

사람에게 주민등록번호가 있듯 물품에는 HS 코드가 있음. 같은 물건을 `playstation`, `PS4`, `video game console` 어떻게 부르든 코드는 `9504.50` 하나.

### 자리수 구조

| 자리 | 명칭 | 예 (노트북 `8471.30`) |
|---|---|---|
| 2자리 | **류** | `84` |
| 4자리 | **호** | `8471` |
| 6자리 | **소호** | `8471.30` |

**6자리까지가 국제 표준.** 그 뒤는 나라마다 다름. 우리나라는 통계 목적으로 총 10자리를 쓰고 이를 **HSK** 라 함. 8자리를 쓰는 나라, 9자리를 쓰는 나라 등 다양.

### HS 코드로 알 수 있는 것

| 항목 | 내용 |
|---|---|
| 관세율 | 기본세율 / WTO 협정세율 / FTA 협정세율 |
| **수출입 요건** | 수출입공고 / 통합공고 해당 여부 |
| 원산지표시 | 표시 대상인지 |
| **FTA 원산지결정기준** | 협정별 기준 |

즉 HS 코드가 정해지지 않으면 **아무것도 확정되지 않음**.

## 2. 직접 찾아보는 방법

전문 분류는 관세사에게 맡기는 것이 맞지만, 대략의 위치는 스스로 확인할 수 있어야 함.

### 사이트

**관세법령정보포털** (관세청). 무료. 상단 메뉴 `세계HS` → `속견표`.

### 순서

```
1단계  속견표에서 2자리 "류" 찾기
        01 산동물 / 02 고기 / 03 생선 ... 95 완구/운동용구 / 97 예술품/골동품
        → 게임기는 95류로 감이 잡힘

2단계  4자리 "호" 찾기
        해당 류의 호 목록을 하나씩 읽어야 함
        95류는 9501~9508 로 8개뿐이라 쉬움
        84류(기계)는 8401~8487 로 87개라 노가다
        → 게임기는 9504호 (비디오게임 콘솔/오락용구/테이블게임용구)

3단계  6자리 "소호" 찾기
        → 9504.50 (TV에 연결하는 비디오게임기)

4단계  국내 10자리(HSK) 확인
```

현직자에게 암기는 불필요. **내 물품의 2자리 류만 찾을 수 있으면 됨.**

### 관세사에게 맡길 때

품명을 정확히 알려주는 것이 전부. 상업송장의 품명이 `PARTS` 처럼 모호하면 분류가 불가능함. **재질/용도/형태**가 드러나게 쓸 것.

## 3. 상대국 관세율 확인

내가 수출하는 물품에 상대국이 얼마의 관세를 매기는지는 바이어와의 가격 협상에 직결됨.

| 확인할 것 | 어디서 |
|---|---|
| 상대국 기본세율 / 협정세율 | **관세청 FTA 포털** |
| FTA 협정문 및 양허 스케줄 | FTA 포털 |
| 원산지결정기준 | FTA 포털 → 협정별 원산지결정기준 |

관세사에게 물어보기 전에 스스로 1분이면 확인 가능한 정보. 상세는 [09장](09_원산지증명서와_FTA.md).

## 4. 수출 가능한 물품인가 — 무역 3법

무역에 실제로 적용되는 법은 세 개.

| 법 | 규율 대상 |
|---|---|
| **관세법** | 수출입 통관절차, 관세/내국세 |
| **대외무역법** | 무역 전반. **수출입 제한** |
| **외국환거래법** | 수출 시 외화 입금, 수입 시 외화 출금 등 자본 이동 |

수출 가능 여부를 정하는 것은 **대외무역법**.

## 5. 수출입공고와 통합공고

대외무역법이 수출입을 제한하는 방식은 두 가지.

| 구분 | 내용 | 실무 빈도 |
|---|---|---|
| **수출입공고** | **대외무역법 자체**가 정하는 제한 | 걸리는 경우가 많지 않음 |
| **통합공고** | 대외무역법 **이외의 모든 법**이 정하는 수출입 요건을 통합해 공고 | **거의 예외 없이 걸림** |

우리나라는 IMF 이후 무역자유화가 선언되어, **열거된 품목이 아니면 자유롭게 수출입 가능**.

### 수출입공고의 구조

| 별표 | 내용 | 효과 |
|---|---|---|
| 별표 1 | **수출금지품목** | 어떤 경우에도 수출 불가 |
| 별표 2 | **수출제한품목** | 품목별 수출요령에 따라 **승인**을 받으면 수출 가능 |
| 별표 3 | 수입제한품목 | 승인 시 수입 가능 |

수입금지품목은 열거하지 않음. WTO 무역자유화 원칙과 배치되기 때문.

제한 판단 기준은 **HS CODE 6자리**.

### 통합공고

식품위생법, 약사법, 전기용품안전관리법, 전파법, 화학물질관리법 등 **개별 법령이 정한 요건**을 대외무역법이 모아서 공고한 것.

수출보다는 수입에서 훨씬 자주 걸리지만, 수출도 품목에 따라 요건이 붙음. **요건이 있으면 요건확인기관의 승인/신고/검사를 먼저 받아야 신고가 수리됨.**

### 확인 방법

| 방법 | 내용 |
|---|---|
| 관세법령정보포털 | HS 코드 조회 시 세관장확인대상 요건 표시 |
| 유니패스 | 요건 확인 |
| 관세사 문의 | 가장 확실 |

## 6. 전략물자

`[보강 필요]` 군용/이중용도 물품은 별도의 **전략물자 수출허가**가 필요함. 채널에 콘텐츠가 없어 전략물자관리원(YesTrade) 자료로 별도 작성 예정. 기계/전자/화학 품목을 수출한다면 반드시 사전 확인할 것.
