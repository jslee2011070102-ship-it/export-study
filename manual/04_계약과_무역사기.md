# 04. 오퍼/계약과 무역사기 피하기

이 장이 끝나면 — **이 거래를 진행해도 되는지** 스스로 판정할 수 있게 됨.

수출에서 가장 큰 손실은 물건이 아니라 **대금 미회수**. 그리고 대부분의 사고는 계약 단계에서 이미 신호가 보임.

---

## 1. 계약이 성립되는 과정

| 단계 | 서류 | 작성자 |
|---|---|---|
| 문의 | Inquiry | 바이어 |
| **청약** | **Offer Sheet** | **수출자** |
| 승낙 | Purchase Order (P/O) | 바이어 |
| 확정 | Sales Contract / Proforma Invoice | 양측 |

Offer Sheet 에 반드시 들어가야 할 것.

| 항목 | 비고 |
|---|---|
| 품명 / 규격 / 수량 | HS 분류가 가능한 수준으로 |
| 단가 / 총액 / **통화** | |
| **가격조건 (인코텀즈 + 지정장소)** | `FOB BUSAN Incoterms® 2020` |
| **결제조건** | 선급 비율 포함해 구체적으로 |
| 선적 기한 | |
| 유효기간 (Validity) | 오퍼는 무기한이 아님 |
| 포장 방법 | |
| 원산지 / (필요 시) C/O 발급 여부 | |

## 2. 무역사기 판별 — 위험신호 3가지

채널이 10년 실무 경험으로 정리한 자가진단 기준.

### 신호 1 — 바이어가 먼저 신용장을 개설해 주겠다고 함

직관과 반대되지만 **의심 대상**.

이유 — 바이어 입장에서 신용장은 절차가 복잡하고 수수료도 비싸며 얻는 이익이 거의 없음. 그런데도 굳이 먼저 개설해 주겠다고 하면 다른 의도를 의심할 것.

**신용장은 돈을 안 주려고 작정하고도 개설할 수 있음.**

| 원칙 | 결과 |
|---|---|
| 물품 인도 | **매매계약**대로 이행 |
| 대금 결제 | **신용장 조건**대로 수취 |

이 둘이 완전히 분리되어 있음. 계약대로 정상 선적해도 신용장 조건에 맞는 서류를 못 내면 대금을 못 받음. 물건은 이미 넘어간 상태에서.

대응.

- 신용장 초안이 오면 **요구서류와 조건을 전부 검토**. 하나라도 충족 불가능한 항목이 있으면 위험
- 충족 불가능한 조건을 일부러 넣는 것을 **독소조항**이라 함
- 특히 **물품이 바이어에게 바로 넘어갈 수 있는 조건**(항공운송서류 매수인 기명식 등)이 포함되어 있으면 더욱 의심

### 신호 2 — 바이어가 FOB/FCA 만 고집함

FOB/FCA 는 **바이어가 포워더를 지정**하는 조건. 즉 **운송 주도권이 바이어에게 있음**.

문제 — 수출자는 그 운송인의 신용도를 확인할 방법이 없음. 실제 사고 유형.

- 포워더에게 물품을 넘겼는데, 포워더가 바이어에게 그대로 넘기고 폐업
- 공신력 없는 자가 항공기 등을 보내 물품만 받고 잠적

특히 위험한 멘트 — **"항공기가 없으면 군용기라도 띄울 테니 안심하고 생산만 하세요"** 류의 과장.

대응.

- 사기 여부가 애매하면 **CFR / CPT** 를 제안. 내가 국내의 공신력 있는 포워더를 쓰므로 물품 탈취 가능성이 크게 낮아짐
- 정당한 거래인데 FOB 만 고집하는 경우도 있으므로 거래 중단까지 갈 필요는 없음. 대신 **바이어가 지정한 포워더가 국제적으로 공신력이 있는지 확인**할 것

### 신호 3 — 현금 결제를 제안함

수입국 외국환거래법 사정으로 송금이 어려워 현금을 제시하는 정상 거래도 있음. 그러나 **자금 출처 불명, 외국환거래법 위반 소지**가 있으므로 그대로 수용하지 말 것.

우리 쪽 외국환거래법 신고 문제로도 번짐 → [12장](12_대금회수와_외국환거래법.md).

## 3. 계약 전 확인 체크리스트

| # | 항목 |
|---|---|
| 01 | 바이어 회사가 실재하는가 (사업자 정보, 홈페이지, 소재지) |
| 02 | 메일 도메인이 회사 도메인인가 (무료 메일 계정 주의) |
| 03 | 기존 거래처의 **계좌 변경 요청 메일**이 아닌가 (메일 해킹 사기 유형) |
| 04 | 요구 수량이 첫 거래치고 비정상적으로 크지 않은가 |
| 05 | 가격 협상을 거의 하지 않는가 (사기는 가격에 관심이 없음) |
| 06 | **선급금을 지불할 의사가 있는가** |
| 07 | 인코텀즈 조건에서 운송 주도권을 누가 갖는가 |
| 08 | (L/C) 충족 불가능한 조건이 없는가 |

**5번과 6번이 가장 강력한 필터.** 사기는 대개 가격을 깎지 않고, 선급금을 내지 않음.

## 4. 사고가 났을 때 — 분쟁 해결

| 방법 | 특징 |
|---|---|
| 협상 | 가장 빠르고 저렴 |
| **중재 (Arbitration)** | 국제거래의 표준. 단심제로 종결. 뉴욕협약에 따라 외국에서도 집행 가능 |
| 소송 | 상대국 법원. 시간/비용 부담이 큼 |

국제 거래에서 소송보다 중재가 선호되는 이유 — 각국 법원 판결은 외국에서 집행이 어렵지만, **중재 판정은 뉴욕협약 가입국 사이에서 집행이 가능**하기 때문.

계약서에 **중재조항**(중재기관/중재지/준거법)을 넣어두는 것이 실익. 대한상사중재원 표준중재조항을 참고할 것. `[검증]` 세부 절차는 대한상사중재원 자료로 보강 필요.

## 5. 위험신호가 겹치는 지점 — 전략물자

무역사기 신호와 **전략물자 상황허가 판단사유**는 상당 부분 겹침. 대외무역법 제19조의3이 열거한 13개 사유 중 아래는 사기 신호와 사실상 동일함.

| 사유 | 사기 신호로도 읽히는 이유 |
|---|---|
| 수입자가 **최종용도 정보 제공을 기피** | 실체 없는 거래일 수 있음 |
| **가격조건/지불조건이 통상 범위를 벗어남** | 가격을 깎지 않는 사기의 특징과 일치 |
| **납기일이 통상 기간을 벗어남** | |
| **수송경로가 통상 경로를 벗어남** | 우회 수출 가능성 |
| **최종수하인이 운송업자** | 실화주 은폐 |
| 정보/목적지에 **과도한 보안 요구** | |

**수상한 거래는 사기이거나 전략물자 문제이거나 둘 다일 수 있음.** 전체 목록과 처벌 수위는 [07장](07_HS코드와_수출요건.md) 6절 참조.

## 6. 사후 대비 — 신용조사와 무역보험

계약 단계에서 판단이 서지 않으면 **한국무역보험공사(K-SURE)의 신용조사**로 상대 신용도를 확인할 수 있고, 사후송금 비중이 남으면 **무역보험**으로 미회수 위험을 이전할 수 있음.

상세는 [14장 무역보험](14_무역보험.md).
