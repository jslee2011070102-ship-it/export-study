# 06. 상업송장과 포장명세서 작성

이 장이 끝나면 — **상업송장(C/I)** 과 **포장명세서(P/L)** 가 손에 남음. 수출신고에 필요한 서류는 원칙적으로 이 둘이 전부.

이 장은 수출자가 **직접** 해야 하는 유일한 문서 작업. 그리고 이후 모든 서류가 여기서 파생되므로 가장 중요한 장.

---

## 1. 두 서류의 관계

| 항목 | 상업송장 (Commercial Invoice, C/I) | 포장명세서 (Packing List, P/L) |
|---|---|---|
| 성격 | **거래 명세서** | **포장 명세서** |
| 핵심 정보 | 단가 / 총금액 | 순중량 / 총중량 / 포장 방법 |
| 작성 시점 | 매매계약 확정 직후 | 수출 포장 완료 후 |
| 법정 양식 | **없음** | **없음** |

서식은 **90% 이상 동일**. 다른 점은 딱 하나 — **송장에는 금액이, 포장명세서에는 중량이 들어감.**

### 왜 나누는가

원래 순서가 그렇기 때문. "이런 조건으로 보내겠다"(송장) 가 먼저 나오고, "이렇게 포장해서 보냈다"(포장명세서) 가 나중에 나옴. 국내 온라인 주문에서 주문내역이 먼저 뜨고 배송 정보가 나중에 뜨는 것과 같은 구조.

부수 효과 — 가격 정보를 노출하고 싶지 않은 상대에게는 포장명세서만 전달할 수 있음.

실무에서는 **엑셀 양식 하나에서 두 서류가 동시에 완성되도록** 만들어 쓰는 경우가 대부분. 사실상 세트로 움직임.

## 2. 상업송장에 들어가는 것

법정 양식이 없으므로 회사 양식을 쓰거나 인터넷에서 받아 써도 됨. 다만 아래 정보는 빠지면 안 됨.

| 구분 | 항목 |
|---|---|
| 당사자 | Shipper/Exporter (수출자 상호/주소) / Consignee (수입자 상호/주소) / Notify Party |
| 거래 식별 | Invoice No. / Invoice Date / 계약번호 또는 P/O No. |
| 운송 | 출발지 / 목적지 / (아는 경우) 선박명/항차 |
| 조건 | **가격조건(인코텀즈 + 지정장소)** / **결제조건(T/T, L/C 등)** / 결제통화 |
| 물품 | 품명 / 규격 / 수량 / 단위 / **단가** / **금액** / 합계 |
| 원산지 | Country of Origin |
| 서명 | 수출자 서명 |

### 얼마나 상세하게 쓸 것인가

이 판단이 핵심. 채널이 제시하는 기준은 하나.

> **관세사가 수출통관을 할 수 있을 만큼만 정확히 적는다.**

- 너무 상세 → 불필요한 정보까지 상대방과 세관에 노출됨
- 너무 약식 → 관세사가 HS 분류를 못 해 통관이 지연됨

품명은 특히 중요. **HS 코드 분류의 근거**가 되므로 재질/용도/형태가 드러나야 함. `PARTS` 같은 표기는 분류 불가.

### 가격조건 표기가 뒤에 미치는 영향

송장의 가격조건(인코텀즈)은 단순 표기가 아님. 수출신고 시 금액이 **FOB 기준으로 환산**되기 때문.

| 송장 조건 | 수출신고 처리 |
|---|---|
| FOB | 그대로 |
| CFR | 운임을 공제해 FOB 산출 |
| CIF | 운임 + 보험료를 공제해 FOB 산출 |

따라서 CIF 등으로 계약했다면 **운임과 보험료 금액을 관세사에게 알려줘야** 신고가 됨.

## 3. 포장명세서에 들어가는 것

송장 내용에서 금액을 빼고 아래를 추가.

| 항목 | 설명 |
|---|---|
| **G.W. (Gross Weight, 총중량)** | 포장이 완료된 상태의 무게. 박스/완충재 포함 |
| **N.W. (Net Weight, 순중량)** | 포장을 제외한 물품 자체의 무게 |
| 포장 개수 / 단위 | `CT` (Carton, 박스) 등. 실무에서 박스는 보통 Carton 으로 표기 |
| 포장 방법 | 팔레트 구성, 박스당 수량 등 |
| 치수 (Measurement) | 부피. CBM |

### 총중량이 순중량보다 중요함

운송에서 의미가 있는 것은 **총중량**. 운임 산정도, 적재 가능 여부도 실제로 실리는 무게로 판단됨.

그리고 **적재 사고의 원인 1위가 신고중량과 실제중량의 차이**. 실제로 선적했는데 유니패스에서 미선적으로 처리되어 과태료를 무는 경우가 여기서 나옴.

중량은 엄격하게 정확할 필요는 없고 어느 정도 오차는 인정되지만, **B/L 에 기재될 중량과 크게 벌어지지 않도록** 할 것.

## 4. 작성 순서

```
계약 확정 (인코텀즈/결제조건/통화 합의 완료)
   → 상업송장 작성
        - 당사자 정보는 해외거래처부호 등록 정보와 일치시킬 것
        - 품명은 HS 분류가 가능한 수준으로
   → 수출 포장 완료
   → 포장명세서 작성 (송장 복사 → 금액을 중량/포장 정보로 교체)
   → 두 서류를 관세사에게 전달
        + 물품소재지 / 적재예정보세구역 함께 통보
        + CIF/CFR 이면 운임/보험료 금액도 함께
```

## 5. 검수 포인트

작성 후 아래를 대조. 특히 **원산지증명서를 발급할 예정이면 대소문자와 주소까지** 맞춰야 함.

| # | 확인 항목 |
|---|---|
| 01 | 수출자/수입자 상호가 해외거래처부호 등록 정보와 동일한가 (대소문자 포함) |
| 02 | 주소가 동일한가 |
| 03 | 단가 × 수량 = 금액 계산이 맞는가 |
| 04 | 통화 표기가 계약과 같은가 (USD/CNY/EUR) |
| 05 | 가격조건에 **지정장소**가 붙어 있는가 (`FOB BUSAN` 형태) |
| 06 | 품명이 HS 분류 가능한 수준인가 |
| 07 | C/I 와 P/L 의 품명/수량/포장개수가 서로 일치하는가 |
| 08 | 원산지 표기가 실제 원산지와 같은가 |

## 6. 이 서류를 틀리면 생기는 일

송장 오류의 정정 범위는 송장에서 끝나지 않음.

```
상업송장 오류 발견
  → 수출신고 정정
  → B/L 정정
  → 적하목록 재신고 (포워더 과태료 발생 가능)
  → 관세사 수출입신고 오류점수 상승 → 이후 검사 선별 확률 증가
  → 이미 발송한 원산지증명서 원본을 해외에서 회수
```

**보내기 전 한 번 더 보는 것이 가장 싸다.**

## 7. 자주 하는 질문

**Q. 양식을 어디서 구하나요**
법정 양식이 없으므로 자유. 회사 양식이 없다면 거래 포워더나 관세사에게 요청하면 통상 제공해 줌.

**Q. 송장과 포장명세서를 관세사가 대신 써줄 수 있나요**
원칙은 수출자 작성이지만, 첫 거래이거나 어려우면 포워더나 관세사가 대신 작성해 주기도 함. 다만 **내용의 책임은 수출자에게 있음**.

**Q. 송장 금액과 실제 입금액이 다르면요**
결제조건상 분할 지급이라도 송장은 거래 총액 기준으로 작성. 다만 수출신고 결제금액과 실제 외환 수취가 어긋나면 외국환거래법 쟁점이 될 수 있으므로 계약과 다르게 처리할 때는 사전에 확인할 것.
