# 00. 수출 1건의 전체 흐름

이 장이 끝나면 — **내가 무엇을, 언제, 누구에게 넘겨야 하는지**에 대한 지도를 갖게 됨. 세부 방법은 각 장에서 다룸.

---

## 1. 먼저 알아야 할 사실 3가지

무역이 어려워 보이는 이유는 개념이 어려워서가 아니라 **용어와 등장인물이 많아서**. 아래 세 가지만 잡으면 나머지는 순서대로 붙음.

### 무역은 국내거래와 본질이 같음

물건을 팔 사람과 살 사람의 합의로 계약이 성립되고, 물건이 가고 돈이 옴. 다만 국경을 넘기 때문에 **통관**과 **국제운송**이 끼어들고, 그 과정에서 서류가 늘어날 뿐.

### 수출자가 직접 하는 일은 생각보다 적음

| 일 | 담당 |
|---|---|
| 상업송장/포장명세서 작성 | **수출자 본인** |
| HS 코드 분류, 수출신고, 원산지증명서 발급 | **관세사** (대행) |
| 운송계약, 선적, B/L 발행 | **포워더** |
| 대금 수취, 외국환 신고 | **은행** |

수출자가 반드시 직접 챙겨야 하는 것은 **상업송장/포장명세서**와 **각 담당자에게 정확한 정보를 넘기는 것** 두 가지.

### 수출은 수입보다 쉬움

수입은 세금(관세/부가세)을 내는 절차라 가격신고까지 얽힘. 수출은 세금을 내지 않으므로 절차가 단순함. **수출신고에는 운송서류(B/L)조차 필요 없음** — 이 점이 수입과 결정적으로 다름.

## 2. 전체 흐름 한 장 요약

```
[0단계] 사전등록 ─ 최초 1회만
   통관고유부호 발급  /  해외거래처부호 등록
        │
[1단계] 계약
   가격조건(인코텀즈) 확정  /  결제조건(T/T 또는 L/C) 확정
        │
[2단계] 서류 작성          ← 수출자가 직접
   상업송장(C/I)  →  포장명세서(P/L)
        │
[3단계] 수출신고            ← 관세사에 C/I + P/L 전달
   HS 분류 → 수출신고 → [수출신고필증(적재 전)] 수령
        │
[4단계] 원산지증명서        ← 수입자가 요구한 경우
   원산지판정 → C/O 발급
        │
[5단계] 운송/선적           ← 포워더
   운송계약 → 화물반입 → 선적 → [B/L 또는 AWB] 수령
        │                          ※ 수리일부터 30일 이내 적재 (관세법 제251조)
[6단계] 적재확인
   [수출신고필증(수출이행)] 재수령
        │
[7단계] 대금회수/사후
   대금 수취 → 부가세 영세율 신고 → (해당 시) 관세환급 → 수출실적 인정
```

## 3. 단계별 산출물과 다음 단계로 넘기는 것

| 단계 | 내가 하는 일 | 손에 남는 것 | 다음으로 넘기는 것 |
|---|---|---|---|
| 0 사전등록 | 유니패스에서 신청 | 통관고유부호 / 해외거래처부호 | - |
| 1 계약 | 인코텀즈/결제조건 합의 | 계약서 또는 확정된 오퍼 | 가격조건 → 송장 |
| 2 서류 | C/I 작성 → P/L 작성 | 상업송장 / 포장명세서 | **관세사에게 전달** |
| 3 수출신고 | 물품소재지/적재예정지 알려주기 | **수출신고필증(적재 전)** | **포워더에게 전달** |
| 4 원산지 | BOM 제출 | 원산지증명서(C/O) | **수입자에게 송부** |
| 5 선적 | 포워더 선정 | B/L 또는 AWB / 운임인보이스 | 은행 또는 수입자 |
| 6 적재확인 | 관세사에 적재 처리 요청 | **수출신고필증(수출이행)** | 세무 자료로 보관 |
| 7 대금회수 | 입금 확인 | 부가세 영세율 근거 | - |

## 4. 왜 이 순서인가 — 초보가 가장 많이 틀리는 지점

### 수출신고가 운송보다 먼저

수입은 물건이 도착해야 신고가 시작되지만, 수출은 **신고를 먼저 하고 그 다음에 운송계약을 맺음**. 그래서 수출신고서에는 선박명/출항일자 칸이 대부분 비어 있음.

수출신고에 필요한 것은 **상업송장과 포장명세서뿐**. 포워더를 아직 정하지 않았어도 수출신고는 진행 가능.

### 상업송장이 모든 서류의 출발점

C/I 하나에서 나머지가 파생됨.

```
상업송장(C/I)
  ├→ 포장명세서(P/L)      : 금액 대신 중량/포장 정보로 교체. 90% 동일
  ├→ 수출신고서            : 품명/수량/금액/거래조건이 그대로 반영
  ├→ 원산지증명서(C/O)     : C/I 기준으로 작성. 정보가 절대적으로 일치해야 함
  └→ 신용장 제시서류        : 신용장 문면과 일치해야 대금 지급
```

**C/I 가 틀리면 뒤의 모든 서류가 함께 틀림.** 정정하려면 수출신고 정정 → B/L 정정 → 적하목록 재신고 → C/O 원본 해외 회수까지 번짐. 송장 단계의 정확성이 전체 비용을 결정함.

### 수출신고필증은 두 번 받음

| 시점 | 명칭 |
|---|---|
| 적재 전 | 수출신고필증 (적재전) |
| 적재 후 | 수출신고필증 (수출이행) |

적재가 끝났는데 미선적으로 처리되어 과태료를 무는 사고가 잦음. 원인은 대개 **신고중량과 실제중량의 차이**. B/L 을 받았다면 관세사에게 **적재 처리된 면장을 다시 요청**할 것.

## 5. 첫 수출 전 체크리스트

| # | 항목 | 확인 |
|---|---|---|
| 01 | 사업자등록증 보유 | 업종이 무역/도소매가 아니어도 무방 |
| 02 | 통관고유부호 발급 | 유니패스. 개인 직구용 부호와 별개 |
| 03 | 거래 관세사 확보 | 첫 건은 대행 권장 |
| 04 | 바이어와 인코텀즈 합의 | EXW/FCA/FOB 중 하나가 대부분 |
| 05 | 결제조건 합의 | T/T 분할이 일반적 |
| 06 | 수출요건 대상 여부 확인 | 수출입공고/통합공고. 요건 있으면 승인 선행 |
| 07 | 수입자가 C/O 를 요구하는지 확인 | 요구 시 판정에 시간이 걸리므로 **사전 요청 필수** |
| 08 | 물품소재지 확정 | 사업장 주소가 아니라 **실제 물품이 있는 장소** |
