# 부록 B. 서류 체크리스트

조건별로 **무엇이 더 필요한지** 한 장에 정리.

---

## 1. 모든 수출에 공통

| # | 서류 | 만드는 사람 | 시점 |
|---|---|---|---|
| 01 | **상업송장 (C/I)** | **수출자** | 계약 확정 직후 |
| 02 | **포장명세서 (P/L)** | **수출자** | 포장 완료 후 |
| 03 | **수출신고필증 (적재전)** | 세관 | 신고 수리 시 |
| 04 | **B/L 또는 AWB** | 선사 / 포워더 | 선적 후 |
| 05 | 운임인보이스 | 포워더 | 선적 전후 |
| 06 | **수출신고필증 (수출이행)** | 세관 | 적재 후 |

## 2. 인코텀즈 조건별 추가

| 조건 | 추가로 필요한 것 | 비고 |
|---|---|---|
| EXW | 수출통관 주체 합의 문서 | 규칙상 바이어 의무이나 현실적으로 수출자 대행 |
| FCA / FAS / FOB | 없음 | 바이어가 운송/보험 처리 |
| CPT / CFR | **운임 금액**을 관세사에게 통보 | FOB 환산에 필요 |
| **CIP** | **보험증권 (최대담보)** + 운임/보험료 통보 | 피보험자 = 바이어 |
| **CIF** | **보험증권 (최소담보)** + 운임/보험료 통보 | 피보험자 = 바이어 |
| DAP / DPU | 목적지까지의 운송 수배 | 위험도 수출자 부담 |
| DDP | 상대국 수입통관/관세 처리 | 부담이 가장 큼 |

## 3. 결제방식별 추가

| 방식 | 추가로 필요한 것 |
|---|---|
| **T/T** | 없음. 입금 증빙 보관 |
| **D/P / D/A** | **환어음** + 선적서류 일체 (은행 제시용) |
| **L/C** | **환어음** + 신용장이 요구하는 서류 전부 (아래) |

### 신용장 요구서류 (거의 예외 없음)

| # | 서류 | 주의 |
|---|---|---|
| 01 | 상업송장 | 신용장 문면과 **품명 표기 일치** |
| 02 | **선하증권** | **Master B/L** 요구됨 |
| 03 | 포장명세서 | |
| 04 | 보험서류 | **원본 전통(full set)** 요구가 일반적 |
| 05 | 원산지증명서 | |
| + | 할랄 인증서 / 검사증명서 등 | 품목/국가별 |

L/C 는 **Surrender / SWB 를 쓸 수 없음.** 원본이 은행을 통해 이동해야 하기 때문.

## 4. FTA 특혜를 적용할 때

| # | 서류 | 만드는 사람 |
|---|---|---|
| 01 | **BOM (원재료 명세서)** | 수출자 |
| 02 | **원산지(포괄)확인서** | **원재료 공급자** |
| 03 | 원산지소명서 | 수출자 / 관세사 |
| 04 | 제조공정도 | 수출자 |
| 05 | 거래명세서 / 세금계산서 | 수출자 |
| 06 | 상업송장 / 포장명세서 / B/L | 기존 서류 활용 |
| 07 | 수출신고필증 | **신고번호만 입력하면 자동 반영** |
| → | **원산지증명서 (C/O)** | 세관/상공회의소 또는 자율발급 |

## 5. 수출요건이 있을 때

| # | 항목 |
|---|---|
| 01 | 수출입공고 별표2(수출제한품목) 해당 시 → **수출승인서** |
| 02 | 통합공고상 요건 해당 시 → **요건확인기관 승인/신고/검사 증명** |
| 03 | 전략물자 해당 시 → **수출허가** |

## 6. 관세환급을 받을 때

| 방법 | 필요 서류 |
|---|---|
| **개별환급** | **소요량계산서** + **기납증/분증** (공급 단계마다) + 원재료 수입신고필증 |
| **간이정액환급** | 별도 서류 없음. 단 **중소기업 + 환급실적 6억원 이하** 요건 충족 필요 |

## 7. 보관 세트

수출 1건 종료 후 아래를 묶어서 보관. 사후 원산지조사 / 세무조사 / 환급 심사 대비.

| # | 서류 |
|---|---|
| 01 | 계약서 / 오퍼시트 / P/O |
| 02 | 상업송장 / 포장명세서 |
| 03 | 수출신고필증 (적재전 + 수출이행) |
| 04 | B/L 또는 AWB |
| 05 | 운임인보이스 |
| 06 | 보험증권 (해당 시) |
| 07 | **원산지증명서 + 판정 근거서류 일체** |
| 08 | 입금 증빙 |

**자율발급으로 C/O 를 냈다면 07번 보관이 특히 중요.** 사전 심사가 없었던 만큼 사후에 전부 입증해야 함.
