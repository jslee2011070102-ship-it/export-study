# 14. 무역보험 — 대금을 못 받을 위험 넘기기

이 장이 끝나면 — **T/T 로 팔았는데 돈을 못 받을 위험**을 어떻게 다룰지 판단할 수 있게 됨.

앞선 장들에서 계속 나온 문제. 실무 표준은 T/T 인데, T/T 에는 은행 보증이 없어 **수출자의 신용위험이 그대로 남음**. 그 위험을 넘기는 제도가 무역보험.

---

## 1. 적하보험과 다른 것

이름이 비슷해 헷갈리지만 완전히 다른 위험을 다룸.

| 구분 | 적하보험 ([11장](11_적하보험.md)) | 무역보험 |
|---|---|---|
| 담보 위험 | **물건**이 운송 중 망가짐 | **돈**을 못 받음 |
| 인수자 | 손해보험사 | **한국무역보험공사 (K-SURE)** |
| 근거법 | 상법 (해상보험) | **무역보험법** |
| 언제 필요 | CIP/CIF 조건이면 의무 | T/T 사후송금 등 신용위험이 남을 때 |

둘 다 드는 것이 정상. 서로 대체 관계가 아님.

## 2. 법적 구조

| 항목 | 내용 | 근거 |
|---|---|---|
| 운영 주체 | **한국무역보험공사** (공사) | 무역보험법 제37조 |
| 보험 종류 | **공사가 산업통상부장관 승인을 받아 정함** | 무역보험법 제3조 |
| 보험료율 | 공사가 승인을 받아 정함. 수입과 지출의 균형 유지 | 무역보험법 제4조 |

**보험 상품이 법률에 열거되어 있지 않음.** 공사가 정하는 구조라 상품 구성과 요율은 K-SURE 에서 직접 확인해야 함.

### 공사가 하는 일 (무역보험법 제53조)

| # | 업무 |
|---|---|
| 01 | 무역보험 (환율 변동/이자율 변동 위험 담보 포함) |
| 02 | **수출신용보증** 및 수출용 원자재 수입신용보증 |
| 03 | 기금의 관리 및 운용 |
| 04 | **신용조사 및 신용정보 관리** |

수출자 입장에서 실질적으로 쓰는 것은 01 / 02 / 04.

### 잘 알려지지 않은 기능 — 채권추심 위임

> 공사는 수출이나 그 밖의 대외거래에서 발생한 **수출자 등의 대외채권에 대한 추심 업무를 위임받은 경우** 채권추심업을 할 수 있다. — 무역보험법 제53조제3항

**무역보험에 가입하지 않은 건도 추심을 위임할 수 있음.** 대금을 못 받았을 때 해외 상대에게 직접 독촉하기 어려운 중소 수출자에게 현실적인 수단.

## 3. 언제 필요한가

[03장 결제조건](03_결제조건.md)의 위험 구분과 그대로 연결됨.

| 결제조건 | 수출자 신용위험 | 무역보험 필요성 |
|---|---|---|
| T/T 전액 선급 | 없음 | 불필요 |
| **T/T 분할 (선급 + 잔금)** | **잔금분만큼 남음** | 금액이 크면 검토 |
| **T/T 전액 사후송금** | **전액** | **강하게 권장** |
| D/P / D/A (추심) | 은행 보증 없음. 그대로 남음 | 권장 |
| L/C | 개설은행 보증으로 크게 감소 | 개설은행 자체의 신용위험은 남음 |

**신규 거래처 + 사후송금 + 금액이 큼** — 이 셋이 겹치면 무역보험 없이 진행하지 말 것.

## 4. 신용조사를 먼저 쓸 것

보험 가입보다 앞서는 단계. 공사의 **신용조사** 업무(제53조제1항제4호)로 상대 바이어의 신용도를 확인할 수 있음.

[04장 무역사기](04_계약과_무역사기.md)의 자가진단 체크리스트가 "의심스럽다"에서 멈춘다면, 그다음은 신용조사로 넘어가는 것이 순서.

## 5. 실무 순서

```
바이어 확정
  → K-SURE 신용조사 의뢰 (상대 신용등급 확인)
  → 결제조건 최종 결정 (조사 결과를 협상 카드로 사용)
  → 사후송금 비중이 남으면 보험 가입 검토
  → 선적 및 보험 청약 (선적 전/후 시점은 상품별로 다름)
  → 만기 미결제 발생 시 사고 통지
  → 보험금 청구 또는 추심 위임
```

## 6. 확인이 필요한 사항

`[검증]` 아래는 법률에 규정되지 않아 **K-SURE 에서 직접 확인해야 하는 항목**. 이 설명서를 실제로 쓰기 전에 채울 것.

| 항목 | 확인처 |
|---|---|
| 단기수출보험의 상품 구성과 정확한 명칭 | K-SURE (ksure.or.kr) 또는 지역본부 |
| 부보율 (손실의 몇 %까지 보상되는지) | 상품별 약관 |
| 보험료율과 산정 방식 | 공사 고시 |
| 청약 시점 (선적 전 / 선적 후) | 상품별 |
| 중소중견기업 대상 우대 제도 | K-SURE |
| 사고 통지 기한과 보험금 지급 절차 | 약관 |
| 수출신용보증(선적전/선적후)과 무역보험의 차이 | K-SURE |

작성 방침 — 위 항목은 개정과 상품 개편이 잦음. **채널이나 2차 자료를 인용하지 말고 반드시 K-SURE 현행 자료로 채울 것.**

## 7. 체크리스트

| # | 항목 |
|---|---|
| 01 | 결제조건에 사후송금 비중이 있는가 |
| 02 | 신규 거래처인가 |
| 03 | 금액이 감당 못 할 수준인가 |
| 04 | (01~03 중 둘 이상 해당) K-SURE 신용조사를 의뢰했는가 |
| 05 | 무역보험 가입 여부를 결정했는가 |
| 06 | 가입했다면 청약 시점을 놓치지 않았는가 |
| 07 | 미결제 발생 시 사고 통지 기한을 아는가 |
