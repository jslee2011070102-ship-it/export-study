# 01. 무역 기초용어 30개

이 장이 끝나면 — 포워더/관세사/바이어가 보내는 메일을 **사전 없이 읽을 수 있게 됨**.

무역이 어려운 이유는 개념이 아니라 **용어**. 일본식 번역어가 많아 한국어인데도 뜻이 안 잡힘. 아래 30개면 실무 메일의 대부분이 해석됨.

---

## 1. 사람 (당사자)

| 용어 | 영문 | 뜻 |
|---|---|---|
| 매도인 | Seller | 파는 사람. 수출 거래에서 **나** |
| 매수인 | Buyer | 사는 사람. 바이어 |
| 수출화주 / 수입화주 | Shipper / Consignee 화주 | 물품의 실제 주인. 줄여서 **화주** |
| 송하인 | Shipper | 운송인에게 물품을 넘기는 자. 수출자가 되는 것이 보통 |
| 수하인 | Consignee | 목적지에서 물품을 받는 자 |
| 착화통지처 | Notify Party | 화물 도착 통지를 받을 자. 보통 실제 수입자 |
| 포워더 | Freight Forwarder | 운송주선업자. 배/비행기를 직접 갖고 있지 않고 운송을 중개 |
| 선사 | Shipping Line / Carrier | 실제 배를 보유한 운송인 |
| 관세사 | Customs Broker | 통관을 대행하는 국가전문자격사 |
| 수익자 | Beneficiary | **신용장 거래에서 매도인을 부르는 말** |

`송하인`과 `수하인` 한 글자 차이라 실무에서 자주 헷갈림. **하(荷)** 는 짐. 짐을 **보내는** 사람과 **받는** 사람.

## 2. 서류

| 용어 | 영문 / 약어 | 뜻 |
|---|---|---|
| 상업송장 | Commercial Invoice / C/I | 거래 명세서. 송장/송품장/인보이스 모두 같은 말 |
| 포장명세서 | Packing List / P/L | 포장/중량 명세서 |
| 선하증권 | Bill of Lading / B/L | 해상 운송서류. **권리증권** |
| 항공화물운송장 | Air Waybill / AWB | 항공 운송서류. 권리증권 아님 |
| 원산지증명서 | Certificate of Origin / C/O | 물품의 국적 증명. FTA 특혜용 |
| 보험증권 | Insurance Policy | 적하보험 가입 증서 |
| 수출신고필증 | - | 통칭 **수출면장**. 수출신고 수리 후 발급 |
| 도착통지서 | Arrival Notice / A/N | 화물 도착 통지 |
| 인도지시서 | Delivery Order / D/O | 화물 반출 지시서 |
| 환어음 | Draft / Bill of Exchange | 대금 청구 증권 |

**선적서류(Shipping Documents)** = 물품과 관련된 서류 전체. 그중 **3대 선적서류**는 송장 / 운송서류 / 보험서류.

## 3. 물류

| 용어 | 뜻 |
|---|---|
| FCL | 컨테이너 하나를 통째로 쓰는 화물. **CY** 로 직행 |
| LCL | 컨테이너를 채우지 못하는 소량화물. **CFS** 에서 다른 화주 화물과 혼재 |
| CY | Container Yard. 컨테이너 장치장 |
| CFS | Container Freight Station. 혼재/분해 작업 창고 |
| 적재 (선적) | 운송수단에 싣는 것. 배는 선적, 비행기는 기적 |
| 양하 (하차) | 운송수단에서 내리는 것 |
| 보세구역 | 관세 미납 상태로 외국물품을 둘 수 있는 구역 |
| DEM | Demurrage. 컨테이너를 터미널에서 안 빼가서 나오는 체화료 |
| DET | Detention. 컨테이너를 반납 안 해서 나오는 지체료 |
| THC | Terminal Handling Charge. 터미널 화물처리비 |

## 4. 조건/제도

| 용어 | 뜻 |
|---|---|
| 인코텀즈 (Incoterms) | 국제 정형거래조건. 인도장소/위험이전/비용부담을 정함 |
| T/T | Telegraphic Transfer. 송금 방식 결제 |
| L/C | Letter of Credit. 신용장 |
| HS CODE | 수출입 물품에 부여되는 국제 통일 6자리 번호 |
| 통관고유부호 | 관세청이 업체별 수출입을 관리하는 식별번호 |
| 유니패스 | 관세청 전자통관시스템 |
| 목록통관 | 소액 물품에 대해 수출신고를 간이 목록 제출로 갈음 |
| 관세환급 | 수출물품에 든 외국 원재료의 수입 관세를 돌려받는 제도 |

## 5. 실무에서 그대로 쓰이는 표현

메일에서 그대로 날아오는 말들.

| 표현 | 뜻 |
|---|---|
| **CPL 보내주세요** | Commercial Invoice + Packing List 를 보내달라는 뜻 |
| **면장 끊어주세요** | 수출신고필증을 발급해 달라는 뜻 |
| **서렌더 쳐주세요** | B/L 원본의 권리증권 기능을 포기 처리해 달라는 뜻 |
| **네고한다** | 신용장 서류를 은행에 제시하고 매입을 받는 것 |
| **체크 B/L** | 출항 전 확인용 가(假) B/L |
| **O.B/L** | Original B/L. 원본 선하증권 |

## 6. 헷갈리기 쉬운 짝

| 짝 | 구분 |
|---|---|
| 총중량 (G.W.) / 순중량 (N.W.) | 포장 **포함** / 포장 **제외**. 운송에서 중요한 것은 총중량 |
| 선적지 인도 / 양륙지 인도 | 위험이 **출발지**에서 넘어감 / **도착지**에서 넘어감 |
| Master B/L / House B/L | **선사**가 발행 / **포워더**가 발행 |
| 기관발급 / 자율발급 | C/O 를 **기관**이 심사 발급 / **수출자**가 직접 발행 |
| 수출신고필증(적재전) / (수출이행) | 적재 **전** / 적재 **후** |
| 관세사 / 포워더 | **통관** 담당 / **운송** 담당 |

## 7. 한 문장 요약

> 화주가 송장과 포장명세서를 만들어 관세사에게 주면 면장이 나오고, 그 면장을 들고 포워더에게 가면 배에 실린 뒤 B/L 이 나오고, 그 B/L 로 상대가 물건을 찾아가면서 돈이 들어온다.

이 한 문장이 수출의 전부. 나머지는 세부사항.
