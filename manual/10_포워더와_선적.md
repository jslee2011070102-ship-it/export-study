# 10. 포워더 선정과 선적

이 장이 끝나면 — 물건이 배에 실리고 **B/L 이 손에 들어옴**. 이 서류가 대금 회수의 근거가 됨.

---

## 1. 등장인물

| 용어 | 역할 |
|---|---|
| **선사 / 항공사** | 실제 배와 비행기를 가진 **실제운송인** |
| **포워더** | 운송을 주선하는 **계약운송인**. 운송주선업자 |
| 콘솔(Consolidator) | LCL 혼재 전문 업체. 규모가 포워더보다 큰 경우가 많음 |

### 왜 선사와 직접 거래하지 않는가

소량 화주가 선사와 직접 계약하기는 어렵고, 소량화물은 컨테이너 단위로 모아야 운임 경쟁력이 생김. 포워더가 여러 화주의 화물을 모아 컨테이너를 채움.

영세 포워더는 자체 혼재가 어려워 콘솔 업체에 재의뢰함. **내가 만나는 포워더가 실제 작업까지 하는 건 아닐 수 있음.**

## 2. FCL 과 LCL

| 구분 | FCL | LCL |
|---|---|---|
| 뜻 | 컨테이너 하나를 통째로 씀 | 컨테이너를 못 채우는 소량화물 |
| 경로 | **CY** 로 직행 | **CFS** 에서 혼재 → 목적지 CFS 에서 분해 |
| 운임 | 컨테이너 단위 | 부피/중량 기준 |
| 리스크 | 낮음 | 다른 화주 화물과 섞여 작업이 추가됨 |

## 3. 수출 선적 흐름

```
수출신고필증(적재전) 수령
  → 포워더 선정 및 부킹(Booking)
  → 수출서류 + 면장을 포워더에게 송부
  → 화물 반입 (FCL: CY / LCL: CFS)
  → 혼재 및 적입 작업 (LCL)
  → 선적(배) 또는 기적(비행기)
  → B/L 또는 AWB 발행
  → 적재 처리된 수출신고필증(수출이행) 재수령
```

**수출신고필증이 나온 뒤에 선적이 가능함.** 순서를 바꿀 수 없음.

## 4. B/L 과 AWB

| 항목 | B/L (선하증권) | AWB (항공화물운송장) |
|---|---|---|
| 운송 | 해상 | 항공 |
| **유가증권성** | **권리증권** | 아님. 단순 운송장 |
| 원본 유통 | 필요 | 불필요 |
| 화물 인도 | 원본 회수 또는 Surrender 후 | 수하인 본인확인으로 인도 |

AWB 가 권리증권이 아닌 이유 — 항공은 운송이 빨라 원본이 화물보다 늦게 도착함. 유통증권으로 만들 실익이 없음.

## 5. Master B/L 과 House B/L

| 구분 | Master B/L | House B/L |
|---|---|---|
| 발행 | **선사** → 포워더 | **포워더** → 각 화주 |
| 다른 이름 | Direct B/L / Line B/L / Groupage B/L | Forwarder's B/L |
| **선사에 대한 직접청구권** | **있음** | 없음 |

### Master B/L 이 필요한 경우

| 상황 | 이유 |
|---|---|
| **신용장 방식** | 개설은행이 B/L 을 담보로 잡는데, House 는 선사 직접청구권이 없어 담보 기능이 약함. **예외 없이 Master 요구** |
| 특정 국가 정책 | 수입국 규정상 요구하는 경우 |

**대응은 간단함.** 선사와 직접 계약할 필요 없이, 포워더에게 **"수입자가 Master B/L 을 요구한다"** 고 전달하면 처리해 줌.

### 받은 B/L 이 어느 쪽인지 판별하는 4가지 방법

| # | 확인 위치 | Master | House |
|---|---|---|---|
| 01 | 우측 상단 발행인 로고 | 선사명 (`SHIPPING`, `LINE`) | 물류업체명 (`LOGISTICS`, `INTERNATIONAL`, `FORWARDING`) |
| 02 | **하단 서명란** | `as Carrier` / `as Agent for(on behalf of) the Carrier` | `acting as Carrier` 또는 회사명만 |
| 03 | **유니패스 화물추적** | Master B/L 번호 입력란에서 조회됨 | House B/L 번호 입력란에서 조회됨 |
| 04 | 선적란 (Place of Receipt/Delivery) | `CY-CY` | `CFS-CFS` |

주의 — **포워더가 발행했다고 무조건 House 가 아님.** 포워더가 **선사의 대리인 자격**(`as Agent on behalf of the Carrier`)으로 서명하면 Master 로 처리됨. 신용장에서 Master 가 필요할 때 포워더에게 이 서명 형식으로 요청하는 방식이 실무에서 쓰임.

02번(서명란)이 가장 확실하고, 03번(유니패스)이 가장 객관적.

## 6. Surrender / SWB / L/G

원본 B/L 은 **권리증권**. 소지자가 화물의 주인이므로, 수하인이 원본을 받아 운송인에게 반환해야 화물을 찾을 수 있음.

| 방식 | 내용 |
|---|---|
| 원본 B/L | 특송으로 원본을 바이어에게 송부 → 바이어가 운송인에게 반환 |
| **Surrender** | 송하인이 원본을 운송인에게 반납하고 권리증권 기능을 포기. 바이어는 본인확인만으로 화물 수령 |
| **SWB** (Sea Waybill) | 애초에 권리증권이 아닌 운송장 |
| **L/G** (수입화물선취보증서) | 원본이 아직 도착하지 않았을 때 은행 보증으로 먼저 화물을 찾는 방식 |

Surrender 여부 확인 — B/L 면에 `SURRENDERED` / `SURRENDER` 표기, `COPY` 도장, 또는 **`TELEX RELEASE`**. **Telex Release 와 Surrender 는 같은 말.**

실무 빈도 — 중국/일본 등 근거리 거래에서는 Surrender 가 압도적. 원본 B/L 이 화물보다 늦게 도착하는 문제 때문.

**신용장 거래에서는 Surrender/SWB 를 쓸 수 없음.** 원본이 은행을 통해 이동해야 하기 때문. 원본 미도착 시에는 **L/G** 를 씀.

### 대금 회수와 직결

Surrender 를 언제 쳐줄 것인가는 **대금 회수 시점과 직결**됨. 잔금을 못 받은 상태에서 Surrender 를 치면 바이어가 물건을 가져가 버릴 수 있음.

권장 — **잔금 입금 확인 후 Surrender.** T/T 분할 결제에서 이 순서를 지키는 것이 대금 미회수를 막는 마지막 방어선.

## 7. 운임 항목

운임은 기본운임(Ocean Freight)만이 아니라 부대비용이 붙음.

| 항목 | 내용 |
|---|---|
| THC | Terminal Handling Charge. 터미널 화물처리비 |
| BAF | Bunker Adjustment Factor. 유류할증료 |
| CAF | Currency Adjustment Factor. 통화할증료 |
| Documentation Fee | 서류 발급비 |
| Wharfage | 부두사용료 |
| **DEM** | Demurrage. 컨테이너를 터미널에서 안 빼가서 나오는 체화료 |
| **DET** | Detention. 컨테이너를 반납 안 해서 나오는 지체료 |

**운임인보이스는 인코텀즈 조건과 무관하게 반드시 요청할 것.** CFR/CIF 로 내가 운임을 내는 경우 수출신고 시 FOB 환산에 필요하고, FOB 로 바이어가 내는 경우에도 국내 발생 비용이 있을 수 있음.

## 8. 포워더 선정 시 확인할 것

| # | 항목 |
|---|---|
| 01 | 목적지 노선 취급 경험이 있는가 |
| 02 | 견적에 **부대비용이 모두 포함**되어 있는가 (기본운임만 싸게 제시하는 경우 주의) |
| 03 | Master B/L 발행이 가능한가 (신용장 거래 시) |
| 04 | 출항 스케줄과 마감(Closing) 시간 |
| 05 | 적재기한 30일 안에 선적이 가능한 스케줄인가 |
| 06 | (바이어 지정 포워더인 경우) **공신력이 있는 업체인가** → [04장](04_계약과_무역사기.md) |
