# 수출 실무 양식

수출 1건에 등장하는 서류를 **누가 만드는가**로 나눠 정리. 내가 만들어야 하는 것은 이 폴더의 템플릿을 쓰고, 기관이 발행하거나 법정서식이 정해진 것은 아래 출처에서 받을 것.

---

## 1. 이 폴더의 템플릿

법정 양식이 **없어서** 직접 만들어야 하는 서류. 바로 쓸 수 있게 제작했고 예시 값이 한 줄 들어 있음.

| 파일 | 서류 | 특징 |
|---|---|---|
| [수출서류_상업송장_포장명세서.xlsx](수출서류_상업송장_포장명세서.xlsx) | **상업송장 (C/I) + 포장명세서 (P/L)** | **`입력` 시트 하나만 채우면 두 서류가 동시에 완성됨** |
| [오퍼시트_Offer_Sheet.xlsx](오퍼시트_Offer_Sheet.xlsx) | Offer Sheet | 청약서. 유효기간 항목 포함 |
| [BOM_원재료명세서.xlsx](BOM_원재료명세서.xlsx) | BOM (원재료 명세서) | FTA 원산지판정용. 비원산지 비중 자동 계산 |

### 사용법

- **노란색 칸만 채울 것.** 흰색 칸은 수식이므로 건드리면 연결이 끊김
- 첫 행에 들어 있는 예시 값(`FACIAL CLEANSING FOAM 150ML` 등)은 형식을 보여주는 것이므로 **지우고 실제 값을 넣을 것**
- 상호/주소는 **통관고유부호 및 해외거래처부호 등록정보와 대소문자까지 일치**시킬 것

### C/I 와 P/L 을 한 파일로 묶은 이유

두 서류는 서식이 90% 동일하고, 다른 것은 **송장에 금액이, 포장명세서에 중량이 들어간다는 점 하나**. 그리고 원산지증명서와 수출신고서가 모두 상업송장을 기초로 작성되므로 **상업송장이 사실상 마스터 데이터**.

따라서 입력을 한 곳으로 모으면 서류 간 불일치가 원천 차단됨. 송장 오류는 수출신고 정정 → B/L 정정 → 적하목록 재신고 → C/O 원본 해외 회수까지 번지므로 이 구조가 실익이 큼. 상세는 [../manual/06_상업송장_포장명세서.md](../manual/06_상업송장_포장명세서.md).

## 2. 공식 서식 원본 (forms/공식서식/)

FTA특례법 시행규칙 별지서식을 국가법령정보센터에서 내려받아 보관함. **hwp / pdf 각 1부.**

| 서식 | 언제 쓰는가 |
|---|---|
| **원산지소명서** | 원산지판정 근거 정리. C/O 발급 필수서류 |
| **원산지(포괄)확인서** (Declaration of Origin) | 원재료가 국내산임을 **공급자가 증명**. 세번변경 불성립 시 필수 |
| **국내제조(포괄)확인서** (Declaration of Inward Processing) | 국내 제조 사실 확인 |
| **원산지증명서 발급(재발급/정정발급)신청서** | 기관발급 신청 |
| **협정관세 적용신청서** (갑지/을지) | 수입 시 특혜관세 신청 |
| **업체별 원산지인증수출자 인증(연장) 신청서** | 인증수출자 취득 |
| **품목별 원산지인증수출자 인증(연장) 신청서** | 인증수출자 취득 |
| **사전심사신청서** | 품목분류/원산지 사전심사 |

수집 시점 — 2026-08-31 / 시행규칙 시행일 2026-05-01. **개정이 잦으므로 실제 제출 전 국가법령정보센터에서 현행본 재확인 권장.**

### 수출통관 서식 (forms/공식서식/수출통관/)

「수출 및 반송통관에 관한 고시」(시행 2026-06-26) 별지/별표. **hwp / pdf 각 1부.**

| 파일 | 내용 |
|---|---|
| **별지01_수출신고서** | 수출신고서(갑지/을지) + **수출신고필증 8종** — 적재전/수출이행 × 갑지/을지 × 국문/영문 |
| **별표01_수출신고서_작성요령** | **항목별 TYPE / 자릿수 / 필수여부 / 기재례** (35쪽). 파서와 검증 규칙의 근거 |
| 별지01-2_간이수출신고서 | 간이수출신고서 + 간이수출신고필증 8종 |
| 별지06 / 별지14 | 수출·반송신고 정정, **적재기간 연장승인(신청)서** |
| 별지07 | 수출·반송신고필증 재교부 신청서 |
| 별지15 | 수출신고수리취소 예정통보 |
| 별표09 | 수출신고정정 시 표준증빙 서류 |
| 별표11 | 수출목록 변환신고 작성요령 |

작성요령에서 뽑은 항목 명세는 [data/수출신고서_항목.csv](../data/수출신고서_항목.csv) (98개 항목).

**수출신고필증 실물 샘플** — 서식만으로는 실제 값이 어떻게 찍히는지 안 보임. 채워진 필증은 아래에서 구함.

| 출처 | 비고 |
|---|---|
| **유니패스** (unipass.customs.go.kr) — 전자신고 > 통관서식출력 | **본인 건**. 전자문서라 언제든 재출력. 가장 정확 |
| **KITA okFTA** (okfta.kita.net) 자료실 | 교육용으로 공개된 실제 발급본 |
| 관세청 / 무역협회 교육자료 PDF | 항목 설명과 함께 실린 경우가 많음 |
| 포워더 / 관세사 블로그 | 개인정보 마스킹본. 항목 위치 확인용으로만 |

이 저장소에는 **식별정보를 치환한 텍스트 샘플**만 둠 — [automation/samples/수출신고필증_예시.txt](../automation/samples/수출신고필증_예시.txt). 원본은 KITA okFTA 공개자료이며, 상호/대표자/사업자등록번호/통관고유부호/신고번호/제품명을 가공 값으로 바꿨음.

## 3. 기관에서 받거나 발행되는 서류

직접 만들 필요가 없는 것들. 출처만 알면 됨.

| 서류 | 어디서 | 비고 |
|---|---|---|
| **수출신고서 / 수출신고필증** | **유니패스** (unipass.customs.go.kr) | 관세사 대행 시 관세사가 처리. 자가신고 시 유니패스 화면에서 직접 입력 |
| **원산지증명서 (C/O)** | 유니패스(세관) 또는 **대한상공회의소 원산지증명센터** (cert.korcham.net) | **기관발급 협정**만 해당. 세관 무료 / 상의는 비회원 수수료 |
| **원산지소명서 / 원산지(포괄)확인서** | **`공식서식/` 폴더에 보관 중** | 협정별 서식이 있으므로 임의 양식 사용 금지 |
| **한-EU / 한-영 원산지신고서** | 별도 양식 없음 | **상업송장에 원산지 문구를 기재**하는 방식. 문구는 아래 참조 |
| **수출승인서** | 품목별 수출승인기관 | 수출입공고 별표2(수출제한품목) 해당 시 |
| **구매확인서 / 내국신용장** | 외국환은행, 무역협회 (uTradeHub) | 간접수출 실적 인정용 |
| **선하증권 (B/L) / 항공화물운송장 (AWB)** | 선사 / 포워더 | 발행받는 서류. 내가 만들지 않음 |
| **적하보험증권** | 손해보험사 | CIP/CIF 조건에서 수출자가 가입 |
| **환어음 (Draft)** | 거래은행 | 추심/신용장 거래 시. 은행 서식 사용 |
| **소요량계산서 / 기납증 / 분증** | 유니패스, 관세사 | 관세환급(개별환급) 시 |

### 한-EU / 한-영 FTA 원산지신고문안

별도의 원산지증명서 없이 **상업송장 등 상업서류에 아래 문구를 기재**하면 원산지가 인정됨.

```
The exporter of the products covered by this document (customs authorisation No ...(1))
declares that, except where otherwise clearly indicated, these products are of ...(2)
preferential origin.
```

- (1) 인증수출자 번호 — **건당 6,000유로 초과 시 인증수출자만 가능** `[검증]`
- (2) 원산지 국가

6,000유로 이하는 인증수출자가 아니어도 작성 가능. 상세는 [../manual/09_원산지증명서와_FTA.md](../manual/09_원산지증명서와_FTA.md).

## 4. 공식 서식을 받는 곳

| 출처 | 무엇이 있는가 |
|---|---|
| **국가법령정보센터** (law.go.kr) | 법령별 **별지서식** 원본(hwp/pdf). `자유무역협정의 이행을 위한 관세법의 특례에 관한 법률 시행규칙`, `수출통관 사무처리에 관한 고시` 등에서 검색 |
| **관세법령정보포털** (unipass.customs.go.kr/clip) | 고시 원문 및 첨부 서식 |
| **관세청 FTA 포털** | 협정별 원산지증명서 서식, 원산지소명서/확인서 서식 |
| **FTA 강국, KOREA** (fta.go.kr) | 원산지신고문안 처리지침, 협정문 |
| **한국무역협회 / uTradeHub** | 무역 서식 모음, 구매확인서 |
| **대한상사중재원** (kcab.or.kr) | 표준중재조항 |

`[검증]` 서식 번호(별지 제○호 서식)는 개정으로 바뀌므로 **인용하지 않았음**. 실제 사용 시 위 출처에서 현행본을 확인할 것.

## 5. 서류 준비 순서

```
Offer Sheet (오퍼)              ← forms/오퍼시트
   ↓ 바이어 P/O 수령
상업송장 (C/I)                  ← forms/수출서류 [입력] 시트
   ↓ 포장 완료
포장명세서 (P/L)                ← 위 파일에서 자동 생성
   ↓ 관세사 전달
수출신고필증 (적재전)            ← 유니패스
   ↓ (FTA 적용 시) BOM 제출     ← forms/BOM
원산지증명서 (C/O)               ← 유니패스 또는 상공회의소
   ↓ 포워더 전달
B/L 또는 AWB                    ← 포워더
   ↓ 적재 확인
수출신고필증 (수출이행)          ← 유니패스
```

조건별로 무엇이 더 필요한지는 [../manual/부록B_서류_체크리스트.md](../manual/부록B_서류_체크리스트.md).
