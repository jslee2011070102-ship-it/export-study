## 재수집

```bash
python3 scripts/collect_channel.py --out out
```

YouTube 공개 페이지의 `ytInitialData` 와 innertube `browse`/`player` 엔드포인트만 사용. API 키/로그인 불필요.

## 수집 한계

- 자막(transcript)은 미수집. watch 페이지가 공유 IP에서 429/봇차단으로 막힘. 대신 제목 + 설명란 + 챕터 타임스탬프(57편) + 연계 블로그 본문(141건)으로 내용을 파악함.
- 재생목록 표시 상한이 100건이라 `현직자를 위한 무역실무` / `[무역자격증과 취업]` 두 재생목록은 100편까지만 확보됨. 단 두 목록의 미표시분은 영상탭 수집분에 포함됨.
- Shorts 탭은 별도 렌더러를 써서 탭 단위로는 0건. 다만 Shorts 개별 영상은 재생목록 경로로 수집되어 전체 390편에 포함됨.

## 저작권

영상/블로그 본문은 무꿈사TV(정재환 관세사)의 저작물. 본 저장소는 **메타데이터와 링크 색인, 그리고 자체 작성한 분석/요약**만 보관. 원문 텍스트는 저장하지 않음.
