## 재수집

```bash
python3 scripts/collect_channel.py --out out          # 채널 메타데이터 재수집
python3 scripts/fetch_transcripts.py --urls data/need_transcript_urls.txt --out <볼트경로>   # 자막 일괄 수집
```

YouTube 공개 페이지의 `ytInitialData` 와 innertube `browse`/`player` 엔드포인트만 사용. API 키/로그인 불필요.

## 수집 한계

- 자막(transcript)은 이 컨테이너에서 직접 수집 불가. watch 페이지가 공유 IP에서 429/봇차단으로 막힘. 대신 `scripts/fetch_transcripts.py` 로 로컬 PC에서 64편을 수집해 옵시디언 볼트(`second-brain`)에 보관 중.
- 확보한 자막은 **YouTube 자동생성 자막**이라 오인식이 많음(`정재환`→"정제 아닙니다", `EXW`→"x 웍스"). 구조/논리 파악에는 충분하나 **원문 인용과 수치 인용은 불가**. 숫자/코드/기한은 전부 1차 출처 대조 필요.
- 재생목록 표시 상한이 100건이라 `현직자를 위한 무역실무` / `[무역자격증과 취업]` 두 재생목록은 100편까지만 확보됨. 단 두 목록의 미표시분은 영상탭 수집분에 포함됨.
- Shorts 탭은 별도 렌더러를 써서 탭 단위로는 0건. 다만 Shorts 개별 영상은 재생목록 경로로 수집되어 전체 390편에 포함됨.

## 저작권

영상/블로그 본문은 무꿈사TV(정재환 관세사)의 저작물. 본 저장소는 **메타데이터와 링크 색인, 그리고 자체 작성한 분석/요약**만 보관. 원문 텍스트는 저장하지 않음.
