# 대금결제 — T/T, 추심, 신용장, 외국환거래법

수출설명서 3장(결제조건)과 12장(대금회수)의 원본 자료. 무꿈사TV 결제/외환 10편 자막 및 관련 블로그에서 추출.

주의 — 자동자막 기반이라 구조와 논리만 복원함. 조문/수수료/한도 등 수치는 원문 확인 필요.

---

## 1. 결제방식 3단계

무역결제 방식은 **두 당사자의 위험을 어떻게 나누느냐**로 진화해 온 구조.

| 위험 | 정의 | 누가 지는가 |
|---|---|---|
| 신용위험 (Credit Risk) | 물품을 인도했으나 대금을 받지 못할 위험 | 매도인 |
| 상업위험 (Commercial Risk) | 대금을 지급했으나 물품을 받지 못할 위험 | 매수인 |

### 송금방식 (T/T)

- 정식 명칭 Telegraphic Transfer. 계약서에 `TT` 로 표기됨.
- 국내 계좌이체와 동일한 구조. 가장 단순하고 가장 많이 쓰임.
- **누가 먼저 이행하느냐로 위험이 결정됨.** 매도인이 선적 먼저 → 매도인이 신용위험. 매수인이 송금 먼저 → 매수인이 상업위험.
- 실무상 선급금/잔금 분할(예: 계약 시 30%, 선적 후 70%)로 위험을 나눔.

### 추심방식 (Collection — D/P, D/A)

- 매도인이 물품은 직접 보내고, **선적서류를 은행을 통해** 매수인에게 전달하며 은행이 대금을 대신 수취.
- 매수인은 물품 도착과 서류 도착을 확인한 뒤 지급 여부를 결정 → **상업위험 소멸**.
- 그러나 은행의 지급보증이 없으므로 **매도인의 신용위험은 그대로 남음**. 매수인이 인수를 거절하면 대금 회수 불가.
- D/P (Documents against Payment) = 지급인도, D/A (Documents against Acceptance) = 인수인도.

### 신용장 (L/C)

- 정식 명칭 Documentary Credit. 실무에서는 `L/C` 로만 부름.
- 구조 — 매도인이 서류를 자신의 거래은행에 제시 → 개설은행으로 전달 → 개설은행이 심사 후 지급.
- 추심과의 결정적 차이 = **개설은행의 지급보증**. 매수인의 의사와 무관하게 서류만 일치하면 지급됨 → 매도인의 신용위험이 획기적으로 감소.

## 2. 신용장 당사자

| 영문 | 국문 | 실체 |
|---|---|---|
| Applicant | 개설의뢰인 / 발행의뢰인 | **매수인** |
| Issuing Bank | 개설은행 / 발행은행 | 매수인의 거래은행 |
| Advising Bank | 통지은행 | 매도인의 거래은행 |
| Beneficiary | **수익자** | **매도인** |
| Nominated Bank | 지정은행 | 서류를 제시받는 은행. 실무상 통지은행과 동일한 경우가 대부분 |

용어 전환에 주의 — 신용장 국면에서 매도인은 `매도인`이 아니라 **`수익자(Beneficiary)`** 로 불림. 신용장 문면 해석의 출발점.

## 3. 신용장이 요구하는 서류

거의 예외 없이 요구되는 5종.

| # | 서류 | 목적 |
|---|---|---|
| 01 | 상업송장 (Commercial Invoice) | 거래 명세서 |
| 02 | 선하증권 (B/L) | 운송인에게 물품을 인도했다는 증거 |
| 03 | 포장명세서 (Packing List) | 포장/중량 명세 |
| 04 | 보험서류 (Insurance Policy) | 운송 중 사고 시 보상 근거 |
| 05 | 원산지증명서 (C/O) | 수입국 관세 혜택 |

품목/국가별 추가 — 할랄 인증서, 식품 검사증명서 등.

**신용장 거래에서는 Master B/L 이 요구됨.** House B/L 은 선사에 대한 직접청구권이 없어 개설은행의 담보 기능이 약하기 때문. 상세는 [08_운송서류_BL.md](08_운송서류_BL.md) 참조.

## 4. 신용장 2대 원칙

| 원칙 | 내용 | 결과 |
|---|---|---|
| **독립성** | 은행은 신용장 문면만 보고 업무. 매매계약서 내용과 무관 | 계약서에 보험서류가 있어도 신용장에 없으면 은행은 보험서류 없이 지급 |
| **추상성** | 은행은 서류만 심사. 실제 선적 여부나 서류 진위는 판단하지 않음 | 서류가 문면상 일치하면 지급. 반대로 정상 선적이어도 서류 불일치면 미지급 |

실무 함의 — **계약서 조건이 신용장에 정확히 반영되었는지 수익자가 직접 검토해야 함.** 은행은 확인해 주지 않음.

### 서류심사 기준

| 기준 | 내용 |
|---|---|
| 엄격일치 원칙 | 문면이 완전히 일치해야 지급 |
| 상당일치 원칙 | 실질적으로 동일하면 지급 |

국제적 원칙은 상당일치이나, **한국 은행은 보수적으로 엄격일치에 가깝게 심사하는 경향**이 있다는 것이 채널의 실무 관찰. 은행/담당자별 편차가 커서 실무자들끼리 정보를 공유하는 수준.

## 5. 신용장 효용성 — 그리고 감소 추세

| 당사자 | 효용 |
|---|---|
| 수익자(매도인) | 신용위험 회피 + **신용장을 담보로 무역금융 대출 가능** |
| 개설의뢰인(매수인) | 이론상 서류를 빠짐없이 확보. **실무상 장점 거의 없음** — 수수료 부담만 발생 |
| 은행 | 각 단계마다 수수료 수익 |

채널 진술 — 2000년 이전에는 전 세계 무역결제의 상당수가 신용장이었으나 현재는 비중이 크게 축소됨. 원인은 **매수인 우위 시장**. 매수인 입장에서 신용장은 비용만 늘어나므로 T/T 를 요구.

수치 검증 필요 — 채널은 "2000년 전 80% → 현재 10% 미만"이라고 언급하나 출처 미제시. 설명서에 인용하려면 ICC 나 무역통계로 재확인해야 함.

## 6. 환어음

| 항목 | 내용 |
|---|---|
| 성격 | 발행인이 지급인에게 수취인 앞 지급을 위탁하는 증권 |
| 사용 국면 | 추심(D/P, D/A)과 신용장에서 대금 청구 수단 |
| T/T 에서는 | 불필요 |

이해 순서 — 채널은 어음의 개념 → 약속어음 → 환어음 3단계로 나누어 설명. 국내 어음과 달리 무역에서는 **매도인이 발행인**이 되는 점이 초보의 첫 장벽.

## 7. Usance (기한부)

| 구분 | 지급 시점 |
|---|---|
| Sight L/C (일람출급) | 서류 제시 즉시 |
| Usance L/C (기한부) | 일정 기간 후 |

Usance 는 **누가 이자를 부담하느냐**로 나뉨.

| 유형 | 이자 부담 |
|---|---|
| Banker's Usance | 은행이 인수/할인. 수입자가 이자 부담 |
| Shipper's Usance | 수출자(Shipper)가 신용공여. 수출자가 사실상 이자 부담 |

수출신고필증 결제방법 코드와의 대응 — 일람출급 L/C = `LS`, 기한부 L/C = `LU`. 상세 코드표는 [03_수출지식맵.md](03_수출지식맵.md) 4.5 참조.

## 8. 외국환거래법

수출자가 반드시 알아야 하는 이유 — **경고 없이 곧바로 과태료/형사처벌**로 이어지는 법. 채널이 가장 강하게 경고하는 영역.

채널의 정리 방식 — 신고대상을 **4개 유형으로 압축**하면 실무상 대부분 커버 가능. 수출 실무에서 걸리기 쉬운 지점은 아래.

| 상황 | 논점 |
|---|---|
| 해외 계좌로 수출대금 수취 | 해외예금계좌 개설/사용이 신고대상인지 |
| 제3자 지급/수령 | 계약 당사자가 아닌 자에게 지급하거나 받는 경우 |
| 상계 처리 | 수출채권과 수입채무를 상계하는 경우 |
| 지급방법 변경 | 계약과 다른 방법으로 결제하는 경우 |

**2023년 전면개정** — 2021년 이전 영상 내용은 폐기하고 개정 내용으로 재작성 필요. 송금한도도 상향됨.

## 9. 수출설명서 집필 시 처리 방침

| 항목 | 방침 |
|---|---|
| 서술 순서 | 위험(신용/상업) 정의 → T/T → 추심 → 신용장. 채널과 동일. "왜 신용장이 생겼는가"가 이해의 핵심 |
| 비중 조정 | 채널은 신용장에 압도적 비중을 두나, **실무 빈도는 T/T 가 압도적**. 설명서는 T/T 분할결제 설계를 더 두껍게 |
| 신용장 | 축소하되 2대 원칙과 요구서류 5종, Master B/L 요구는 반드시 포함 |
| 외국환거래법 | 2023년 개정 기준으로 전면 재작성. 채널 자막 인용 불가 |
| 보강 필요 | **무역보험(K-SURE 단기수출보험)이 채널에 전무.** T/T 신용위험의 현실적 대응책이므로 외부 소스로 반드시 보강 |
