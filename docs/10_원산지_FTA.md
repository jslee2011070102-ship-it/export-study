# 원산지와 FTA — 판정부터 원산지증명서 발급까지

수출설명서 9장의 원본 자료. 무꿈사TV 원산지/FTA 19편 중 자막 5편 + 관련 블로그(인증수출자/발급절차/실무적용/RCEP) 기준.

이 모듈의 자막 품질은 다른 모듈보다 양호함. 특히 `수습관세사 원산지업무 도전하기`는 관세사무소 실무 대화를 그대로 재현한 구성이라 절차 복원도가 높음.

---

## 1. 수출자가 이 챕터를 읽어야 하는 이유

원산지증명서(C/O)는 **수입자가 관세 혜택을 받기 위해 수출자에게 요구하는 서류**. 발급 주체는 수출자이고, 못 만들면 거래가 깨지거나 가격을 깎이게 됨. 수출자가 직접 통제해야 하는 영역.

## 2. FTA 특혜관세 적용 3요건

세 가지가 모두 충족돼야 적용됨. 하나라도 빠지면 혜택 없음.

| # | 요건 | 확인 방법 |
|---|---|---|
| 01 | 상대국과 **FTA 체결/발효** | FTA 포털 |
| 02 | 해당 물품이 **양허 대상** | **HS 6단위** 기준으로 판정 |
| 03 | 수출국이 발행한 **원산지증명서** | 수출자가 발급 |

자주 나오는 오해 3가지.

- **"FTA면 무조건 0%"가 아님.** 협정별/품목별로 양허 대상이 아닌 품목이 존재. 양허율은 상대국 교역 상황에 따라 다름 (채널 예시 — 호주/뉴질랜드는 사실상 100%, 일본은 83% 수준. 수치는 검증 필요).
- **양허 대상이어도 즉시 0%가 아님.** 최대 20년에 걸쳐 단계적으로 철폐되는 품목이 있음.
- **C/O 가 항상 필요한 것도 아님.** WTO 협정관세로 이미 0%면 C/O 없이도 무관세. 기본세율과 협정세율을 비교해 **협정세율이 유리한 경우에만** 발급하면 됨.

C/O 를 요구하는 근본 이유 — 없으면 그 물품이 실제로 그 나라에서 생산된 것인지, 제3국 물품이 우회 수출되는 것인지 구분할 수 없기 때문.

## 3. 발급형식 — 기관발급 vs 자율발급

| 구분 | 기관발급 | 자율발급 |
|---|---|---|
| 발급 주체 | 세관 또는 상공회의소 | **수출자 본인** |
| 사전 심사 | 있음 (보완통보 → 재신청) | 없음 |
| 소요 | 서류 완비 시 반나절 수준 | 즉시 |
| 비용 | 세관(유니패스) 무료 / 상공회의소는 비회원 수수료 | 없음 |
| 장점 | 공신력. 우회수입 방지. **사후조사 대응 용이** | 신속/편리, 비용 절감 |
| 단점 | 절차 복잡, 시간/비용 | 허위증명 가능성. 판정서류를 **스스로 작성/보관**해야 하며 부실 시 원산지조사에서 중처벌 |

자율발급의 함정 — 아무도 서류를 강제하지 않으므로 판정 근거 없이 발행하기 쉬움. 그러나 사후 원산지조사에서 입증하지 못하면 특혜 배제 + 추징. **자율발급일수록 내부 서류관리가 더 중요.**

### 협정별 발급형식

| 발급형식 | 협정 |
|---|---|
| **기관발급** | 한-중 / 한-베트남 / 한-싱가포르 / 한-아세안 / 한-인도 |
| **자율발급** | 한-EU / 한-영 / 한-EFTA / 한-터키 / 한-미 / 한-캐나다 / 한-칠레 / 한-페루 / 한-콜롬비아 / 한-중미 / 한-호주 / 한-뉴질랜드 |
| **원칙 기관발급, 인증수출자 시 자율발급** | RCEP |

검증 필요 — 채널 내 두 자료에서 **한-싱가포르의 분류가 엇갈림**. 한쪽 표는 자율발급, 다른 글은 기관발급 목록에 포함. 설명서 확정 전 FTA 포털에서 재확인할 것.

### 협정 선택 문제

한 나라에 복수 협정이 적용 가능한 경우가 있음.

| 상대국 | 선택 가능 협정 |
|---|---|
| 베트남 | 한-베트남 / 한-아세안 / RCEP |
| 싱가포르 | 한-싱가포르 / 한-아세안 / RCEP |

베트남처럼 결정기준과 세율이 동일하면 어느 쪽으로 발행해도 무방하나, **수입자가 원하는 양식이 있는지 사전 확인**이 필요. 협정마다 결정기준이 다를 수 있으므로 유리한 쪽을 고르는 것도 실무 판단 사항.

## 4. 인증수출자 제도

### 왜 존재하는가

한-EU FTA 는 **별도의 원산지증명서 양식 없이 상업송장 등 상업서류에 원산지 문구를 기재하는 것만으로** 원산지를 인정함 (원산지신고서 방식).

> "The exporter of the products covered by this document (customs authorisation No ...(1)) declares that, except where otherwise clearly indicated, these products are of ...(2) preferential origin"

(1) 에 인증수출자 번호, (2) 에 원산지 국가를 기재.

절차가 극단적으로 간편해진 만큼 부정 수혜 가능성이 커짐. 이를 막기 위해 **인증수출자 제도**를 함께 운영.

### 언제 필수인가

| 협정 | 조건 |
|---|---|
| 한-EU / 한-영 | **건당 6,000유로 초과** 수출 시 인증수출자만 원산지신고서 작성 가능 |
| RCEP | 인증수출자 자격 취득 시 자율발급 가능 |

6,000유로 이하는 인증수출자가 아니어도 원산지신고서 작성 가능. 즉 **소액 수출로 시작하는 단계에서는 인증수출자가 없어도 됨.**

## 5. 원산지 판정 — C/O 발급의 전제

**원산지판정이 먼저, 원산지증명서 발급은 그 다음.** 판정 없이 C/O 는 나오지 않음.

### 5.1 출발점 = BOM

관세사가 수출자에게 가장 먼저 요구하는 것은 **BOM(원재료 명세서)**.

작성 요령 — 완제품에 투입되는 원재료를 **누락 없이** 기재. HS 코드는 아는 것만 기재하고, 원산지/가격 정보는 우선 공란으로 두어도 됨 (판정 단계에서 필요한 만큼만 채움).

### 5.2 원산지결정기준

협정별/HS 6단위별로 기준이 다름. **관세청 FTA 포털 → FTA협정별 원산지결정기준 → 협정 선택 후 HS 코드 입력**으로 조회.

주요 기준 2가지.

| 기준 | 내용 |
|---|---|
| **세번변경기준 (CTC)** | 투입 원재료의 HS 세번과 완제품 세번이 달라지면 그 공정이 일어난 국가를 원산지로 인정. 변경 단위에 따라 CC(2단위) / CTH(4단위) / CTSH(6단위) |
| **부가가치기준 (RVC)** | 역내 부가가치 비율이 기준 이상이면 원산지 인정. 예 — FOB 가격 기준 40% 이상 |

기준이 `CTH 또는 RVC 40%` 처럼 선택형으로 규정되는 경우가 많음. 수출자에게 유리한 쪽을 고르면 됨.

### 5.3 판정 실무 흐름 — 3단계 완충구조

세번변경기준을 먼저 시도하고, 막히면 완충장치를 차례로 적용하는 구조.

| 단계 | 상황 | 대응 | 부담 |
|---|---|---|---|
| **1단계** 세번변경 | 완제품과 **HS 코드가 같은 원재료**가 존재 → 세번변경 불성립 | 그 원재료가 **국내산**이어야 함. 공급자로부터 **원산지확인서** 수취 | 문제 원재료에 대해서만 확인서 필요 (가장 가벼움) |
| **2단계** 미소기준 | 원산지확인서를 못 받는 경우 | 문제 원재료가 전체에서 차지하는 비중이 **10% 이내**면 허용 (최소허용기준) | BOM 에 **가격 정보 전부** 기재 필요 |
| **3단계** 부가가치기준 | 미소기준도 초과 | RVC 로 전환. FOB 가격 기준 **40% 이상 국내산** | **모든 원재료**에 대해 원산지확인서 필요 (가장 무거움) |

실무 원칙 — **최소한의 노력으로 판정이 이루어지도록 1단계에서 끝내는 것이 목표.** 문제 원재료에 대해서만 원산지확인서를 확보하면 됨.

미소기준 10% 등 구체 수치는 협정별로 다를 수 있으므로 협정문 확인 필요.

### 5.4 두 가지 대원칙

| 원칙 | 내용 | 확인 서류 |
|---|---|---|
| **역내가공 원칙** | 원칙적으로 국내에서 가공이 이루어져야 함 | 제조공정도 |
| **충분가공 원칙** | 단순 포장/라벨링 등 단순가공은 원산지를 부여하지 않음 | 제조공정도 |

## 6. 원산지증명서 발급 서류

| # | 서류 | 역할 |
|---|---|---|
| 01 | **BOM (원재료 명세서)** | 판정 기준 확인의 출발점 |
| 02 | **원산지(포괄)확인서** | 특정 원재료가 국내산임을 공급자가 증명. 생산자와 수출자가 다른 경우에도 필요 |
| 03 | **원산지소명서** | 판정 근거 정리 |
| 04 | **제조공정도** | 역내가공/충분가공 원칙 확인 |
| 05 | **거래명세서 / 세금계산서** | BOM 상 원재료가 실제 거래되었음을 증명 |
| 06 | **상업송장 / 포장명세서 / B/L** | 해당 물품이 실제 거래/운송되는 물품임을 증명 |
| 07 | **수출신고필증** | 수출신고가 이루어졌음을 증빙. **전산 연계로 신고번호만 입력하면 자동 반영 → 첨부 생략 가능** |

## 7. 발급 실무에서 사고가 나는 지점

### 7.1 검수 — C/O 는 원칙적으로 1회만 출력

| 항목 | 내용 |
|---|---|
| 출력 제한 | 원산지증명서는 원칙적으로 **한 번만 출력 가능** |
| 출력 전 정정 | 정정신고 후 재승인 받으면 됨 (상대적으로 간단) |
| **출력 후 정정** | 출력된 **원본을 세관에 반환**하는 절차가 추가됨 |

따라서 **출력 전 검수가 결정적**. 확인 항목.

- 수출자/수익자 상호 — **대소문자까지 동일한지**
- 주소 동일 여부
- 품명/HS 코드/수량/금액이 상업송장과 일치하는지
- **출항일자**가 B/L 과 일치하는지

### 7.2 Check B/L 로 승인받은 경우

출항 전 Check B/L(가B/L) 기준으로 C/O 승인을 받는 것이 일반적. 이때 **출항 지연이 발생하거나 B/L 정보가 변경되면 정정승인**을 다시 받아야 함.

권장 절차 — 포워더로부터 마감 후 또는 출항 후 발행되는 **O.B/L 스캔본을 받아 최종 대조한 뒤 출력**.

### 7.3 송장 오류의 연쇄 — 가장 비싼 실수

수출자가 잘못된 상업송장을 보내 C/O 가 잘못 발행되면 정정 범위가 다음처럼 번짐.

```
상업송장 오류
  → 수출신고 정정
  → B/L 정정
  → 적하목록 신고 재신고 (포워더 과태료 가능)
  → 관세사 수출입신고 오류점수 상승 (이후 검사 선별 확률 증가)
  → 이미 발송한 C/O 원본 해외 회수
```

교훈 — **상업송장이 원산지증명서의 기초**이므로 송장 단계에서의 정확성이 전체 비용을 결정. 자동화 설계에서 C/I 를 마스터 데이터로 두는 근거가 여기서도 확인됨.

## 8. 수출설명서 집필 시 처리 방침

| 항목 | 방침 |
|---|---|
| 서술 순서 | 3요건 → 발급형식 → 판정(BOM/결정기준/3단계 완충) → 발급서류 → 검수. 채널의 실무 순서와 동일 |
| 강조점 | "FTA면 무조건 0%"라는 오해를 첫 문단에서 깨는 것 |
| 실익 판단 | 기본세율 vs 협정세율 비교 후 발급 여부 결정. C/O 발급이 항상 정답은 아님을 명시 |
| 인증수출자 | 6,000유로 이하는 불필요 → 초보 수출자는 당장 취득할 필요 없음을 분명히 |
| 검증 필요 | 한-싱가포르 발급형식 / 미소기준 10% / 양허율 수치 / RVC 40% — 전부 FTA 포털 및 협정문 대조 |
| 보강 필요 | 사후 원산지조사(검증) 대응 절차는 채널에 얕음. 관세청 자료 보강 |
