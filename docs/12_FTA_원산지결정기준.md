# FTA 협정별 원산지결정기준 — 미소기준 / RVC / 품목별 기준

`docs/11_법령검증_결과.md` 에서 미검증으로 남겼던 **미소기준**과 **RVC** 를 1차 출처로 대조한 결과.

출처 — **자유무역협정의 이행을 위한 관세법의 특례에 관한 법률 시행규칙 [별표 1~15-11]** (시행 2026-05-01). 국가법령정보센터 OPEN API 로 수집.

---

## 1. 먼저 — "협정별 RVC 몇 %"라는 값은 존재하지 않음

초안이 `RVC 40%` 를 협정 수준 상수처럼 다룬 것은 부정확함.

| 항목 | 실제 성격 |
|---|---|
| **미소기준** | **협정 단위 상수.** 각 협정 별표의 "원산지인정의 최소기준"에 규정 |
| **RVC 기준값** | **품목(HS) 단위 변수.** 같은 협정 안에서도 40% / 45% 등으로 갈림 |
| **RVC 계산식** | **협정 단위.** 집적법/공제법 등 채택 방식이 협정별로 규정됨 |

예 — 한-베트남 협정에서 `0402.10` 은 부가가치 **45%**, `33.04` 는 **40%**. 따라서 "한-베트남 RVC 40%" 라는 서술은 성립하지 않음.

## 2. 미소기준 (원산지인정의 최소기준)

세번변경기준을 충족하지 못해도, 세번변경이 일어나지 않은 비원산지재료가 아래 한도 이하이면 원산지물품으로 인정하는 완충장치.

| 협정 | 일반품목 | 기준가격 | 섬유류 (제50~63류) | 비고 |
|---|---|---|---|---|
| **한-아세안** | **10%** | FOB | 중량 10% | 섬유류는 일반기준 적용 제외 |
| **한-베트남** | **10%** | FOB | 중량 10% | |
| **RCEP** | **10%** | FOB | 중량 10% | 제1~97류 전체 적용 |
| **한-필리핀** | **10%** | FOB | 중량 10% | |
| **한-UAE** | **15%** | **공장도가격** | 중량 또는 공장도가격 **10%** | **다른 협정과 다름** |
| **한-에콰도르** | **10%** | FOB | 중량 10% | **제1~14류 적용 배제**, 제15~24류는 6단위 세번 상이 시에만 적용 |

**"미소기준은 10%"라는 일반화는 위험함.** 한-UAE 는 15%/공장도가격이고, 한-에콰도르는 농산물 상당수를 아예 배제함.

공통 단서 2가지.

- 미소기준을 적용해도 **해당 협정 원산지 챕터의 다른 모든 요건**을 충족해야 함
- **부가가치기준을 적용하는 경우**, 미소기준으로 넘어간 비원산지재료의 가격도 RVC 계산 시 비원산지재료 가격에 **포함**해야 함 (한-필리핀/RCEP/한-UAE/한-에콰도르에 명시)

수집하지 못한 협정 — 나머지 19개 협정의 별표는 법령정보센터에 **이미지(gif)/hwp 로만** 등재되어 텍스트 추출이 불가능함. 해당 협정은 별표 원문(hwp/pdf)을 직접 열어 확인할 것.

## 3. RVC 계산방법

| 협정 | 용어 | 채택 방식 | 특징 |
|---|---|---|---|
| 한-아세안 | 역내부가가치비율 | 집적법 / 공제법 | **수출자가 선택 가능.** 단 동일 회계연도 내 일관 적용 |
| 한-베트남 | 역내부가가치비율 | 집적법 / 공제법 | |
| RCEP | 역내가치포함비율 (RVC) | 직접법(집적법) / 간접법(공제법) | 비원산지재료 가치에서 운송비/관세/폐기물 등 **차감 가능** (입증 시) |
| 한-필리핀 | 역내가치포함비율 | 직접법 / 간접법 | 집적법에 **운송비** 포함 |
| 한-에콰도르 | 역내가치포함비율 | 공제법 / 집적법 | |

### 계산식

```
집적법 (직접법)
  RVC = 원산지재료 가격 ÷ FOB × 100
        ※ RCEP 및 필리핀은 분자에 직접노무비 + 직접경비 + 이윤(+운송비) 포함

공제법 (간접법)
  RVC = (FOB - 비원산지재료 가격) ÷ FOB × 100
```

- **분모는 FOB** (한-UAE 는 공장도가격 기준)
- 가격은 「1994 GATT 제7조의 이행에 관한 협정」(관세평가협정) 결정방식에 따름
- 비원산지재료 가격 — 수입재료는 **CIF**, 국내 획득 재료는 확인 가능한 최초 지불가격

## 4. 품목별 원산지결정기준 데이터셋

텍스트 추출이 가능한 6개 협정의 품목별 기준을 CSV 로 정리함.

**파일 — [`data/fta_psr.csv`](../data/fta_psr.csv)** (4,831행)

| 열 | 내용 |
|---|---|
| `협정` | 한-아세안 / 한-베트남 / RCEP / 한-필리핀 / 한-UAE / 한-에콰도르 |
| `류` `호` `소호` | HS 2/4/6단위 |
| `적용단위` | 실제 기준이 걸리는 단위 |
| `기준` | 원산지결정기준 원문 |

| 협정 | 수집 행수 | 비고 |
|---|---:|---|
| RCEP | 2,188 | |
| 한-베트남 | 1,240 | |
| 한-필리핀 | 1,212 | |
| 한-에콰도르 | 100 | |
| 한-UAE | 48 | |
| 한-아세안 | 43 | 본표가 이미지라 일부만 추출됨 |

### 사용 예

`3304.99` (화장품류) 를 베트남으로 수출하는 경우.

| 협정 | 적용단위 | 기준 |
|---|---|---|
| 한-베트남 | `33.04` | 4단위 세번변경기준 **또는** 체약당사국 내 발생 부가가치 **40% 이상** |
| 한-필리핀 | `33.04` | 동일 |

`forms/BOM_원재료명세서.xlsx` 의 예시(`CTH or RVC 40%`)가 실제 협정 기준과 일치함을 확인함.

### 데이터 한계

- 원본이 고정폭 표라 **줄바꿈으로 잘린 문구를 재결합**한 결과임. 긴 기준은 문장이 매끄럽지 않을 수 있음
- 한-아세안 등 일부 협정은 본표가 이미지라 커버리지가 낮음
- **실제 판정은 반드시 FTA 포털 또는 관세사 확인을 거칠 것.** 이 CSV 는 사전 검토용

## 5. 수출신고필증 코드표 — 출처 확인

`docs/11` 에서 미검증으로 남겼던 항목. 「수출 및 반송통관에 관한 고시」 [별표 1] 수출신고서 작성요령을 확인한 결과.

| 항목 | 고시 기재 |
|---|---|
| 거래구분 | "일반형태수출 등 해당코드를 기재 **(통계부호표 참조)**" — 기재 예 `11` |
| 종류 | "일반/보세공장수출 등 해당코드를 기재 **(통계부호표 참조)**" — 기재 예 `A` |
| 결제방법 | "L/C, 단순송금 등 해당코드를 기재 **(통계부호표 참조)**" — 기재 예 `TT` |
| C/S구분 | 세관기재란이므로 신고인은 **기재 생략** |

**즉 코드값 자체는 고시가 아니라 관세청 「통계부호표」 소관.** 부록 A 의 코드표를 확정하려면 통계부호표를 봐야 함.

다만 고시의 기재 예시로 **`11`(일반형태수출) / `A`(일반수출) / `TT`(단순송금)** 는 확인됨. 초안의 핵심 3개 값은 맞음.
