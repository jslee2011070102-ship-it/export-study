# 인코텀즈 2020 — 11개 규칙 정리

수출설명서 2장(가격조건)의 원본 자료.

구성 —
- 1~2장, 4장(그룹 논리/2020 개정) : 무꿈사TV 인코텀즈 13편(4.3시간) 자막에서 추출
- 3장 규칙별 상세 : 채널 단독 심화편이 있는 4개(EXW/FCA/CIF/DAP)는 자막 기반, 나머지 7개(FAS/FOB/CPT/CIP/CFR/DPU/DDP)는 인코텀즈 2020 체계에 따라 직접 작성

주의 —
- 자동자막 기반이라 원문 인용은 불가하며 구조와 논리만 복원함
- ICC 인코텀즈 2020 은 저작물이라 원문을 확보하지 못했음. 3장의 조문 수준 서술(A1~A10 / B1~B10 대응)은 **`[검증]` — ICC 원문 대조 필요**
- 규칙 이름/그룹/위험이전 지점 같은 골격은 다수 공개자료로 교차 확인되나, 세부 문언은 원문이 우선

---

## 1. 인코텀즈가 정하는 것

인코텀즈는 가격조건이 아니라 **인도조건**. 읽을 때 봐야 할 것은 딱 두 가지.

| 질문 | 의미 |
|---|---|
| 인도가 어디서/언제 이루어지는가 | 그 시점에 **위험이 매도인 → 매수인으로 이전**. 이후 물품의 멸실/손상 책임은 매수인 |
| 운송계약과 운송비는 누가 부담하는가 | 위험이전과 **별개**. 이 둘이 어긋나는 것이 C 규칙 |

핵심 오해 — 운송비를 매도인이 낸다고 위험도 매도인이 지는 게 아님. C 규칙에서 이 둘이 분리됨.

인코텀즈가 **정하지 않는 것**도 명확히 구분할 것.

| 인코텀즈가 정함 | 인코텀즈가 정하지 않음 |
|---|---|
| 인도장소/시점, 위험이전 | 소유권 이전 시점 |
| 운송/보험 계약 체결 의무 | 대금지급 시기/방법 (L/C, T/T 등) |
| 수출입 통관 수속 의무 | 계약 위반 시 구제수단 |
| 서류 제공 의무, 비용 분담 | 물품의 하자/품질 책임 |
| 검사/포장/화인 의무 | 준거법, 분쟁해결 관할 |

## 2. 4개 그룹

앞 글자로 E / F / C / D 4그룹 분류.

| 그룹 | 인도장소 | 운송계약/운송비 | 위험이전 |
|---|---|---|---|
| **E** (EXW) | 매도인 구내 | 매수인 | 물품을 매수인 처분하에 둔 때 |
| **F** (FCA/FAS/FOB) | 수출국 선적지 | **매수인** (착불) | 선적지에서 운송인에게 인도 시 |
| **C** (CPT/CIP/CFR/CIF) | 수출국 선적지 | **매도인** (선불) | 선적지에서 운송인에게 인도 시 |
| **D** (DAP/DPU/DDP) | 수입국 목적지 | 매도인 | 목적지 도착 후 인도 시 |

E/F/C = **선적지 인도** → 운송 중 사고는 매수인 부담.
D = **양륙지 인도** → 운송 중 사고는 매도인 부담.

C 규칙의 함정 — 매도인이 운송비를 내지만 **위험은 선적지에서 이미 넘어감**. 초보가 가장 많이 틀리는 지점.

### 운송방식에 따른 2분류

그룹 분류와 **직교하는 별개의 축**. 규칙을 잘못 고르는 두 번째 원인.

| 구분 | 규칙 | 인도지점의 성격 |
|---|---|---|
| **모든 운송방식** (7개) | EXW, FCA, CPT, CIP, DAP, DPU, DDP | 운송인 교부 / 장소 인도 |
| **해상/내수로 전용** (4개) | **FAS, FOB, CFR, CIF** | 선측 또는 본선 적재 |

해상 전용 4개는 이름에 배(Ship/Board/Freight)가 들어가는 계열. 항공/육상/복합운송, 그리고 **컨테이너 화물**에는 원칙적으로 부적합.

## 3. 규칙별 상세

각 규칙을 동일한 8개 항목으로 정리. 표기 형식은 `규칙 + 지정장소 + Incoterms® 2020`.

---

### 3-1. EXW — Ex Works (공장인도)

표기 예 — `EXW 경기도 화성시 ○○로 12, Incoterms® 2020`

| 항목 | 내용 |
|---|---|
| 인도장소/시점 | 매도인의 구내 또는 지정된 그 밖의 장소에서, **적재하지 않은 상태로** 물품을 매수인 처분하에 둔 때 |
| 위험이전 | 위 시점 |
| 운송계약/운임 | 매수인. 매도인은 의무 없음 |
| 보험 | 양측 모두 의무 없음 |
| 수출통관 | **매수인**. 매도인은 정보/서류 협조만 (비용/위험은 매수인) |
| 수입통관 | 매수인 |
| 양하의무 | 해당 없음 (애초에 적재도 안 함) |
| 운송방식 | 모든 방식 |

매도인 최소의무. 11개 중 매도인 부담이 가장 작음.

실무 논점 2가지.

- **적재의무 없음.** 매도인 구내에는 크레인/지게차가 있어 매도인이 싣는 게 합리적이나, 규칙상 적재는 매수인 의무. 적재 중 사고 시 책임 소재가 다툼이 됨 → 계약서에 "적재는 매도인이 매수인의 위험과 비용으로 수행" 같은 문구를 따로 넣는 방식으로 보정
- **수출통관도 매수인 의무.** 그러나 외국 매수인이 한국 세관에 수출신고를 하는 것은 현실적으로 곤란. 실무에서는 매도인이 대행하는 경우가 대부분 → **EXW 로 계약하되 실제로는 FCA 처럼 운영되는 불일치**가 발생

한국 수출자에게 특히 문제 — 수출신고가 매도인 명의로 되지 않으면 **관세환급/영세율 적용/수출실적 인정**에 문제가 생김. 대안은 FCA.

### 3-2. FCA — Free Carrier (운송인인도)  `[검증]`

표기 예 — `FCA 인천공항 화물터미널, Incoterms® 2020`

| 항목 | 내용 |
|---|---|
| 인도장소/시점 | **지정장소가 어디냐에 따라 2가지로 갈림** (아래 참조) |
| 위험이전 | 위 인도 시점 |
| 운송계약/운임 | 매수인. 다만 매수인 요청 시 매수인의 위험/비용으로 매도인이 대신 체결 가능 |
| 보험 | 양측 모두 의무 없음 |
| 수출통관 | **매도인** |
| 수입통관 | 매수인 |
| 양하의무 | 아래 (b) 의 경우 매도인은 양하하지 않음 (실린 채 인도) |
| 운송방식 | 모든 방식 |

인도 시점 2분기 —

| 지정장소 | 인도 완료 시점 | 적재 주체 |
|---|---|---|
| **(a) 매도인의 구내** | 매수인이 마련한 운송수단에 **적재를 마친 때** | 매도인 |
| **(b) 그 밖의 장소** (CY, 포워더 창고, 공항터미널 등) | 매도인의 운송수단에 **실린 채, 양하 준비된 상태로** 운송인 처분하에 둔 때 | 매도인은 양하하지 않음 |

EXW 와의 차이는 이 두 가지 — **매도인이 수출통관을 하고, (a) 의 경우 적재까지 한다.**

2020 신설 — **본선적재표기 선하증권 옵션.** FCA 는 본선 적재 전에 인도가 끝나므로 매도인이 `on board` 표기 B/L 을 받을 수 없어 신용장 결제에 곤란이 있었음. 2020 은 당사자 합의 시 **매수인이 운송인에게 매도인 앞으로 본선적재 B/L 을 발행하도록 지시**하는 구조를 규정. 다만 운송인이 응할 의무가 있는 것은 아니므로 실무에서는 신용장 문언 조정이 더 확실.

컨테이너 화물의 정답 — 컨테이너는 CY/CFS 에서 운송인에게 넘어가고 본선 적재는 그보다 한참 뒤. 따라서 컨테이너 건은 FOB 가 아니라 **FCA 가 정확**함.

### 3-3. FAS — Free Alongside Ship (선측인도)  `[검증]`

표기 예 — `FAS 부산항, Incoterms® 2020`

| 항목 | 내용 |
|---|---|
| 인도장소/시점 | 지정 선적항에서 매수인이 지정한 **선박의 선측**(부두 위 또는 부선 안)에 물품을 둔 때 |
| 위험이전 | 위 시점. 즉 **본선에 싣기 전** |
| 운송계약/운임 | 매수인 |
| 보험 | 양측 모두 의무 없음 |
| 수출통관 | **매도인** |
| 수입통관 | 매수인 |
| 양하의무 | 해당 없음 |
| 운송방식 | **해상/내수로 전용** |

11개 중 가장 사용 빈도가 낮은 규칙. 한국 수출자가 쓸 일은 드묾.

쓰이는 자리 — 곡물/원목/철광석/석탄 같은 **벌크 화물**, 그리고 크레인으로 들어올려야 하는 **중량물/플랜트 설비**. 선적 작업 자체가 큰 비용/위험이라 그 분기점을 선측으로 잡는 것이 관행인 품목들.

실무 유의점 3가지.

- **컨테이너 화물에 쓰면 안 됨.** 컨테이너는 선측이 아니라 CY 에서 운송인에게 인도됨 → FCA 를 쓸 것
- **선측(alongside)의 정의를 계약서에 명시할 것.** 부두 위인지, 본선 크레인 닿는 범위인지, 부선(barge)에 실은 상태인지가 항구 관행마다 다름
- **본선 도착 지연 리스크가 매도인에게 남음.** 매수인이 지정한 선박이 늦게 들어오면 물품을 부두에 대기시켜야 하고 그 사이 위험은 아직 매도인 몫. 체선/보관비 부담을 별도 약정할 것

FAS 와 FOB 의 차이는 **적재작업(하역) 한 단계뿐**. 그 한 단계의 비용/위험을 누가 지느냐가 전부.

### 3-4. FOB — Free On Board (본선인도)  `[검증]`

표기 예 — `FOB 부산항, Incoterms® 2020`

| 항목 | 내용 |
|---|---|
| 인도장소/시점 | 지정 선적항에서 매수인이 지정한 **본선에 적재한 때** (on board) |
| 위험이전 | 위 시점 |
| 운송계약/운임 | 매수인 (착불) |
| 보험 | 양측 모두 의무 없음 |
| 수출통관 | **매도인** |
| 수입통관 | 매수인 |
| 양하의무 | 해당 없음 |
| 운송방식 | **해상/내수로 전용** |

한국 수출 실무에서 가장 널리 쓰이는 조건. 수출신고 금액의 기준 통화가 FOB 인 것도 이 때문.

실무 유의점 4가지.

- **"본선 난간(ship's rail)" 개념은 폐지됨.** 2010 개정에서 삭제. 난간을 넘는 순간이 아니라 **본선에 적재 완료된 때**가 기준
- **컨테이너 화물에 쓰면 위험 공백이 생김.** 실제 인도는 CY 에서 끝나는데 규칙상 위험은 본선 적재까지 매도인이 짐. 그 사이(CY 반입 → 본선 적재)의 사고는 매도인 부담인데 매도인은 물품을 이미 통제하지 못하는 상태. 정확한 선택은 FCA
- **적재비(선적비) 분담을 확인할 것.** 정기선(컨테이너)은 운임에 하역비가 포함(Liner Term)되나, 부정기선은 FI/FO/FIO 같은 하역조건을 따로 정함. FOB 뒤에 `FOB Stowed`, `FOB Trimmed` 같은 변형이 붙는 이유
- **미국식 FOB 와 혼동 주의.** 미국 국내거래 관행의 `FOB (지명)` 은 인코텀즈 FOB 와 의미가 다름. 계약서에 반드시 `Incoterms® 2020` 을 병기

FOB 가 수출자에게 유리한 점 — 운임/보험을 신경 쓸 필요가 없고 자금 부담이 작음.
불리한 점 — **매수인이 포워더를 지정**하므로 그 운송인의 신용을 확인할 방법이 없음 (무역사기 경로). 상세는 manual/04.

### 3-5. CPT — Carriage Paid To (운송비지급인도)  `[검증]`

표기 예 — `CPT 호치민, Incoterms® 2020`

| 항목 | 내용 |
|---|---|
| 인도장소/시점 | 매도인이 **자신이 계약한 운송인에게 물품을 교부한 때**. 운송인이 복수면 **최초 운송인**에게 교부한 때 |
| 위험이전 | 위 시점 = **수출국 선적지** |
| 운송계약/운임 | **매도인**. 지정 목적지까지 |
| 보험 | 양측 모두 의무 없음 |
| 수출통관 | 매도인 |
| 수입통관 | 매수인 |
| 양하의무 | 매도인 의무 아님. 다만 운송계약상 매도인이 양하비를 부담했다면 매수인에게 별도 청구 불가 |
| 운송방식 | 모든 방식 |

관계식 — **CPT = FCA + 매도인 운송비.**

C 그룹의 핵심 구조. **위험분기점과 비용분기점이 다른 유일한 그룹.**

| 분기점 | 위치 |
|---|---|
| **위험** 분기 | 수출국, 최초 운송인 교부 시 |
| **비용** 분기 | 수입국, 지정 목적지 |

실무 유의점 3가지.

- **장소를 2개 써야 함.** `CPT` 뒤에 붙는 지명은 **목적지(비용분기점)** 임. 위험분기점인 인도장소는 별도로 계약서에 명시하지 않으면 분쟁이 됨. ICC 권고도 두 장소를 모두 특정하라는 것
- **복합운송에서 "최초 운송인" 판단이 관건.** 내륙 트럭 운송을 매도인이 계약했다면 그 트럭 기사에게 넘긴 시점에 이미 위험이 이전됨. 매수인은 물품이 아직 한국 안에 있는데 위험을 지게 됨
- **보험 의무가 없음에 주의.** 위험은 매수인이 지는데 운송 정보는 매도인이 갖고 있음. 매수인이 스스로 부보하려면 매도인에게 운송 명세를 계속 요청해야 함 → 이 불편을 해소한 것이 CIP

### 3-6. CIP — Carriage and Insurance Paid To (운송비/보험료지급인도)  `[검증]`

표기 예 — `CIP 호치민, Incoterms® 2020`

| 항목 | 내용 |
|---|---|
| 인도장소/시점 | CPT 와 동일 (최초 운송인 교부 시) |
| 위험이전 | 위 시점 |
| 운송계약/운임 | 매도인. 지정 목적지까지 |
| 보험 | **매도인 의무.** 매수인을 피보험자로, **최대담보 조건**(협회적하약관 (A) 또는 그에 준하는 수준), 최소 **송장금액의 110%**, 계약통화, 인도지점부터 목적지까지 부보 |
| 수출통관 | 매도인 |
| 수입통관 | 매수인 |
| 양하의무 | CPT 와 동일 |
| 운송방식 | 모든 방식 |

관계식 — **CIP = CPT + 매도인이 매수인을 위해 최대담보 보험 가입.**

2020 최대 변경점. 2010 까지는 CIF 와 같은 **최소담보**였으나 2020 에서 **최대담보로 상향**.

- 상향 이유 — 최소담보(ICC (C)) 는 열거된 사고만 보상해 항공/컨테이너 화물의 실제 손상 유형을 거의 못 담음. 실무에서도 최소담보로 부보하는 사례가 드물었음
- **CIF 는 상향되지 않고 최소담보 유지.** 벌크/원자재 등 전통적 해상거래 관행 때문. **CIP 와 CIF 의 보험 수준이 다르다는 점이 2020 의 핵심 암기 포인트**
- 당사자 합의로 담보 수준을 낮출 수는 있으나, 낮추려면 **계약서에 명시**해야 함

실무 유의점 —

- 보험 부보는 매도인이 하되 **피보험자는 매수인**. 보험증권/증명서를 매수인에게 넘겨야 함 (신용장 건이면 서류 요건에 맞춰야 함)
- 매도인은 보험료를 냈지만 **사고 시 보험금은 매수인이 받음.** 매도인은 이미 위험을 넘긴 상태이므로 정상
- 부보금액 110% 는 매수인의 기대이익 10% 를 가산한 관행. 그 이상 필요하면 매수인이 추가 부보

---

### 3-7. CFR — Cost and Freight (운임포함인도)  `[검증]`

표기 예 — `CFR 호치민항, Incoterms® 2020`

| 항목 | 내용 |
|---|---|
| 인도장소/시점 | 지정 선적항에서 **본선에 적재한 때** (FOB 와 동일) |
| 위험이전 | 위 시점 = **선적항** |
| 운송계약/운임 | **매도인**. 지정 목적항까지 |
| 보험 | 양측 모두 의무 없음 |
| 수출통관 | 매도인 |
| 수입통관 | 매수인 |
| 양하의무 | 매도인 의무 아님. 운송계약상 부담했다면 매수인에게 별도 청구 불가 |
| 운송방식 | **해상/내수로 전용** |

관계식 — **CFR = FOB + 매도인 운임.**

CPT 의 해상 전용 버전. CPT 와 동일한 위험/비용 분리 구조를 가지되, 인도 시점이 "운송인 교부"가 아니라 "**본선 적재**".

실무 유의점 3가지.

- **뒤에 붙는 지명은 목적항.** 위험이전은 선적항에서 일어남. 두 항구를 계약서에 모두 쓸 것
- **양륙비(THC/하역비) 분담을 확인할 것.** 정기선 운임에 포함되는지, 목적항에서 매수인이 별도로 내는지가 항로/선사마다 다름. 이중 부담(매도인 운임에도 포함, 매수인도 청구받음) 사고가 잦음
- **수출신고 시 운임을 공제해 FOB 로 환산해야 함.** 관세사에게 운임 실액을 알려주지 않으면 신고가 진행되지 않음

컨테이너 건은 CFR 대신 **CPT** 를 쓰는 것이 정확 (FOB→FCA 와 같은 이유).

---

### 3-8. CIF — Cost, Insurance and Freight (운임/보험료포함인도)

표기 예 — `CIF 호치민항, Incoterms® 2020`

| 항목 | 내용 |
|---|---|
| 인도장소/시점 | 지정 선적항에서 본선에 적재한 때 |
| 위험이전 | 위 시점 |
| 운송계약/운임 | 매도인. 지정 목적항까지 |
| 보험 | **매도인 의무.** 매수인을 피보험자로, **최소담보 조건**(협회적하약관 (C) 또는 그에 준하는 수준), 최소 **송장금액의 110%**, 계약통화 |
| 수출통관 | 매도인 |
| 수입통관 | 매수인 |
| 양하의무 | CFR 과 동일 |
| 운송방식 | **해상/내수로 전용** |

관계식 — **CIF = CFR + 매도인이 매수인을 위해 최소담보 보험 가입.**

가장 오래되고 가장 널리 알려진 규칙. 다만 **컨테이너 화물에는 CIP 가 정확**함.

실무 유의점 —

- **보험이 최소담보(C 약관)** 라는 점을 매수인에게 알릴 것. 도난/파손 등 흔한 사고가 담보 밖일 수 있음. 매수인이 원하면 (A) 약관으로 올리되 추가보험료 부담 주체를 계약서에 명시
- **CIP 와 헷갈리지 말 것.** 이름 구조가 같아 보험 수준도 같다고 오해하기 쉬움. 2020 이후 CIP=최대 / CIF=최소
- **수출신고 시 운임 + 보험료를 공제해 FOB 산출.** 두 금액 모두 관세사에게 전달 필요

### 3-9. DAP — Delivered at Place (도착지인도)

표기 예 — `DAP 호치민 ○○공단 창고, Incoterms® 2020`

| 항목 | 내용 |
|---|---|
| 인도장소/시점 | 지정 목적지에서 **도착 운송수단에 실린 채, 양하 준비된 상태로** 매수인 처분하에 둔 때 |
| 위험이전 | 위 시점 = **수입국 목적지** |
| 운송계약/운임 | 매도인 |
| 보험 | 의무 없음 (다만 위험을 매도인이 지므로 매도인이 자기 보호를 위해 드는 것이 정상) |
| 수출통관 | 매도인 |
| 수입통관 | **매수인** |
| 양하의무 | **없음** |
| 운송방식 | 모든 방식 |

D 그룹의 기준형. DPU 와 DDP 는 여기에 한 가지씩 더하거나 뺀 것.

실무 유의점 3가지.

- **수입통관은 매수인 몫.** 매수인이 통관을 지연시키면 물품이 목적지에 도달하지 못하고, 그 사이 발생하는 체화료/보관비를 두고 다툼이 생김. 인코텀즈는 이 위험을 매수인이 지도록 정하나 계약서에 명시해두는 편이 안전
- **매도인이 목적지까지의 모든 운송 사고 위험을 짐.** 운송보험을 반드시 들 것 (규칙상 의무는 아니나 실무상 필수)
- **양하비를 운송계약에 포함시켰다면 매수인에게 따로 청구 불가**

---

### 3-10. DPU — Delivered at Place Unloaded (도착지양하인도)  `[검증]`

표기 예 — `DPU 호치민 ○○공단 창고, Incoterms® 2020`

| 항목 | 내용 |
|---|---|
| 인도장소/시점 | 지정 목적지에서 **물품을 양하하여** 매수인 처분하에 둔 때 |
| 위험이전 | 양하 완료 시점 |
| 운송계약/운임 | 매도인 |
| 보험 | 의무 없음 (실무상 필수) |
| 수출통관 | 매도인 |
| 수입통관 | 매수인 |
| 양하의무 | **있음 — 11개 중 유일** |
| 운송방식 | 모든 방식 |

관계식 — **DPU = DAP + 매도인 양하의무.**

2020 개정 사항 — 2010 의 **DAT (Delivered at Terminal)** 를 대체. 변경 내용 2가지.

| 항목 | DAT (2010) | DPU (2020) |
|---|---|---|
| 인도장소 | **터미널로 한정** (부두, 창고, 컨테이너야드, 도로/철도/항공 화물터미널) | **임의의 장소로 확대** — 바이어 공장 앞마당도 가능 |
| 규칙 순서 | DAT → DAP | **DAP → DPU** (양하의무가 더해지는 순서에 맞춤) |

실무 유의점 3가지.

- **양하 가능한 장소인지 먼저 확인할 것.** 매도인이 양하를 책임지므로, 지게차/크레인/램프가 없는 장소를 목적지로 지정하면 매도인이 장비를 수배해야 함. 목적지 지정 전 현장 조건 확인 필수
- **양하 중 사고는 매도인 부담.** 위험이전이 양하 완료 후이므로 하역 중 파손 책임이 매도인에게 남음. DAP 와 갈리는 실질적 차이가 여기
- **"하차"라는 표현이 더 통용됨.** 목적지 도착 운송수단이 대부분 육상차량이라 실무에서는 양하보다 하차로 부름

---

### 3-11. DDP — Delivered Duty Paid (관세지급인도)  `[검증]`

표기 예 — `DDP 호치민 ○○공단 창고, Incoterms® 2020`

| 항목 | 내용 |
|---|---|
| 인도장소/시점 | 지정 목적지에서 **도착 운송수단에 실린 채, 양하 준비된 상태로** 매수인 처분하에 둔 때 (DAP 와 동일) |
| 위험이전 | 위 시점 |
| 운송계약/운임 | 매도인 |
| 보험 | 의무 없음 (실무상 필수) |
| 수출통관 | 매도인 |
| 수입통관 | **매도인.** 수입허가/관세/수입부가세 등 수입 시 부과되는 모든 공과금 포함 |
| 양하의무 | **없음** |
| 운송방식 | 모든 방식 |

관계식 — **DDP = DAP + 매도인 수입통관/관세 부담.**

매도인 최대의무. EXW 의 정반대편.

**DPU 가 아니라 DAP 에 얹은 것**이라는 점이 핵심. 따라서 DDP 에도 양하의무는 없음. `DAP → DPU → DDP` 순으로 의무가 커진다고 오해하기 쉬운 지점.

| 규칙 | 양하 | 수입통관 |
|---|---|---|
| DAP | X | 매수인 |
| DPU | **O** | 매수인 |
| DDP | X | **매도인** |

실무 유의점 4가지.

- **수입국 부가세 문제.** 매도인이 수입국에 사업자 등록이 없으면 납부한 수입부가세를 매입세액으로 환급받지 못함. 그대로 원가가 됨. 이 때문에 실무에서는 `DDP VAT unpaid` 같은 변형을 쓰나 인코텀즈 규칙에는 없는 표현이라 반드시 계약서에 정의할 것
- **수입국에서 수입자 자격이 필요한 경우가 많음.** 비거주자가 수입신고인이 될 수 없는 나라가 있고, 특정 품목은 현지 인증/등록이 있어야 통관됨. 계약 전 확인 필수
- **관세율/세제 변동 위험이 매도인에게 있음.** 견적 시점과 통관 시점 사이에 세율이 바뀌면 매도인이 흡수. 장납기 건은 위험 큼
- **대안 — DAP 로 계약하고 관세만 별도 정산.** DDP 의 부담 대부분은 통관 자체가 아니라 세무/자격 문제이므로, DAP + "관세는 매도인이 매수인에게 보전" 방식이 더 안전한 경우가 많음

## 4. 2020 개정 핵심

| 항목 | 2010 | 2020 |
|---|---|---|
| DAT → DPU | DAT (Delivered at Terminal) | **DPU 로 명칭 변경.** 터미널에 한정하지 않고 임의의 장소로 확대 |
| CIP 보험 | 최소담보 | **최대담보로 상향** |
| CIF 보험 | 최소담보 | 최소담보 **유지** |
| FCA 본선적재 B/L | 규정 없음 | 당사자 합의 시 매수인이 운송인에게 **본선적재표기 B/L** 발행 지시하는 옵션 신설 `[검증]` |
| 자가 운송수단 | 제3자 운송인 전제 | FCA/DAP/DPU/DDP 에서 **자기 운송수단 사용**을 명시적으로 허용 `[검증]` |
| 비용 조항 정리 | 여러 조항에 분산 | A9/B9 에 **비용 일람**으로 집약 `[검증]` |
| 규칙 배열 | DAT → DAP | **DAP → DPU** |

CIP 만 상향된 배경 — 최소담보 조건에서는 사고 시 보상이 실질적으로 안 되는 문제가 있었고, 실무에서도 최소담보로 부보하는 사례가 거의 없었음. 다만 CIF 는 벌크/원자재 등 전통적 해상거래 관행을 고려해 유지.

## 5. 수출설명서 집필 시 처리 방침

| 항목 | 방침 |
|---|---|
| 서술 순서 | E → F → C → D. 채널과 동일. 그룹 논리가 개별 암기보다 효율적 |
| 강조점 | C 규칙의 위험/비용 분리를 별도 지면으로 처리 |
| 수출자 관점 | EXW/FCA/FOB 가 압도적으로 많음. 이 3개를 두껍게, 나머지는 비교표 |
| 연결 항목 | 인코텀즈 조건 → 상업송장 가격조건 표기 → 수출신고필증 결제금액(FOB 환산) 으로 이어짐. 자동화 설계와 직결 |
| 컨테이너 지적 | FOB/CFR/CIF → FCA/CPT/CIP 로 바꿔야 한다는 지적을 각 절에 반복 배치. 초보가 가장 자주 틀리는 실무 오류 |
| 출처 구분 | 3장 중 EXW/FCA/CIF/DAP 는 채널 심화편 기반, 나머지 7개는 직접 작성분 → `[검증]` 유지 |
