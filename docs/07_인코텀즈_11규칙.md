# 인코텀즈 2020 — 11개 규칙 정리

수출설명서 2장(가격조건)의 원본 자료. 무꿈사TV 인코텀즈 13편(4.3시간) 자막에서 추출.

주의 — 자동자막 기반이라 원문 인용은 불가하며 구조와 논리만 복원함. 조문 수준 확정은 ICC 인코텀즈 2020 원문 대조 필요.

---

## 1. 인코텀즈가 정하는 것

인코텀즈는 가격조건이 아니라 **인도조건**. 읽을 때 봐야 할 것은 딱 두 가지.

| 질문 | 의미 |
|---|---|
| 인도가 어디서/언제 이루어지는가 | 그 시점에 **위험이 매도인 → 매수인으로 이전**. 이후 물품의 멸실/손상 책임은 매수인 |
| 운송계약과 운송비는 누가 부담하는가 | 위험이전과 **별개**. 이 둘이 어긋나는 것이 C 규칙 |

핵심 오해 — 운송비를 매도인이 낸다고 위험도 매도인이 지는 게 아님. C 규칙에서 이 둘이 분리됨.

## 2. 4개 그룹

앞 글자로 E / F / C / D 4그룹 분류.

| 그룹 | 인도장소 | 운송계약/운송비 | 위험이전 |
|---|---|---|---|
| **E** (EXW) | 매도인 구내 | 매수인 | 물품을 매수인 처분하에 둔 때 |
| **F** (FCA/FAS/FOB) | 수출국 선적지 | **매수인** (착불) | 선적지에서 운송인에게 인도 시 |
| **C** (CPT/CIP/CFR/CIF) | 수출국 선적지 | **매도인** (선불) | 선적지에서 운송인에게 인도 시 |
| **D** (DAP/DPU/DDP) | 수입국 목적지 | 매도인 | 목적지 도착 후 인도 시 |

E/F/C = **선적지 인도** → 운송 중 사고는 매수인 부담.
D = **양륙지 인도** → 운송 중 사고는 매도인 부담.

C 규칙의 함정 — 매도인이 운송비를 내지만 **위험은 선적지에서 이미 넘어감**. 초보가 가장 많이 틀리는 지점.

## 3. 규칙별 정리

### E 그룹

| 규칙 | 인도장소 | 특징 |
|---|---|---|
| **EXW** (Ex Works) | 물품이 현재 있는 장소 (매도인 공장/창고/작업장) | **매도인 최소의무**. 운송/통관 모두 매수인 |

EXW 실무 논점 2가지.

- **적재의무 없음.** 매도인 구내에는 크레인/지게차가 있어 매도인이 싣는 게 합리적이나, 규칙상 적재는 매수인 의무.
- **수출통관도 매수인 의무.** 그러나 외국 매수인이 한국 세관에 수출신고를 하는 것은 현실적으로 곤란. 실무에서는 매도인이 대행하는 경우가 대부분 → **EXW 로 계약하되 실제로는 FCA 처럼 운영되는 불일치**가 발생.

### F 그룹 — 매수인이 운송계약/운송비 부담 (착불)

| 규칙 | 인도장소 | 운송방식 |
|---|---|---|
| **FCA** | 수출국 합의된 장소에서 운송인에게 인도 | 모든 운송방식 |
| **FAS** | 지정 선적항 선측 | 해상 전용 |
| **FOB** | 본선 적재 시점 | 해상 전용 |

### C 그룹 — 매도인이 운송계약/운송비 부담, 위험은 선적지 이전

| 규칙 | 관계식 | 보험 |
|---|---|---|
| **CPT** | FCA + 매도인 운송비 | 없음 |
| **CIP** | CPT + 매도인이 매수인을 위해 보험 가입 | **필수 / 최대담보** |
| **CFR** | FOB + 매도인 운송비 | 없음 |
| **CIF** | CFR + 매도인이 매수인을 위해 보험 가입 | **필수 / 최소담보** |

보험이 C 그룹에만 붙는 이유 — 위험은 매수인이 지는데 운송계약 정보는 매도인만 갖고 있음. 매수인이 보험에 가입하려 해도 운송 정보가 없어 매번 매도인에게 요청해야 하는 불편이 생김. 그래서 **매수인 이름으로 매도인이 가입**하는 CIP/CIF 가 만들어짐.

인코텀즈에서 보험은 원칙적으로 **옵션**. 가운데 `I`(Insurance)가 들어가는 CIP/CIF 만 필수.

### D 그룹 — 양륙지 인도

| 규칙 | 인도 | 양하(하차)의무 | 수입통관/관세 |
|---|---|---|---|
| **DAP** (Delivered at Place) | 목적지 합의장소, 도착 운송수단 위 | 없음 | 매수인 |
| **DPU** (Delivered at Place Unloaded) | 목적지 합의장소, **내려놓은 상태** | **있음** | 매수인 |
| **DDP** (Delivered Duty Paid) | 목적지 합의장소, 도착 운송수단 위 | 없음 | **매도인** (관세/부가세까지) |

- **DPU 는 인코텀즈 11개 중 유일하게 매도인에게 양하의무가 있는 규칙.** 목적지 도착 운송수단이 대부분 육상차량이므로 실무에서는 "하차"라는 표현이 더 통용됨.
- **DDP 는 DPU 가 아니라 DAP 에 통관의무가 더해진 것.** 따라서 DDP 에도 양하의무는 없음. 순서를 DAP → DPU → DDP 로 오해하기 쉬운 지점.
- DDP = **매도인 최대의무** (EXW 의 반대편).

## 4. 2020 개정 핵심

| 항목 | 2010 | 2020 |
|---|---|---|
| DAT → DPU | DAT (Delivered at Terminal) | **DPU 로 명칭 변경.** 터미널에 한정하지 않고 임의의 장소로 확대 |
| CIP 보험 | 최소담보 | **최대담보로 상향** |
| CIF 보험 | 최소담보 | 최소담보 **유지** |

CIP 만 상향된 배경 — 최소담보 조건에서는 사고 시 보상이 실질적으로 안 되는 문제가 있었고, 실무에서도 최소담보로 부보하는 사례가 거의 없었음. 다만 CIF 는 벌크/원자재 등 전통적 해상거래 관행을 고려해 유지.

## 5. 수출설명서 집필 시 처리 방침

| 항목 | 방침 |
|---|---|
| 서술 순서 | E → F → C → D. 채널과 동일. 그룹 논리가 개별 암기보다 효율적 |
| 강조점 | C 규칙의 위험/비용 분리를 별도 지면으로 처리 |
| 수출자 관점 | EXW/FCA/FOB 가 압도적으로 많음. 이 3개를 두껍게, 나머지는 비교표 |
| 연결 항목 | 인코텀즈 조건 → 상업송장 가격조건 표기 → 수출신고필증 결제금액(FOB 환산) 으로 이어짐. 자동화 설계와 직결 |
| 보강 필요 | **FAS 는 채널에 단독 콘텐츠 없음.** 개별 심화편도 EXW/FCA/CIF/DAP 4개뿐이라 나머지 7개는 ICC 원문 기준으로 직접 작성해야 함 |
