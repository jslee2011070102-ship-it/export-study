# 수출설명서 설계안 + 문서자동화 대상 정의

1단계 채널 분석 결과를 바탕으로 한 다음 단계 제안. 확정안이 아니라 검토용 초안.

## 1. 독자 정의

| 항목 | 설정 |
|---|---|
| 주 독자 | 수출 경험 0~2건. 사업자등록은 있으나 통관고유부호도 모르는 단계 |
| 보조 독자 | 수출 담당으로 배치된 신입/전배 실무자 |
| 독자가 실제로 막히는 지점 | 채널 조회수가 그대로 신호. 인코텀즈 / 신용장 / B/L / 무역서류 / 통관절차 5개에 조회수가 집중됨 |
| 설명서가 답해야 할 첫 질문 | "지금 당장 무엇부터 하면 되나" — 절차 순서와 담당 주체를 먼저 고정 |

## 2. 설명서 목차안

채널의 `왕초보 무역실무` 재생목록 순서와 `무역에 등장하는 모든 무역서류 1부 수출서류편` 챕터 순서를 결합한 구성. 총 4부 13장.

|---|---|---|

| 01 | 무역 기초용어 30개 | M01 |

| 장 | 제목 | 근거 모듈 |

| 03 | 결제조건 선택 — T/T / L/C / D/A / D/P 비교 | M12 |
| 04 | 오퍼/계약과 무역사기 회피 | M03 |

### 2부 — 선적 전에 하는 일

| 장 | 제목 | 근거 모듈 |

### 3부 — 선적과 그 이후

| 장 | 제목 | 근거 모듈 |
|---|---|---|
| 10 | 포워더 선정과 선적 — B/L / AWB / 운임 항목 | M10 |

## 4. 문서자동화 대상 정의

수출 실무에서 반복 발생하는 문서작업을 3계층으로 구분.

### 계층 1 — 생성 (Generate)

수출자가 직접 만들어야 하는 문서. 자동화 효과가 가장 큼.

| 대상 | 입력 | 출력 | 비고 |
|---|---|---|---|
| 상업송장 (C/I) | 거래 마스터(수출자/바이어/품목/단가/수량/인코텀즈/결제조건) | C/I (xlsx, pdf) | **1순위**. 법정 양식 없음 = 자유 설계 가능 |
| 포장명세서 (P/L) | C/I + 포장정보(포장방법/순중량/총중량/포장개수) | P/L | C/I 와 90% 동일 → **C/I 에서 파생 생성** |
| 오퍼시트 | 거래 마스터 | Offer Sheet | 계약 전 단계 |
| 환어음 | C/I + L/C 정보 | Draft | L/C 거래 시 |
| 선적통지 (Shipping Advice) | C/I + B/L | 메일 초안 | 바이어 통지 자동화 |

핵심 설계 판단 — **상업송장이 마스터 데이터**. 포장명세서/원산지증명서/수출신고서가 전부 C/I 에서 파생됨. 채널이 반복 강조하는 "원산지증명서는 상업송장을 기초로 작성되므로 정보가 절대적으로 일치해야 한다"가 이를 뒷받침. 따라서 자동화는 **C/I 를 단일 원천으로 두고 나머지를 파생시키는 구조**로 가야 정합성 문제가 원천 차단됨.

### 계층 2 — 추출 (Parse)

외부에서 받는 문서를 읽어 데이터화.

| 대상 | 난도 | 활용 |
|---|---|---|
| 수출신고필증 (수출면장) | 중 | 신고번호/HS/FOB금액/적재기한 추출 → 적재기한 알림, 부가세/환급 자료 |
| B/L / AWB | 중 | 선적일/운송서류번호/Notify Party 추출 → 선적통지, 대금청구 트리거 |
| 운임인보이스 | 중 | 비용 항목(THC/BAF/DOC FEE 등) 분해 → 원가 집계 |
| 바이어 P/O | 중 | C/I 자동 초안 생성 |

### 계층 3 — 검증/알림 (Validate & Alert)

문서 생성보다 사고 예방 효과가 큰 영역. [03_수출지식맵.md](03_수출지식맵.md) 5장 함정 10선이 그대로 규칙이 됨.

| 규칙 | 트리거 |
|---|---|
| 적재기한 D-7 알림 | 수출신고필증 수리일 + 30일 |
| 신고중량 vs 실제중량 대조 | 수출면장 중량 ↔ P/L 또는 B/L 중량 |
| C/I ↔ C/O 정보 일치 검증 | 수출자/수입자/품명/HS/금액/원산지 |
| C/I ↔ 수출면장 크로스체크 | 채널이 명시적으로 권고하는 절차 |
| 인코텀즈 조건별 필수서류 체크 | CIF/CIP → 보험증권 필수 등 |
| 결제방식별 필수서류 체크 | L/C → 환어음/선적서류 세트 |

### 우선순위 제안

> 1단계 C/I → P/L 생성 (계층 1) → 2단계 수출면장 파싱 + 적재기한 알림 (계층 2, 3) → 3단계 C/O 파생 및 정합성 검증 → 4단계 B/L 및 운임인보이스 파싱, 원가 집계

C/I & P/L 생성만으로도 초보 수출자가 가장 자주 하는 반복작업이 해결되고, 이후 계층이 전부 같은 마스터를 재사용하므로 확장 비용이 낮음.
