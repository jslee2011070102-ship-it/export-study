## 2. 정정 — 초안이 틀렸던 것

### 2.1 관세환급 신청기한 : 2년 → **5년**

> 환급특례법 제14조제1항 — 관세등을 환급받으려는 자는 물품이 **수출등에 제공된 날부터 5년 이내**에 관세청장이 지정한 세관에 환급신청을 하여야 한다.

채널(및 연계 블로그)은 2년으로 설명하나 현행법은 5년. 초안이 "관세법상 다른 환급은 5년인데 환급특례법은 2년"이라고 대비시킨 것도 함께 폐기.

**원재료 소급 기간 2년(제9조)** 과 **환급신청 기한 5년(제14조)** 은 별개 규정이므로 혼동하지 말 것.

### 2.2 간이정액환급 대상 : 6억원 → **8억원**

> 환급특례법 시행규칙 제12조 — 중소기업자로서 ① 직전 2년간 매년도 환급실적 **8억원 이하** ② 해당 연도 환급신청일까지의 환급실적 **8억원 이하**

### 2.6 적재기한 계산 — 휴일 순연 누락

초안과 `automation/validate.py` 는 **수리일 + 30일**을 그대로 기한으로 삼았음. 틀렸음.

| 근거 | 내용 |
|---|---|
| 관세법 제251조제1항 | 수출신고가 수리된 물품은 **수리일부터 30일 이내**에 운송수단에 적재 |
| 관세법 제8조제2항 | 기간의 계산은 이 법에 특별한 규정이 있는 것을 제외하고 **「민법」에 따름** |
| **관세법 제8조제3항** | **기한이 아래에 해당하면 그 다음 날이 기한** — 1. 토요일 및 일요일 / 2. 「공휴일에 관한 법률」에 따른 공휴일 및 대체공휴일 / 3. 「노동절 제정에 관한 법률」에 따른 노동절 / 4. 그 밖에 대통령령으로 정하는 날 |
| 관세법 제8조제4항 | 국가관세종합정보시스템 장애로 기한 내 처리 불가 시 **복구된 날의 다음 날** |

실제 수출신고필증으로 검증.

| 항목 | 값 |
|---|---|
| 신고수리일자 | 2025-01-09 (목) |
| 수리일 + 30일 | 2025-02-08 **(토)** |
| 제8조제3항 순연 | 02-08 토 → 02-09 일 → **02-10 (월)** |
| **필증 표기 적재의무기한** | **2025/02/10** |

계산값이 필증 표기와 정확히 일치. `적재기한 = 수리일 + 30일` 단순 계산은 **연중 2/7 확률로 틀림**(30일째가 토·일인 경우) + 공휴일까지 겹치면 더 밀림.

반영 — `data/공휴일.csv` (2025~2027) 신설, `validate.py` LOAD 규칙 및 `parse_declaration.py` 가 순연 로직 사용. 다만 **필증에 인쇄된 적재의무기한이 정본**이므로 파서는 계산값을 대조용으로만 씀.

시행일 — 관세법 2026-08-11.

#### 2.8.1 가격조건(인도조건) — DPU 부재

| 출처 | 내용 |
|---|---|
| 고시 별표1 작성요령 (시행 2026-06-26) | EXW/FAS/FCA/FOB/CFR/CIF/CPT/CIP/DAP/**DPU**/DDP — 11개 |
| CLIP `가격조건코드` (운영) | 17종. **DPU 없음.** `25 DAT` 존치. 폐지 조건 `14 C&I` `20 DES` `21 DEQ` `22 DAF` `24 DDU` 잔존 |

판단 —
- 필증 실물에는 숫자가 아니라 알파벳이 인쇄됨 (`EXW-KRW-1,124,200.00`) → 숫자 코드표는 다른 용도의 레거시일 개연성
- 법적 근거는 고시 별표1 이므로 **실무는 11개 규칙 기준**
- 다만 DPU 신고 가능 여부는 `[검증]` 대상. 첫 DPU 건이면 관세사 사전 확인 필요
- 반영 — `parse_declaration.py` DEC-20 을 2단으로 분리. 폐지 조건은 WARN(신고는 통과 가능), 그 밖의 미등록 표기는 ERROR

### 2.10 원산지증명서 발급방식 — 협정 분류 정정

> FTA특례법 시행규칙 제7조 (원산지증명서의 발급방식)

**기관발급과 자율발급이 병존하는 협정이 다수 존재함.** 초안처럼 협정을 둘 중 하나로만 나눈 것은 부정확.

| 구분 | 협정 |
|---|---|
| **기관발급만** | 싱가포르 / 아세안 / 인도 / 베트남 / 중국 / 인도네시아 |
| **자율발급만** | 칠레 / EU / 페루 / 미국 / 튀르키예 / 콜롬비아 / 캐나다 / 뉴질랜드 / 중미 / 영국 |
| **양쪽 병존** | **호주 / 이스라엘 / RCEP / 캄보디아 / 필리핀 / UAE / 에콰도르** |
| 특수 | EFTA — 원칙 자율발급, 단 **스위스 치즈**는 기관발급 |

추가 정정 3건.

- **RCEP** — 인증수출자의 자율발급 외에, **호주/일본/뉴질랜드** 상대 거래는 인증수출자가 아니어도 수출자 또는 생산자가 자율 작성 가능 (제7조제2항제15호의2)
- **한-미 FTA** — 수출자/생산자뿐 아니라 **수입자도** 작성 가능 (제7조제2항제6호)
- **이스라엘** — 자율발급 기준이 6천유로가 아니라 **미화 1천달러 이하** (제7조제2항제14호나목)
- 법령 표기는 `터키` 가 아니라 **`튀르키예`**

### 2.11 6천유로의 계산 단위

초안은 "건당"으로 기재. 규칙의 정확한 표현은 아래.

> 물품의 총가격은 **단일 운송서류**(운송서류가 없는 경우에는 송품장)에 의하여 **단일 수출자로부터 단일 수하인에게 송부된 물품의 총가격**을 기준으로 계산한다. 동시에 송부된 물품이 여러 개인 경우에는 그 합계.

또한 유로화 외의 통화로 작성된 경우 **관세청장이 게시하는 환산금액**을 적용하며, 그 금액은 게시한 해의 다음 해 1월 1일부터 12월 31일까지 적용됨.

| 기획재정부장관 | **재정경제부장관** |
| 산업통상자원부장관 | **산업통상부장관** |

### 2.13 수출신고인 범위

> 고시 제5조 — 수출신고는 **수출화주 또는 관세사등**의 명의로 하여야 하며, **화주에게 해당 수출물품을 제조하여 공급한 자**의 명의로도 할 수 있다.

초안은 "관세사 대행 또는 자가신고" 2가지로만 서술. 제조자 명의 신고가 제3의 선택지로 존재함.

## 4. 검증 방법 (재현 가능)

국가법령정보센터 OPEN API 사용. 별도 인증키 없이 `OC=test` 로 조회 가능.

```
https://www.law.go.kr/DRF/lawService.do?OC=test&target=law&type=XML&LM=<법령명>
https://www.law.go.kr/DRF/lawSearch.do?OC=test&target=admrul&type=XML&query=<검색어>
https://www.law.go.kr/DRF/lawService.do?OC=test&target=admrul&type=XML&ID=<행정규칙일련번호>
```

`target` 값 — `law`(법령) / `admrul`(행정규칙, 고시 및 훈령).
