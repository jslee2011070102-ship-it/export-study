# 수출 지식맵 — 영상/블로그에서 추출한 절차/서류 체계

무꿈사TV 수출 관련 145편과 연계 블로그 73건에서 추출한 수출 실무 구조. 수출설명서 본문의 뼈대이자, 문서자동화 대상 정의의 근거.

주의 — 아래 수치/코드/기한은 채널이 게시 시점에 설명한 내용 기준. 설명서로 확정 집필하기 전에 관세청 고시 원문(수출통관 사무처리에 관한 고시 등)과 대조 검증 필요. 특히 2019~2022년 영상 기반 항목은 개정 확인 필수.

---

## 1. 수출 1건의 표준 흐름

채널이 반복적으로 제시하는 골격은 **3단계**로 압축됨.

> ① 수출신고 → ② 화물반입 및 혼재(포장)작업 → ③ 선적 및 선하증권 발행

실무 기준으로 풀면 7단계.

| # | 단계 | 주 수행자 | 산출물 | 관련 모듈 |
|---|---|---|---|---|
| 0 | 사전등록 (1회성) | 수출자 | 사업자 통관고유부호 / 해외거래처부호 | M05 |
| 1 | 계약/오퍼 확정 | 수출자 ↔ 바이어 | Offer Sheet / Purchase Order / 인코텀즈 조건 확정 | M02 M03 |
| 2 | 서류 작성 | 수출자 | 상업송장(C/I) / 포장명세서(P/L) | M04 |
| 3 | 수출신고 | 관세사 (또는 유니패스 자가신고) | 수출신고필증(적재전) | M06 |
| 4 | 원산지증명 | 관세사/상공회의소/세관 | 원산지증명서(C/O) | M09 |
| 5 | 운송계약/선적 | 포워더 | B/L 또는 AWB / 운임인보이스 | M10 |
| 6 | 적재확인 | 관세사 | 수출신고필증(수출이행) | M06 |
| 7 | 대금회수/사후 | 수출자/은행 | 환어음 / 선적서류 / 부가세 영세율 / 관세환급 | M12 M08 M15 |

핵심 포인트 3가지.

- **수출신고에는 운송서류가 필요 없음.** 수입과 결정적으로 다른 지점. 수출은 수출신고 후에 운송계약을 맺으므로 B/L 또는 AWB 없이 신고 가능. 필요한 건 상업송장과 포장명세서뿐.
- **수출신고 수리일부터 30일 이내 적재 의무.** 미이행 시 과태료. 기간 내 불가하면 적재기간 연장신청.
- **적재 후 면장을 다시 받아야 함.** 적재 전에는 `수출신고필증(적재전)`, 적재 후에는 `수출신고필증(수출이행)`. 실제 선적했는데 신고중량과 실제중량 차이로 미선적 처리되어 과태료를 무는 사고가 잦음.

## 2. 단계별 상세

### 2.0 사전등록

| 항목 | 내용 |
|---|---|
| 사업자 통관고유부호 | 수출/수입 불문 무역의 전제. 관세청이 업체별로 수출입을 관리하는 키. 유니패스에서 발급 |
| 업종 제한 | 없음. 사업자등록만 되어 있으면 업종이 무역/도소매가 아니어도 신청 가능 |
| 개인 직구용 부호와의 관계 | 완전 별개. 혼동 금지 |
| 해외거래처부호 | 상대 바이어(구매자)를 유니패스에 등록. 미등록 시 수출신고서 작성 불가. 제3자가 이미 등록해둔 부호도 사용 가능 |

### 2.1 수출신고 대상 판단

| 구분 | 기준 |
|---|---|
| 원칙적 생략 가능 | 환급대상이 아닌 **FOB 200만원 이하** 물품. 송품장/간이통관목록 제출로 갈음 (수출통관 사무처리에 관한 고시 제36조 목록통관) |
| 반드시 신고 | ① FOB 200만원 초과 ② 관세환급 대상 ③ 수출승인(요건) 필요 물품 |
| 소액이어도 신고하는 이유 | 부가가치세 영세율/조기환급 + **수출실적 인정** (정부지원/은행 대출에 직결) |

채널 결론 — 관세환급 실익은 소액에서 미미하나, **부가세 환급과 수출실적** 때문에 가능하면 신고하는 편이 유리.

### 2.2 신고 장소 / 시기

- 수출신고는 **현재 물품이 있는 장소(물품소재지)의 관할세관**. 사업장 소재지도, 선적 항구도 아님.
- 물품소재지를 실제와 다르게 신고하면 검사 시 적발되어 과태료.
- 관세사에게 반드시 명확히 전달해야 할 두 가지 = **물품소재지 / 적재예정보세구역**.

### 2.3 신고 방법 선택

| 방식 | 특징 |
|---|---|
| 관세사 대행 | 실무 표준. 수입신고는 가격신고까지 얽혀 사실상 필수 |
| 유니패스 자가신고 | 수출은 상대적으로 단순해 가능. 다만 채널 진행자(관세사 본인)조차 "시간당 최저시급이 안 나온다"고 평가. 아주 가끔 한 건씩 하는 경우가 아니면 비권장 |

자가신고 화면 구성은 **공통사항1 → 공통사항2 → 란사항** 3부로 나뉘고, 채널에 각 단계별 화면 해설 영상/포스팅이 모두 존재. 자동화 설계 시 이 3분할이 그대로 입력 폼 구조가 됨.

### 2.4 검사

| 종류 | 내용 |
|---|---|
| 신고지검사 | 수출신고한 물품소재지에 방문 검사. 반송물품/계약상이물품/재수출물품/원상태수출물품 등 |
| 적재지검사 | **원칙**. 적재지 보세구역에서 검사 |
| 걸리기 쉬운 케이스 | 첫 수출 / 불법/도난 가능성 있는 중고물품 |
| 비용 | 적재지검사를 받은 중소/중견기업 컨테이너 화물은 검사 후 1개월 내 유니패스에서 검사비용 환급 신청 가능 |

수출은 수입보다 검사 확률이 낮음. C/S 구분상 대부분 `[A] 수출검사생략`.

### 2.5 원산지증명서

- 발급 주체 = **수출자**. 자체 발행 또는 관세사 대행.
- 발급 시점 = 수출신고 직전 또는 직후. 소급발급도 가능하나, 원칙은 수입자가 수입신고 시 제출할 수 있도록 사전 처리.
- 원산지증명서는 **상업송장을 기초로 작성**되므로 송장 정보와 절대적으로 일치해야 함. → 자동화 관점에서 C/I 가 마스터 데이터.
- 수입국 통관 시 우리나라는 사본으로도 FTA 특혜관세 적용 가능(수입 방향 기준).
- 물품에 따라 발급에 시간이 오래 걸릴 수 있어 사전 요청 필수.

## 3. 수출 서류 전체 목록

| 서류 | 약어 | 작성/발행 주체 | 시점 | 성격 | 자동화 난도 |
|---|---|---|---|---|---|
| 오퍼시트 | Offer Sheet | 수출자 | 계약 전 | 청약 | 낮음 |
| 주문서 | P/O | 수입자 | 계약 | 승낙 | 낮음 (수신 파싱) |
| 상업송장 | C/I | **수출자** | 계약 확정 직후 | 거래 내역서. 정해진 법정 양식 없음 | **낮음 — 1순위 자동화 대상** |
| 포장명세서 | P/L | **수출자** | 포장 완료 후 | C/I 와 90% 동일. 단가/총액 대신 순중량/총중량 | **낮음 — C/I 에서 파생 생성** |
| 수출신고서 | - | 관세사 또는 자가 | 신고 | 유니패스 입력 | 중간 (코드 매핑 필요) |
| 수출신고필증(적재전) | 수출면장 | 세관 | 수리 시 | 신고서의 결과물 | 파싱 대상 |
| 원산지증명서 | C/O | 수출자/발급기관 | 신고 전후 | FTA 특혜용. C/I 기준 작성 | 중간 |
| 선하증권 | B/L | 선사/포워더 | 선적 후 | 유가증권. 권리증권 | 파싱 대상 |
| 항공화물운송장 | AWB | 항공사/포워더 | 기적 후 | 단순 운송장. 유가증권 아님 | 파싱 대상 |
| 운임인보이스 | - | 포워더 | 선적 전후 | 인코텀즈 무관하게 반드시 요청 | 파싱 대상 |
| 적하보험증권 | Insurance Policy | 보험사 | CIF/CIP 시 | 수출자 부담 조건에서 발행 | 낮음 |
| 수출신고필증(수출이행) | - | 세관 | 적재 후 | 적재 확인분. 부가세/환급 근거 | 파싱 대상 |
| 환어음 | Draft/B/E | 수출자 | 대금청구 | L/C, D/A, D/P 방식에서 사용 | 낮음 |
| 구매확인서 | - | 외국환은행/무역협회 | 국내 공급 시 | 간접수출 인정 → 영세율/수출실적 | 중간 |

채널이 정리한 서류 등장 순서(35분짜리 `무역에 등장하는 모든 무역서류 1부 수출서류편` 챕터 기준)는 다음과 같음. 설명서 목차와 그대로 대응시킬 수 있음.

> Offer Sheet → P/O → Commercial Invoice → Packing List → 수출신고필증(적재 전) → B/L → AWB → 보험증권 → 원산지증명서 → 수출신고필증(적재 후) → 송금(T/T) → 추심(Collection) → 신용장(L/C)

## 4. 수출신고필증 항목 체계

자동화의 핵심 표. 채널의 `수출신고필증(수출면장) 해석하기`(17,968자) 기준으로 정리. 총 57개 이상의 번호 항목으로 구성되며, 주요 코드값은 아래와 같음.

### 4.1 당사자 항목

| 항목 | 내용 |
|---|---|
| 신고자 | 신고서를 실제 작성한 자. 대행 시 관세사, 자가통관 시 수출대행자 |
| 수출대행자 | 수출신고를 책임지는 당사자 |
| 수출화주 | 실제 수출물품의 소유권자 |
| 제조자 | 미상 처리 가능(`제조미상9999000`). 단 미상이면 **FTA 원산지증명서 발급 곤란 + 환급 제한** |
| 구매자 | 상업송장의 수입자. 사전 등록한 해외거래처부호 필요 |

수출자구분 코드.

| 코드 | 의미 |
|---|---|
| A | 수출대행자 = 제조자 (제조자/수출화주/수출대행자 동일) |
| B | 수출대행만 수행 (수출화주 ≠ 수출대행자) |
| C | 완제품 공급받아 수출 (제조자 ≠ 수출화주, 수출화주 = 수출대행자) |
| D | 수출화주와 제조자가 본/지사 관계 |

수출자구분은 통계 목적 외에 **수출실적 부여 / 내국신용장 / 구매확인서를 통한 간접수출 확인**에 사용됨.

### 4.7 운송형태

운송수단 코드 `10` 선박 / `20` 철도 / `30` 차량 / `40` 항공기.
운송용기 코드 `FC` FCL 컨테이너 / `LC` LCL / `BU` 벌크 / `ETC` 기타.
예 — 해상 LCL = `10LC`, 항공 = `40ETC`.

### 4.8 환율/금액 구조

수출신고필증에는 환율이 항상 2개 표기됨.

- 위 = 수출신고 시점의 **USD 환율**
- 아래 = 실제 **결제통화 환율**

금액은 `결제통화 금액 → FOB USD 환산 → 원화` 3단 구조. 신고 시에는 결제통화 금액만 입력하면 나머지는 유니패스가 자동계산. CIF 조건이면 운임/보험료를 입력해 FOB 로 공제.

### 4.9 보세구역/세관 코드

적재예정보세구역 코드 앞 3자리 = 세관코드. `010` 서울 / `020` 인천 / `030` 부산 / `050` 마산 / `070` 목포 / `090` 제주. 보세구역 미상 시 `세관코드+99999`.

### 4.10 미기재가 원칙인 항목

선박회사(항공사) / 선박명(항공편명) / 출항예정일자는 필수기재사항 아님. 대부분 공란. 예외는 선상신고(`L`).

## 5. 채널이 반복 경고하는 실무 함정

| # | 함정 | 결과 |
|---|---|---|
| 01 | 물품소재지를 사업장 주소로 신고 | 검사 적발 시 과태료 + 물품 이동 부담 |
| 02 | 수출신고 수리 후 30일 내 미적재 | 과태료. 연장승인 필요 |
| 03 | 신고중량과 실제중량 차이 | 실제 선적했는데 미선적 처리 → 부당 과태료 |
| 04 | 제조자를 미상으로 처리 | FTA 원산지증명서 발급 곤란 / 환급 제한 |
| 05 | 상업송장과 원산지증명서 정보 불일치 | 수입국 통관 거부 / 특혜 배제 |
| 06 | 적재지 변경 후 신고 미정정 | 물품검사 전 반드시 수출신고 정정해야 함 |
| 07 | 수출입신고 오류점수 누적 | 검사 선별 확률 상승 ("왜 내 화물만 검사 걸리냐"의 원인) |
| 08 | 운임인보이스 미수령 | 가격신고 부정확 / 통관 지연 (주로 수입 방향) |
| 09 | 소액이라고 수출신고 생략 | 부가세 영세율/조기환급 및 수출실적 누락 |
| 10 | 외국환거래법 신고대상 미신고 | 경고 없이 과태료/형사처벌. 신고대상은 4개 유형으로 압축 가능 |

## 6. 채널 커버리지 공백

수출설명서를 완성하려면 아래 영역은 **외부 소스로 보강 필요**. 채널에 사실상 콘텐츠가 없거나 매우 얕음.

| 영역 | 상태 | 보강 소스 후보 |
|---|---|---|
| 수출계약서/일반거래조건협정서 작성 | 거의 없음 | KOTRA / 무역협회 표준계약서 |
| 바이어 발굴/시장조사 | 없음 | KOTRA 해외시장뉴스, buyKOREA |
| 무역보험 (K-SURE 단기수출보험 등) | 없음 | 한국무역보험공사 |
| 전략물자 판정/수출허가 | 없음 | 전략물자관리원 YesTrade |
| 수출바우처/지원사업 | 거의 없음 | 산업부/중기부 수출지원사업 공고 |
| 관세환급 실무 (간이정액/개별환급 절차) | 개념 수준 1편 | 관세청 환급특례법 고시 |
| 전자상거래 수출 (역직구/풀필먼트) | 코드 언급 수준 | 관세청 전자상거래 수출 가이드 |
| 통관 이후 사후관리(사후심사/AEO) | 없음 | 관세청 |
| 인코텀즈 2020 개별 규칙 심화 | EXW/FCA/CIF/DAP만 2부작. **나머지 7개 규칙 미제작** | ICC 인코텀즈 2020 원문 |

인코텀즈는 조회수 최상위 주제인데도 개별 규칙 심화편이 4개(EXW/FCA/CIF/DAP)만 존재. 설명서에서는 11개 규칙을 균등하게 다뤄야 채널 대비 차별점이 생김.
